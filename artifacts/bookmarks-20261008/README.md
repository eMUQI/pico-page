# 书签（R9）

截图来自实际 `ReaderApp` C++ 画布，尺寸 684 × 1216，使用测试字体 LXGW WenKai。合成长章节 EPUB 和临时 TF 卡目录用于演示；未调用网络或硬件接口。

- `tools-add.png`：工具页顶栏右侧新增书签开关，当前页没有书签时显示空心书签和「加书签」。
- `tools-remove.png`：点击后写入 `.picopage/bookmarks.json`，开关变为实心和「删书签」，底部提示「已加书签」。
- `reading-marked.png`：正文页有书签时，右上角页边显示实心书签角标，位置与工具页开关的中心对齐。
- `contents-toc.png`：目录面板在四个工具页签下新增「目录 / 书签」切换行，目录列表整体下移 72 px。
- `contents-bookmarks.png`：书签列表，每行显示章节名、创建时的全书百分比和页首文字摘要；当前页的书签反白并显示「本页」。

## 与原稿的差异及原因

原稿没有书签界面。为不改动已有五格工具栏的宽度、热区和操作习惯，书签开关放在工具页顶栏右侧（占 100 px，原有「尚未保存 / 位置不同」标记相应左移）；正文角标沿用同一位置。目录面板新增切换行，未改变页签、目录行样式和翻屏控件。

## 生成方法

根目录 host 构建（`build/host`）后执行 `python3 artifacts/bookmarks-20261008/render.py`。脚本复用 `build/host` 中的 CMake include/link 参数编译 `render.cpp`，仅用 Python 标准库将原始 8 位灰阶画布无缩放编码为 PNG。截图不能作为墨水屏光学效果或真机触摸行为的证据。
