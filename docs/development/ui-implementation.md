# 界面实现说明

本文按当前页面和交互说明视觉基线、状态与失败处理；产品取舍以[当前决定](../planning/decisions.md)为准，发布及验收状态见[开发状态](../development-status.md)。原始 PNG／HTML 不修改；已被替代的手机配网、旧设置布局和逐批设计差异见[整理前快照](../archive/ui-implementation-20261024.md)。

## 视觉与共通反馈

保留 684 × 1216 竖屏、黑白／灰阶、方角和现有页面组织。布局起点见[原始设计](../design/README.md)，未单独导出的状态按其 HTML／文字实现。产品使用 Pico Page；版本、书名、时间、百分比和地址来自运行时数据，演示截图不作为生产默认值。

颜色、字体、线框、尺寸和组件外观以[设计系统](../design/system/README.md)为准，本文说明页面行为。产品界面与传书网页不使用虚线（D39）。按 D46，可点击控件使用实线框或黑底；不可用控件不画框，只显示淡色文字，通常不注册热区；固件更新的安装按钮在条件不满足时仍可点按，以重新检查条件并说明原因，因此保留实线框，见该页规则。单独按钮的黑底表示推荐操作，相连一组中的黑底表示当前项（D47）；删除、清除或替换使用明确动作文字与黑色实线框，推荐项为「取消」。单选项以圆点表示选中，以文字「当前」「待保存」表示保存状态。D46 通用组件及部分页面已完成首批迁移，全部页面的字号与热区尚未收敛；实施范围、剩余差异与待澄清规则见[一致性检查](../design/design-system-audit-20261028.md#首批实施跟进)，真机视觉仍待验收。

顶栏左侧为「‹ 上一级名称」，后接粗体标题，中间不加竖线；书库子目录保留「‹ 上一级 | 文件夹名」。工具面板统一返回「‹ 正文」。「›」只用于进入子页的行，立即执行的动作使用按钮。多行说明不拆开英文单词、数字和路径，结束标点不置于行首。

界面文案按 [Tech-Doc-Style-Chinese](https://github.com/Fenng/Tech-Doc-Style-Chinese) 的规则在中文界面中采用：控件名、网络名和引用文字用「」，嵌套用『』；中文与英文、数字之间留半角空格；存储介质统一称「TF 卡」，不与「存储卡」混用。错误与空状态写清发生了什么、影响和下一步，只陈述已确认的原因；任务、锚点、字段、驱动原因码等实现细节只写入日志。加载中的短标签保留单个「…」，以适应控件宽度。

提示使用既有页脚区（y=1120 起）；有多屏时暂时替代中央页码，两侧翻屏保留。提示在下一次输入时清除，K2 不清除。书库、目录、书签和使用说明的翻屏页脚边界为 205／479，文字贴 36／648；不可用方向留空，单屏只显示提示。正文页脚另从 y=1128 起，不混用两者高度。

阅读位置只显示「已保存」或「尚未保存」。保存状态来自 StoreAck，上传确认对应实际发送的 revision 与账户，显示忙碌和基准来自显示事务；页数可未知，字体须区分偏好与实际回退。文档／存储／同步层的英文错误只写诊断日志，界面按实际类别显示中文，未分类错误不推断文件损坏。缺字统一显示空心方框；正文缺字时提示「部分字符无法显示，可在排版中更换字体」。

书库中的书名、文件夹名、继续阅读信息，以及书籍详情和管理确认中的内容文字，整段使用全局阅读默认字体；单书排版覆盖不改变书库。书内目录、章节名、书签摘录和同步位置名称使用当前书实际使用的正文字体。菜单、按钮、状态、错误和帮助说明仍使用界面字体。字号、布局和界面强调沿用各页面规则，不随正文字号变化。所选字体缺字时显示空心方框，不逐字混用其他字体；书库字体文件无法打开时整段回退界面字体，保留用户偏好。

| 工具 S03 | 不操作背后 | 全刷当前画面 | 不操作背后 |
| 排版 S05 | 不操作背后 | 全刷当前预览，保留草稿 | 不操作背后 |
| 目录/书库 S04/S01 | 上一屏 | 全刷当前画面 | 下一屏 |
| 冲突/确认 S07/S12 | 不操作背后 | 全刷当前画面，不执行确认或取消 | 不操作背后 |
| 传输 S09 | 按实际传输模式可用项 | 全刷当前画面，不结束传输 | 按实际传输模式可用项 |
| 睡眠 S11 | 由实际 wake_sources 决定 | 同左，不假设 K2 可唤醒 | 同左 |

默认映射遵守 D03：K2 立即全刷当前画面，绕过像素相同优化，不关闭、取消、确认或退出传输。休眠准备是例外：触摸和 K1/K2/K3 均忽略，仅短按电源键取消，长按请求电源菜单；不重放忽略的输入。自定义按键尚未实现，候选规则见[路线图 R7](../planning/roadmap.md#r7--自定义按键)。

正文左／中／右点按分别翻前页、打开工具、翻后页；书库、目录、书签、使用说明和正文支持左滑向后、右滑向前，工具、排版和确认上下文不翻背后页面。阈值及长按互斥见[轻扫决定](../planning/decisions.md#2026-10-10--左右轻扫翻屏与翻页)。书库长按在松手时进入详情；正文图片按住达到 600 ms 时进入查看，松手不再点击；文字长按按下方词典规则处理。K1/K2/K3 不增加长按快捷动作。

一个输入序列只有一个消费者，打开、关闭、唤醒后的尾部事件不能穿透。刷新中的重复 K2 忽略；连续翻页按 D14 最多保留一次后续翻页，屏幕键盘采用专门的有序输入规则。忙碌时只保留当前状态实际允许的取消／返回入口。

### 非正文刷新

`reader_core` 的 `Display::present()` 统一决定逐像素保持：有效基准下的 `FramePurpose::Overlay + RefreshIntent::Content` 保持未变化的非白像素，前后变化的像素沿用当前波形序列，白→白保留当前 BSP 波形自带的维护驱动。默认 Gray16 在已有相位内维护白底，不增加相数；快速 Gray8 原表没有该脉冲，继续保持。该规则适用于书库、书籍详情、目录、书签、设置各页、传书页、使用说明、工具栏、各类面板、确认页和错误页的普通整屏更新，也适用于正文页脚、传书状态区、更新进度、休眠等待及取消恢复页脚、锁屏失败提示、内联图片补图、键盘区和输入框的已有局部更新；局部更新仍限于原请求的区域。

默认档使用既有 Gray16 保持表，快速档使用既有 Gray8 保持表；变化像素及白→白维护沿用各自源表的相位序列。面板仍完成既有扫描，不新增内存，不改变源波形表、扫描时序、pclk 或刷新档位，也不承诺刷新时间按变化面积缩短。未变化的非白区域不再顺带重刷，连续操作的累积残影由 K2 清除。灰阶、闪烁、残影及同条件面板耗时须按 DP08 在两档分别验收。

K2（`ManualRefresh`）、基准失效、刷新失败后的恢复、二维码首次出现（`overlay(true)`）仍完整清屏；所有显式 `FullClean` 均清除区域限制和 `changed_pixels_only`，保留开机首帧、返回书库、锁屏、关机或安装结果等已有全刷请求。正文翻页（`Body`）不设置该标记，继续按刷新档位和翻页效果执行；独立页脚更新和补图属于 Overlay，不推进正文位置或修订。正文帧内页脚的相同非白像素保持，白→白保留当前 BSP 波形自带的维护驱动；不为快速 Gray8 表添加原本不存在的脉冲。

### 翻页效果

正文提供「关闭」和「水波纹」，默认关闭，重启后关闭，不持久化。下一页从右向左传播，上一页相反，方向来自实际翻页动作，按键、点按与轻扫一致。只在允许效果的普通正文刷新中播放；清晰档、K2、自动全刷和失败恢复仍完整刷新。

效果只改变显示过程，最终页面成功呈现后才推进位置和保存；中间帧不算已呈现。连续翻页按 D14 最多补一次，可跳过剩余效果帧显示目标页。残影与耗时须经真机验收，不以 host 画面证明效果合格。

## 书库与管理

文件夹用带页签的外框，排在书前面（降序时也是）。卡片为 184 × 250 的封面加一行状态；封面铺满卡片，无封面时在卡片上写书名。状态为「文件夹」、百分比、「在读」或「未读」（D24）。文件夹条目不显示内部书籍数量，绘制时不为数量扫描子目录；进入文件夹后，顶部数量由已加载的当前目录列表计算，写作「1 个文件夹 · 4 本书」。点卡片打开书，长按进入详情（D22）；「详情 ›」已去掉。列表视图按原稿 S01-1：有封面的书在行左侧显示 59 × 80 的封面，没有封面的不留空位；状态在行右侧。列表封面由卡片缩略图缩小得到，两种视图共用同一份缓存。封面缩略图全白时按没有封面处理，在卡片上写书名；真机上有多本文章类 EPUB 的封面解码结果是全白。「继续阅读」卡片只在书库首页和多个扫描根的根文件夹显示，且仅当有可继续的书；没有时列表上移。单一扫描根的内容直接显示在书库首页，不额外列出根文件夹；进入其子文件夹后返回书库。

排序按钮依次切换「最近阅读 / 书名升序 / 书名降序」，成功写入全局设置后才采用，失败保留原顺序。最近阅读首页不重复列出继续阅读中的书，计数写「另有 N 本」；该卡片也能长按进入详情。继续阅读卡片在书库首页的每一屏持续显示，进入子文件夹后仍不显示；列表有卡片时每屏最多 5 项，没有卡片时每屏最多 7 项，卡片视图每屏 6 项。仅当当前书库存在最近记录分组或继续阅读卡片时，在最近记录之后按书名列出「其他书籍」；没有阅读记录时不显示该分组标题，不将缺少历史记录等同未读。进度状态仅为可见条目延迟读取，支持备份进度；不在书库扫描时逐本探测进度文件。历史文件不可读时本次扫描回退书名顺序，不改写排序偏好，排序按钮持续显示「书名（回退）」。书名排序不读取最近历史。实际日期按与正文时钟一致的 UTC+8 显示今天、昨天、N 天前或月日；未校时、未知及未来日期只显示进度。

书库排序和视图切换区位于顶栏或继续阅读卡片下方：可见按钮高 60 px，字号 22 px，上下各留 14 px，以保持标题、辅助工具与内容的层级；触控区独立扩展至工具行的 88 px 高，不与标题或书籍行重叠。排序按钮宽 164 px，两个视图按钮各宽 92 px。数量文字为 22 px，混合目录中的文件夹计数为 20 px。列表行高 126 px，保留每屏 7／5 项和卡片视图 6 项，分组标签与末行均不得侵入 y 1120 起的页脚。

默认置顶；「设置 → 书库 → 书库文件夹」可改为「跟随最近」。后者按已记录的目录内打开活动排序，不再次查询历史路径的文件状态；已删除或移走的子书仍可能贡献该目录的历史活动日期。历史路径只用于排序和日期，打开书籍时仍执行现有路径安全检查。不递归打开目录中的 EPUB。书名排序下仍将文件夹置顶。

封面按 EPUB 3 `cover-image`、EPUB 2 `meta name="cover"`、guide 封面页依次查找，无声明时仅接受第一 spine 的单图片页。只处理当前屏最多六张封面，不计算整书身份摘要；封面页 XML 最多 256 KiB，图片最多 2 MiB。缩略图最多缓存八张、184,000 字节像素，文件大小／修改时间变化时失效，卸载 TF 时清空。继续阅读卡片保留两行书名，未开书且没有位置缓存时提示「打开后恢复已保存的位置」。

详情不改变阅读会话，长标题最多四行。管理入口提供清除本地进度和删除原书（缓存清理只在「设置 → 存储」整体进行），破坏性操作另有带书名与路径的确认；删除保留伴随记录，清进度不修改远端，也不能被旧备份／outbox 恢复。文件范围与提交协议见[存储约定](storage.md)。原文件大小不冒充原书、缓存与附属文件合计。

目录扫描区分正常结束、达到 512 项上限、部分读取失败和目录不可用。条目在扫描后已不存在时跳过；其他元数据或目录读取错误保留已读条目，页脚提示「部分文件读取失败，列表可能不完整」；没有可用条目时显示「无法读取书库目录」和「重试」按钮，不显示正常空目录。数量上限及部分失败提示保留到重新扫描，不被封面加载或最近记录回退提示覆盖。

默认书库 `Books/` 不存在时，扫描先由 store 创建该目录（不覆盖已有条目），新卡因此直接进入空书库。自定义扫描根不自动创建：不存在时写「找不到书库目录」并指出 `PicoPage/settings.toml` 的 `library.roots`；同名普通文件写「无法打开书库目录」；创建 `Books/` 失败时，确认可用空间为 0 写「存储卡已满」，FatFs 的 EACCES 同时代表写保护和满卡，未确认满卡时写「存储卡拒绝写入，可能处于只读状态」，其余错误可重试。顶栏保留「导入」。

存储卡不可用时顶栏不显示「导入」，不显示继续阅读卡片，正文按原因区分：启动时未检测到卡、卡上没有可识别的文件系统、挂载失败，以及运行中拔卡；均提示重启，并提供「关机 / 重启」打开电源菜单，因为重新插卡后需要重启才能挂载。

TF 卡与书库目录问题沿用空书库的版式：标题 y=160（40 px 粗体），灰色概述 y=222（26 px），其下一条分隔线；处理方法逐行列出，有先后顺序的步骤才编号，替代做法合并为一行；唯一的操作按钮与空书库相同，在列表结束后隔 56 px（宽 636、高 96）。需要电脑处理的目录问题提供「USB 连接电脑」，读取失败提供「重试」，只读卡不提供按钮。有继续阅读卡片时从卡片下方 40 px 开始。顶栏没有「导入」时省略整格及其分隔线，不留空格。运行中拔卡时，在书库直接显示该状态；在其他页面先显示错误页，最近位置未保存时说明「最近的阅读位置没有保存」，不提供无法成功的「重试保存」。

### 空书库

书库根目录没有书且没有继续阅读卡片时，正文区改为标题（y=160）、说明（y=222）和三行放书方式（y=288 起，行高 132，沿用设置页的行，框线为黑色）。「USB 连接电脑」直接请求 USB 传输，「Wi-Fi 传书」直接请求设备热点传书，「直接放入 TF 卡」只是说明，没有箭头和热区。列表结束后隔 56 px 是「查看使用说明」（y=740）打开说明第 1 屏，此时说明页左上角返回书库；按钮下方隔 40 px 是内置字体说明。顶栏不变。文件夹为空，以及根目录为空但仍有继续阅读卡片时，保持原有文案和「导入」按钮；原文案在目录名前补上空格。存储卡和书库目录不可用的页面见上文。

从空书库发起的 USB 或热点没有启动时，原因显示在「网络与传输」页，该页左上角返回书库。Wi-Fi 已关闭时点「Wi-Fi 传书」同样进入「网络与传输」页，页面说明 Wi-Fi 已关闭并提供「Wi-Fi 设置」，左上角返回书库。从书库进入的「网络与传输」页打开 Wi-Fi 设置时，Wi-Fi 页左上角标「‹ 传输」并返回该页；从设置进入时仍返回设置。

放书说明按实际书库目录显示「插回后重启设备」；长路径先省略完整前缀目录，仍放不下或配置多个根时写「已设置的书库目录」。内置字体说明使用「文楷字体」，不依赖内置子集中不存在的字。

## 阅读、目录与书签

阅读顶栏仅在「尚未保存」和「位置不同 ›」时显示状态标签。五格工具栏宽度为 137／137／137／137／136，末格止于屏幕右缘；「刷新模式」为 26 px，其余四项 28 px，名称只打开刷新面板，不等于全刷。收起热区为 y=104–1080，提示条不占热区。面板上沿提供收起，下面为目录、排版、同步、刷新页签。

目录使用工具面板，当前章节反白并显示「当前 · P%」，其他条目显示章起点的全书百分比；子条目位置在该章加载前未知，不显示百分比。页数未知时按章节大小估算。父条目保留折叠按钮及子条目数量。

目录条目的行高、分页和绘制使用同一套最多两行的标题布局，字号沿用顶层 28 px、子级 24 px。标题按实际字体升部、降部及行间距垂直居中，上下至少各留 14 px；右侧百分比按自身字体度量居中。超过两行的标题以省略号收尾，右括号、问号等结束标点与前面的文字一起换行，标题不覆盖相邻条目、展开热区或底部翻屏控件。共享标题绘制使用相同的结束标点换行规则；不改变目录结构、展开方式或阅读位置。

### 书签

工具页顶栏右侧提供 100 px 书签开关：当前页没有书签时为空心书签和「加书签」，有书签时为实心和「删书签」。点击直接写入或删除，不另设确认；删除只作用于当前页内的书签。原有「尚未保存 / 位置不同」标记左移到开关之前。五格工具栏的宽度、热区和顺序不变。正文页有书签时，在右上角页边（正文顶部留白内）显示实心角标，与开关中心对齐。目录面板在四个页签下提供 72 px 的「目录 / 书签」切换行，目录列表相应下移；切换状态保留到打开另一本书。书签列表沿用目录行的反白、分隔线和翻屏控件，每行显示章节名、创建时的全书百分比和页首文字摘要；当前页的书签反白并显示「本页」。书签文件损坏、版本较新或属于另一份内容时，列表只显示原因，不提供跳转。默认 K2 在这些页面仍只全刷。

书签提交期间，进入排版、刷新、同步及其他需要读卡的设置页前，先处理当前提交结果。提交失败时显示现有错误页，停止后续设置操作；目录或书签列表中完成的失败也显示错误页。文件被外部修改后重新读取，并提示「请核对当前书签」，避免再次点击把已经完成的添加或删除反向执行。

### 正文图片与等待反馈

正文图片按 D36 渐进显示：先呈现文字和图片占位，首次开书的正文帧成功刷新后即可提交图片准备，后续翻页仍须短暂停留，保持翻页可用；停留期间继续翻页不启动旧页图片任务，也不为该任务提前清理预取和分页资源；图片就绪且仍在原页时局部补刷。已准备好的当前页或预取位图直接显示；空闲时不预先准备下一页的图片，也不预取下一分段或下一章。翻页取消旧请求，旧结果不覆盖新页；补图不改变阅读进度。缺图、解码失败或内存不足只在图片区域显示原有错误提示，不阻止阅读其余正文。

图片查看页左上返回正文，右上按原图 0/3、增强 1/3、2/3、3/3 循环；每次打开默认原图，切换及 K2 全刷当前图片，不改变阅读位置。缺图或资源不足仅在图片区显示原因，不丢其余正文。

正文跨章／分段立即进入加载状态并暂留原画面；1 秒内完成直接显示目标页，超过 1 秒时请求章节 worker 在检查点暂停，确认后显示一次「正在准备章节…」及取消控件，再继续解析。提示出现前没有隐藏取消热区，K2 不改变已确认位置。目录等面板发起的跳转立即显示等待反馈；目标页呈现失败不推进进度。

开书和书库封面使用「正在打开书籍…」「正在生成封面…」等阶段反馈，不做动画或进度轮询；已命中封面直接显示。从工具或错误页开始加载时先恢复正文再显示状态行，同步位置换算留在同步面板，排版图片准备留在预览区。异步完成不等于已呈现或已保存，资源与取消边界见[架构](architecture.md)。

### 阅读页脚

- 左侧依次显示全书页码/总页数、全书百分比、章节序号/总章节数、当前章节名。默认显示全书页码/总页数。章节名与阅读页顶部使用同一名称，空名称显示「第 N 章」；显示名称先按 UTF-8 字符边界保留最多 128 字节，超出时附省略号，再按可见宽度单行省略，右侧电量/时钟不被覆盖。
- 页数尚未统计完成时，页数模式显示「正在统计页数」或「等待统计页数」；统计失败显示「页数未知」。百分比模式沿用章节大小估算，四舍五入显示整数（如「27%」），不附「估算」；统计完成后保留两位小数及尾随零（如「5.00%」），通常按全书页码/总页数计算。若当前位置属于不参与全书页数统计的非正文条目，仍使用估算比例，但显示精度由统计完成状态决定。
- 右侧默认电量，点击按「电量 → 时钟 → 不显示 → 电量」循环。系统时间不可用时显示「—」，可用时显示北京时间（UTC+8）HH:MM。启动时可从已校准的 PMU RTC 恢复系统时间；按需联网收到真实 NTP 回包后，空闲时写回 RTC。PMU 复位或完全断电可能失去校准，仍需联网恢复；内部时钟会漂移，不保证离线长期精度。切换页脚时钟不隐式联网或定时刷新；翻页或重画页脚时更新。明确校准入口合并到 Wi-Fi 设置页，见下方 Wi-Fi 页。
- 684 px 画布上的左侧热区为 x < 540，右侧为 x ≥ 540，均在 y ≥ 1128 的页脚内。采样接触跨越左右边界或正文/页脚边界时忽略，不触发切换；显示忙时或指向旧画面的接触仍沿用忽略规则。
- 两侧均可切换为「不显示」：左侧在当前章节名之后进入，下一次点击恢复页码；右侧在时钟之后进入，下一次点击恢复电量。隐藏时保留原热区和页脚留白，不扩展正文区域；两侧可以同时隐藏，必要通知和休眠提示仍按原规则显示。右侧隐藏时不因充电状态变化刷新。
- 两侧模式在当前应用会话内保留，切换不改阅读位置、不写配置或进度文件，不翻页或打开工具。页脚通知仍优先显示在左侧；下一次有效输入按既有规则清除通知。K2 只全刷当前画布。
- 正文普通更新在同一次刷新内保持 y ≥ 1128 的未变化像素，页码、进度、电量、时钟及提示等变化像素仍按所选波形更新；左右隐藏时沿用页脚留白。保持掩码在扫描前生成，行生产者仅使用既有向量位掩码操作；临时 PSRAM 分配失败时停用本次页脚保持，继续原有灰阶刷新。正文区域和水波纹条带顺序不变，不增加独立页脚刷新。K2、清晰档、自动全刷、基准失效与欠载恢复仍完整清屏；实际闪烁、残影及耗时待 DP10 真机对照。
- 充电标识：PMU 报告正在充电时，仅在右侧电池内部显示静态闪电，保留电量百分比及热区。电池与百分比作为一组靠右排列，右边界为 x=648，图标与数字间距为 10 px；电池外框为 32 × 18 px，与 24 px 数字的可见区域垂直居中，端子另占 3 px。充电时以闪电替代电量填充，百分比仍显示实际电量；停止充电后恢复填充。时钟模式只显示时间，不因充电状态变化刷新。充电状态独立于百分比有效性，SOC 无效但 PMU 状态有效时仍可显示闪电；PMU 状态读取或校验失败时清除充电快照。电量模式下充电状态变化后，主循环在阅读页空闲时局部更新整条页脚；有已排队输入、正在进行的输入序列、唤醒输入恢复、刷新、内容加载、图片查看或休眠准备时延后，只更新快照，后续绘制采用最新状态。不新增定时器、弹窗、动画或休眠唤醒，不以连接 USB 或电量达到 100% 推断正在充电。其他页面不增加充电状态。

页码对应当前排版中首个可见字符所在页，恢复、目录或链接跳转后连续翻页可重复或跳过页码；页数未知不阻塞正文。改排版后重新统计，统计完成不单独刷新屏幕。异步输入取消在途统计但保留可复用会话，改代次、离开正文或其他内容工作需要资源时交还；无法继续时保留未知／等待状态。长章节按分段读取，不用整章大小拒绝有效正文；真实资源不足仍显示错误并保留确认位置，边界见[文档后端](document-runtime.md)与[图形排版](graphics-runtime.md)。

## 排版与字体

七个参数与「恢复默认」组成 4 × 2 网格，框线从 x=24 到 660，列宽 150、间隔 12。参数区 y=780/872，步进 y=976，底部操作 y=1088。字重紧邻字体；步进两键对齐首末列，底部两键各跨两列。预览状态移入收起条，有草稿时显示「放弃修改」；不再提供基本/高级切换或重复的取消链接。到达范围边界的步进键不画框，只显示淡色文字，没有热区。原本超出 UI 步进范围但合法的文件配置仍可读取。字重能力见 [图形运行说明](graphics-runtime.md)。

预览只改草稿。「应用到此书」优先准备当前位置；取消不写文件。「使用阅读默认」删除本书覆盖，不等于恢复固件出厂设置；「设为阅读默认」只保存已确认有效参数，影响继承默认的书，本书应用和全局保存分别反馈。存在单书覆盖时不得被全局更新覆盖，无效字体不能设为默认。

### 分页字体选择

点击排版网格的「字体」进入选择页，仍属于排版上下文。顶部使用当前正文位置及排版草稿预览，预览范围为 y=64–500；y=500–550 显示「预览 · 尚未应用」和正在试看的字体名。y=576 起显示标题与实际列表数量，每屏四项，从 y=624 起、行高 90；长字体名最多两行，超长部分省略，已知字体的独立字重文件补充字重名称以便区分。右侧圆点表示正在试看的字体，「当前使用」标记进入排版时已应用的字体，两者互不替代。

「上一页」「下一页」位于 y=1008，中央显示当前屏与总屏数；不可用方向不画框，只显示淡色文字，不注册热区。每次打开定位到排版草稿字体所在屏。翻屏只重绘下方列表和控件，保留已经显示的预览像素，不加载字体、重新排版或启动预览图片任务，不改变草稿字体、正文锚点或阅读进度；点选其他字体才更新上方预览，并将字重重置为常规。字体列表复用现有的 Fonts/ 扫描结果，翻屏、点选和绘制中不新增目录扫描。

底部 y=1104 的「取消」在图片预览加载期间仍可用，与预览区的取消入口一样恢复进入字体页前的字体、字重及恢复默认意图，保留此前的字号等草稿；取消后返回排版面板，图片预览显示暂不可用，不自动重启已取消的准备任务。「选用此字体」保留本次选择并回到排版面板，不写入配置。之后仍由「应用到此书」或「设为阅读默认」正式保存。按用户确认，不显示「选择后返回排版预览」。所选字体不可用时显示替代预览说明，并禁用「选用此字体」；可以选择其他字体或取消。沿用现有字体回退、图片异步准备与显示失败恢复路径。K2 全刷当前画面并保留选择、分页和进度；K1/K3 及轻扫沿用排版上下文，不操作背后正文。

### 使用说明

设置固定提供「使用说明」，也可从空书库进入；每次从第 1 屏开始，左上返回来源页面。当前为 12 屏，离线、无 TF 卡或无用户字体时可读，不新建书籍和进度。内容随固件维护，涵盖按键、触摸、书签、页脚、传书、联网、接续、休眠与更新。

### 首次开机引导

## Wi-Fi、键盘与同步

手机配置会话已按 D37 删除；Wi-Fi 密码和同步账户在设备键盘输入。默认允许无线不等于开机联网；已保存 SSID 不表示在线。连接、扫描与验证由 worker 执行，不在输入或绘制回调等待网络。

### Wi-Fi 页

- 首页：大字写连接状态（未连接 / 正在连接 / 已连接「名称」/ Wi-Fi 已关闭），小字写连接方式。「Wi-Fi」行右侧显示「开 / 关」，点一下切换，不带「›」。下面依次是「连接方式」「已保存网络」「添加网络」。「立即连接」和「断开」按状态只显示一个；没有已保存网络时「立即连接」不画框，只显示淡色文字（不可用）。Wi-Fi 关闭时只留开关一行。
- 连接方式：单选列表，「自动」和每个已保存网络各一行，点一下立即生效，不需要确认。当前项只用左侧圆点表示，不加外框和「当前」标签。
- 已保存网络：列出网络，被指定的那一个标「指定」。点一个网络进入详情：「更新密码」和「忘记网络」；忘记需要确认，忘记被指定的网络时提示将改回自动。
- 添加网络：进入时扫描一次，列出附近的 2.4 GHz 网络（每屏 6 个，页脚翻屏），右侧写「需要密码 / 开放网络 / 已保存」。点开放网络直接连接；其余进入密码页。「手动输入网络名称」分两步：名称、密码。已保存满 5 个时，未保存的网络和手动输入不可点，仍可更新已保存网络的密码。
- 连接中页只有「取消」；取消后回到密码页，已输入的内容保留。失败页写原因和「网络没有保存」，密码被拒时主按钮是「重新输入密码」，其余是「重试」。已连上但写入 `network.toml` 失败时，标题写「没能保存『名称』」，说明已经连上、下次开机不会自动连接，不写「无法连接」。驱动原因代码只写入设备日志，不放在提示正文。成功页写已保存的数量；没有同步账户时提供「设置 KOReader 同步」。

Wi-Fi 首页底部使用现有设置行显示当前时间、UTC+8 和「校准」操作，不增加设置首页入口或独立时间页。系统时间不可用时显示「尚未校准」；Wi-Fi 关闭、无已保存网络或其他无线任务运行时不显示「校准」操作，也不提供热区；关闭无线和缺少网络时给出对应说明。明确发起校准后右侧操作变为「取消」，取消后显示「结束中」并等待 worker 交还；返回或关闭 Wi-Fi 也取消校准。成功只表示收到新的真实 SNTP 回包，不表示已写入 RTC；失败保留已有时间。桌面预览使用主机系统时间，校准操作明确报告不支持，不模拟设备校时成功。最近校准时间尚未持久化。

### 屏幕键盘

- 键盘区从 y=796 起，4 行，键高 92，键宽 61，行距和键距 6–8。三层：字母、数字与符号、其余符号，合起来覆盖全部可打印 ASCII。字母层的「大写」只作用于下一个字母。网址键盘把空格换成 `https://`、`.`、`/`、`:`。
- 回车键的文字随场景变化：密码页「连接」，名称页「下一步」，同步字段「完成」。条件不满足时不画框，只显示淡色文字（不可用）：Wi-Fi 密码为 1–7 位、满 64 位但不是十六进制密钥、名称为空。
- 按键没有按下反色。输入字符或退格只刷新输入区（y 104–424）；切换层只刷新键盘区；回车键可用状态变化时两者一起刷新；K2 全刷。
- 键盘区和输入区的普通局刷共用上述非正文逐像素保持规则：大小写切换主要驱动标签的变化像素，未变化的非白边框保持，白底和间隙保留当前 BSP 波形的白→白维护；数字或符号层的按键几何变化仍清除旧边框并绘制新边框。变化像素沿用当前 GL16 / 8 灰阶 GL16 的相位序列，面板仍完成完整扫描；K2、基准失效及欠载恢复绕过保持掩码。切换时的横带、灰阶与连续切换残影仍须真机验收。
- 字符键只改内存中的输入内容，在主循环的下一个空闲点一次画出。刷新期间的点按全部保留并按顺序执行，不沿用「忙时只留最后一次点按」的规则（`ReaderApp::keyboard_visible()`）。排队的「回车」也执行，其他排队控件忽略。
- 点按滑出按键则不输入。每个键的命中区域延伸到间隙中线。K1、K3 在键盘页不起作用。
- 按键按当前输入内容匹配，不按已画出的控件匹配：补足最后一位后紧接着点回车，即使那一位还没画出，也会执行。
- 退格删除一个完整字符；手改配置中的非 ASCII 账户名不会被删成半个字符。
- 密码默认明文显示，可点「隐藏」；「清空」删除全部内容。超出输入框宽度时显示末尾。
- 草稿只在本次流程内保留：取消连接、失败后重新输入时保留；离开流程、休眠或保存成功后清除，不写入存储。

### KOReader 同步账户

- 「设置 › KOReader 同步」改为可编辑的三行：服务地址、账户、密码，各自进入单字段键盘页。「验证并保存账户」在账户和密码都具备时可用；已保存且未修改时写「重新验证」，并沿用已保存的密钥。小标题按实际情况写「未保存 / 已保存 / 已验证 / 验证未通过」：文件里有账户只说明已保存，本次验证通过后才写「已验证」。
- 验证按连接方式联网；只有服务器接受时才写 `sync.toml`。结果写在页面下方：已验证并保存、账户或密码不正确、没有连上同步服务器、联网失败的原因。验证未通过、失败或取消时，已保存的账户写「原来的账户保留」，修改过则写「修改没有保存，原来的账户保留」，只有原本没有账户时才写「账户没有保存」。「移除同步账户」需要确认。
- 已保存账户且有打开的 EPUB 时，显示「检查《书名》的同步」。

### 同步面板

- 两栏「本机 / 远端」加一行状态。本机栏写章节和百分比；远端栏写服务器返回的百分比、设备名，位置对上后写章节。
- 按钮分上下两行。上面一行放不改动数据的操作（检查、再次检查、重试、继续阅读、设置账户）；「上传本机位置…」和「取消」固定在下面一行，所以检查后的第二次点按不会落在上传上。
- 检查前显示「网络」行（自动 / 指定 名称 / 已连接「名称」），点进去是连接方式页。
- 检查中、上传中只显示一句进度、所用的连接方式和取消按钮，不显示无操作的占位按钮。
- 两端位置不同时，两张卡片就是按钮：「留在这里」和「跳到这里」，更靠后的一张用粗框并标「更靠后」。前后关系按远端位置映射后所在的章节、章节分段和段内偏移与本机当前页比较，不使用服务器记录的百分比；远端位置落在当前页内时不标。两张卡片的百分比用同一种方法计算：页数统计完成后按所在页码，完成前按章节大小估算。远端位置无法映射时只显示服务器记录的「约 P%」，不判断前后。「留在这里」不上传，正文顶栏保留「位置不同 ›」，直到下次检查或换书。
- 上传确认分两种：远端无记录时问「上传本机位置？」，主按钮是「上传」；远端有位置时问「用本机位置替换远端？」，写出两端位置，默认按钮是「取消」，「替换」为实线框。不可用控件不画框，只显示淡色文字，并移除热区。
- 远端位置在本机找不到时，主按钮是「继续阅读」，上传是次要操作。位置所在的章节超出精确映射范围（例如含有表格）时，状态行写明这一原因：检查远端时为「远端位置所在的章节含有表格等暂不支持的内容，无法换算成本机位置，没有跳转。」，上传时为「这一章含有表格等暂不支持的内容，无法换算成 KOReader 的位置，没有上传。」，不使用「两端的书可能不是同一版本」或「暂时不能上传」。
- 账户被拒时主按钮是「同步账户设置」。未设置账户、Wi-Fi 关闭、TXT 都在面板内显示，不再跳到整页。
- 指定的网络连不上时，面板写明没有连接其他网络，并提供「重试」和「本次改用自动」；后者只对这一次检查有效。自动方式失败时提供「重试」和「Wi-Fi 设置」。

同步面板在查询/上传期间保留固定等待画面，不随连接、校时和请求阶段反复刷新；结果和错误正常呈现，取消入口与 K2 全刷保留。同步面板默认直接按需联网。明确禁用无线后，点击检查才显示「开启 Wi-Fi 并同步 / 取消」；确认保存许可成功后继续原查询。整次查询与上传使用同一会话，等待用户选择最多两分钟；超时后上传入口先重新查询，不盲推。上传取消或失败保留结果未知，不能当作确定未上传。取消先显示「正在结束同步…」；只有取消的是上传时才提示「已发出的上传仍可能生效」，取消检查时写「本机位置没有改动」。等待页按钮按来源写「恢复阅读」「返回书库」或「返回设置」，账户验证的等待页不写「继续离线阅读」；旧回包不影响正文和新保存位置。结束状态仅由 worker 确认，休眠仍须等待资源完全交还。

同步和添加网络的等待画面不随联网阶段反复刷新；结果显示真实原因。指定方式失败不扫描，不伪造附近网络数量，有两个以上已保存网络时提供「本次改用自动」。输入框沿用界面字体；远端更新时间尚未解析，不显示为已知值。

位置准备任务创建失败时留在同步面板，允许重试、继续阅读、取消和 K2，不改位置或自动上传；与远端位置不支持分开处理。超长节点提示明确写「没有上传」或「没有跳转」，不自动使用附近位置；当前兼容边界见[同步实现](sync-runtime.md#精确映射与明确拒绝)。

跳到远端后显示「返回原位置」；成功向前或向后翻页才清除入口、热区和返回状态，按键、点按、轻扫及跨段／跨章一致。无可翻页、取消、呈现失败和 K2 保留已确认状态。脚注及内部链接的返回规则不变。

## USB 与 Wi-Fi 传书

入口沿用「设置 → 网络与传输」，书库入口返回书库；传书页只显示本次会话地址和真实结果。USB 进入前成功呈现准备画面、保存并交还卡，传输期间由电脑独占；准备失败时按实际原因提示（没有可用的存储卡、设备正忙、正在结束后台任务、阅读位置没有保存）。开启后标题写「USB 文件传输已开启」，不写「电脑正在使用」，因为设备无法判断电脑是否在访问；退出使用屏幕确认并重启，K2 不取消或退出。操作和失败处理见[USB 文件传输](usb-storage-runtime.md)。

Wi-Fi 传书保留设备热点和已保存网络两种方式，具体控件与上传限制见[传书说明](../user/wifi-transfer.md)。会话页首次二维码全刷，地址不变时状态仅局刷；状态为等待、接收、已保存数量和最近文件，完整逐项结果在浏览器。只有提交及回读成功才计数；K1/K3 无动作，K2 全刷。热点页保留 iPhone 无互联网时选择「不连接互联网使用」并打开浏览器的说明，不把认证页一概描述为无法上传。

传书中查看 Wi-Fi 状态不读写配置、不结束服务；返回仍可查看原地址。更改许可或目标前先结束会话，实际收尾由 worker 确认。借用手动 STA 时仅停止服务，临时连接则释放；热点退出不自动恢复 STA，休眠清除暂停的手动连接意图。配置文件的外部编辑在安全边界重新读取。

- 更新日志：标题 30 px 粗体，上方留 28 px；列表 26 px，圆点悬挂缩进 28 px；`**` 之间为粗体。其他 Markdown 语法按纯文字显示，链接只保留文字，反引号去掉。文字区为 y 132–984（首屏从 184 起，上方是发布日期和版本阶段）。分屏在块之间断开，小标题与其后第一行不分开，单块超过一屏才在行间断开。K1/K3、左右轻扫和页脚翻屏；「下载并安装」在每一屏都有（y 1008）。
- 数据格式确认、更新没有完成：底部面板盖在原页面上，面板外没有热区。清单中的阅读进度或设置格式高于本机时，正式构建与开发构建均须在下载前确认；开发构建说明与「换成发布构建」按钮保留。本次检查和缓存清单联网复核后采用相同规则；取消确认不发起下载，K2 只全刷。格式未提高时不增加确认。
- 下载：进度条 y 320–360，下方为已下载量和百分比，再下方是三步指示（y 452–524）。每 5% 只刷新 y 300–424；进入校验时整屏更新一次。顶栏没有返回，只能点「取消下载」。电源键短按在检查和下载期间不响应。
- 下载失败：标题按实际失败写「无法开始下载」（尚未收到数据或没有取得网络时间）、「下载中断」（已下载部分后连接中断或超时）、「下载服务器返回错误」「校验没有通过」「固件超出容量」「型号不符」。超出容量写明是本机固件分区的限制，与存储卡空间无关；超出容量和型号不符重试也不会成功，只提供「返回」，其余提供「重新下载」和「稍后」。
- 校验通过：「重启并安装」（y 976）和「稍后」（y 1088）。重启前的整屏提示只画一次，之后不接受输入。
- 结果：安装成功后首次开机显示版本和更新日志，按钮为「回到书库」；回到旧版本时在书库上显示底部面板。两者都只显示一次。

- 固件更新检查：进行中用状态三格（Wi-Fi、互联网、更新服务器，各 196×176，y 456）随网络阶段更新，进行中的一格写「连接中…」或「读取中…」，正文依次为「正在连接 Wi-Fi。」「已连接『网络名』，正在访问互联网。」「已连接互联网，正在读取更新信息。」，未开始的用淡色实线和灰字写「等待」；底部只有「取消」。失败时标题为「! 这次没有检查成功」，正文说明原因，三格中失败的一格为 3 px 框，格内分别写「未连接」「失败」或「异常」，之后的用淡色实线标「未进行」。互联网一格的失败只陈述实际失败的一步：没有取得网络时间，或无法解析更新服务器的地址；服务器返回非 200 时写出 HTTP 状态，不推断「网络没有问题」。按钮上方一行写上次成功检查的时间和服务器版本，没有缓存清单时不写；缓存不记录检查当时与本机版本的比较结果，因此不写「当时已是最新」。有可安装版本或开发构建时仍用原布局，重新进入页面后失败原因继续写在按钮下方。按钮按失败步骤给出：Wi-Fi 失败时为「重新检查」和主按钮「Wi-Fi 设置」；无法访问互联网时为「Wi-Fi 设置」和主按钮「重新检查」；更新服务器异常时为「稍后」和主按钮「重新检查」。本次检查成功且没有新版本时标题为「已是最新版本」，下方写「检查于 <日期> <时间>」；只有缓存结果时仍写「上次检查未发现新版本」。
- 失败步骤由网络任务判断：连不上 Wi-Fi 为 Wi-Fi 步骤（附近没有已保存网络时写已保存的数量，密码错误时格内注明）；连上后校时失败或解析不到更新服务器域名为互联网步骤；域名可解析但连接失败、HTTP 非 200 或清单无效为更新服务器步骤，格内写「连接失败」「HTTP <状态码>」或「清单无效」。有可安装版本或开发构建的页面仍用原布局，原因写在按钮下方。

卡上清单需要联网复核时，首页和更新日志页的安装入口在 Wi-Fi 关闭或未保存网络时进入 Wi-Fi 设置，仍检查电量、任务与版本条件。查询失败保留旧清单及时间，不能把缓存称作当前最新；回退缓存不记录当时与本机版本的比较结果。

所有返回和取消使用屏幕控件，K2 只全刷。第一批不提供顺便检查、下次开机再装及回滚日志文件；校验后的第二个按钮为「稍后」，说明重启后需重下。版本区不显示构建日期，数据格式确认不承诺首次开机迁移或未经测量的安装时长。结果成功后固定回书库，不自动开上次的书。

## 电源与休眠

休眠反馈按 D43、R4 处理：手动或自动休眠请求被接受后，先在原页页脚显示一次「正在准备休眠，按电源键取消」，提示刷新完成后再结束网络、保存进度、交还后台资源及准备休眠画面；书籍封面、保留正文、简洁屏保和自定义图片共用此流程，不等待图片任务或 1 秒计时，不增加倒计时或连续进度刷新。从请求休眠到进入浅睡，仅再短按电源键取消准备；触摸和 K1/K2/K3 均忽略，不全刷、不保留或重放到原页。长按电源键仍请求电源菜单，待页脚恢复和 worker 交还资源后打开。取消后恢复页脚与原页面交互。真正无法准备时才使用既有简洁屏保，唤醒后在原页面页脚提示「本次使用简洁屏保」，不弹错误页，不要求确认；图片已显示时，轮播记录或图片缓存提交失败不提示，只写诊断日志。提示只局部更新页脚，保留阅读位置、正文图片任务与书库分页，详细原因进入诊断日志；资源不足或缓冲分配失败时允许省略等待提示，详见 PW07。

长按电源键或设置入口打开「关机／重启／取消」。完整点按同一控件才执行，滑出即取消，即使滑回也不恢复本次选择；菜单出现前的旧触摸不能触发按钮。选择后直接保存本地位置，不二次确认或等待云同步；仅本地保存失败允许「仍然关机／重启」或「返回」。进入最终收尾后不再恢复现场。最终画面分别为「已关机」「正在重启」「请手动关机」，画面呈现不证明物理断电；保存、失败及电源边界见[平台实现](platform-runtime.md#电源键菜单与关机重启2026-10-08)。

### 自定义锁屏

「电源与休眠 → 自定义图片」沿用四种休眠画面。图片入口分为「选择图片 / 轮播」与「预览」；文件名下显示「叠加当前画面」切换行，值为「开」或「关」，默认关闭，点按整行切换草稿（D47；固件当前仍为按钮），K2 只全刷，统一通过底部「保存设置」提交。开关适用于指定图片和轮播；关闭时透明区域为白色，开启后保留休眠前当前画面。正文底图清除整条阅读页脚，隐藏统计提示、进度、电量、充电标识、时钟和临时通知；书库和设置仍保留原画面。不透明 PNG 与 JPEG 保持白底完整图片。

预览沿用现有加载及取消入口。开启叠加时，worker 使用进入预览前设置画面的独立副本；准备成功后显示全屏图片，顶部保留「休眠图片预览」返回入口，底部说明底图来源并提供「返回」。预览不提交设置、不推进轮播；取消或失败回电源页，失败提示位于原提示区。休眠准备提示不得进入最终底图，显示和取消规则沿用 D43、R4；合成画面不保存到 TF 卡。

指定图片、轮播顺序、文件限制、20 秒取消预算和缓存提交失败处理见[自定义锁屏实现](platform-runtime.md#自定义锁屏)。透明缓存与流式合成的资源约束见[图片实现](platform-runtime.md#锁屏执行与资源)，不把历史设备样本作为完整 PW07 验收。

## 离线词典

设置的「阅读」页提供「离线词典」行，显示已启用数量。管理页每屏四套，显示元数据名称、启用状态或错误；提供启用／停用、上移／下移、重新扫描和返回设置。词典文件校验与索引缓存按需自动处理，不向用户显示准备按钮或准备状态。停用或缺失的词典不自动替换，保存失败保留旧生效设置。目录来源为卡根 `Dictionaries/`；重新扫描可取消，不在每次翻页时扫描。无词典时显示所需文件与目录说明，达到扫描上限时说明结果不完整。

EPUB／TXT 当前页文字长按后先显示选区，持续接触可跨行拖动，松手后提交一次查询。松手后保留选区画面，0.5 秒内有结果则直接显示释义，否则再显示读取面板（与 KOReader 的查词提示延迟相同）；查询与释义排版期间统一显示「正在查词，可关闭取消…」，不区分索引处理阶段。英文原词与有限屈折候选、中文包含触点的候选由 worker 查询；手动拖选只查精确选区，超出查询长度时保留选区并提示缩短。面板不提供修改选词按钮，正文首尾手柄仍允许调整端点并交叉；抓住手柄时保留手指与文字的偏移，避免跳到相邻行。选区预览期间 K1／K3 不翻正文，K2 保持全刷。图片长按保留查看入口；文字长按优先于文本链接跳转，普通链接点击保持原行为。桌面预览以右键按住并拖动模拟正文长按，左键拖动手柄，释放后查词。

释义使用 560 像素高的上／下方面板，顶部分别为 0／568；根据当前选区各行与两侧面板的重叠高度选择遮挡较少的一侧，相同时按初始触点位置决定。拖动时隐藏释义，最终范围、自动匹配后的选区、释义排版和绘制使用同一位置规则。选区使用反色文字、2 像素连接线与半径 8 像素圆形端点，端点热区保持 44 × 44 像素。正文边缘附近限制端点位置，完整输入序列与抓取偏移规则保持不变。

面板第一行显示命中词头与右侧关闭图标，第二行左侧显示词典名称，右侧依次显示上一词典图标、启用序号和下一词典图标；原词与命中词不同时，在无错误提示的说明行显示对应关系。来源导航使用空心双三角图标，按启用顺序直接查询同一选词的上一／下一词典，首尾对应图标置灰且不注册热区，不循环；在 worker 中按方向依次查询，跳过未收录或失败的来源，命中第一套有释义的词典即显示，不预查全部释义。该方向没有可显示结果时，已有释义则保留当前释义、页码和来源，没有可显示释义则反馈此次查询的具体失败；两者均置灰对应图标；新查询重置此状态。序号表示当前来源在已启用列表中的位置，不是命中结果总数。图标不带按钮框；来源图标热区为 88 × 72 像素，关闭热区为 96 × 72 像素，两者保留 28 px 横向和 20 px 纵向间隔。释义翻页和展开／收起仍在底部。点击词典名称区可打开每页最多五套的选择列表；取消或选择当前来源恢复原释义，选择其他来源只查询该词典，重试保持该范围。名称扫描在 worker 中按需执行，失败仍保留取消与管理入口。管理往返保留正文与选区，配置未改变时恢复原释义；配置改变时优先重新查询原来源，原来源已停用则使用首个启用来源。无词典状态提供「设置词典」入口。有可显示释义时不显示其他来源失败的总括警告；当前释义自身的缺字、字段省略和格式简化提示保留。全部无匹配时显示未找到词条；混合未匹配与来源失败时提示重试或检查词典设置，全部读取失败时保留具体错误。已知的来源格式／支持错误显示在管理页；明确重试、重新扫描或挂载变化后重新判断。

底部一行提供单箭头上一页、当前释义页码、单箭头下一页和展开／收起图标；展开／收起位于最右侧，与释义下一页热区保留 72 px 横向间隔。没有相邻页时图标置灰且不注册热区，不预先计算总页数。成功结果不常驻重试，错误提供重试；替换释义时清空旧分页游标，首屏排版成功前不能翻到下一页；存在多个词条时才显示查询结果编号与「下一词条」，每批最多 32 条，最后一批只有一条时仍可回到第一条。词条编号与释义正文中的编号义项分开。默认 K1／K3 在释义中只翻释义页、在来源列表中翻列表，K2 只全刷；加载期间保留关闭／取消，错误不会穿透到正文。

展开／收起以当前页解码后的 Unicode 标量位置作为锚点，在 worker 中重建布局；锚点前的最后一页允许提前结束，使新页从同一文字位置开始，全部先前释义仍可回翻。新布局、历史和页码仅在排版成功后提交，失败保留原布局和当前文字。全屏释义使用整屏，不显示正文统计页脚；关闭恢复原正文底图、阅读锚点和进度版本。完成休眠后唤醒回正文，不恢复词典临时状态。

基础释义支持字段分隔、段落、列表、强调及 Pango 的原始换行与空白；不加载外部图片、音频或脚本。未知实体保留原文并提示简化，格式错误与未收录分开；含不支持字段时保留可显示文本并说明不完整，没有支持字段时不能显示空白成功。

词头和词典名称使用当前正文字体，仍缺字时提示换字体；长标题单行省略，完整选词留在正文，不挤占导航与关闭热区。超过最近 128 页游标窗口后回翻从起点重放，不丢失早期释义。规划与后置范围见[词典计划](../planning/dictionary-plan.md)，真机拖选、慢卡、取消和资源峰值按 DICT 专项验收。

## 错误、返回与恢复

`error()` 弹出时按当前页面及入口标记记录来源，不以 `has_book()` 代替页面来源。正文类使用 `recover_body()` 恢复最后确认的位置；书库类回书库，保留当前文件夹和分页；设置类回设置首页，丢弃未保存的草稿。按钮分别显示「恢复阅读」「返回书库」「返回设置」，热区与位置沿用现有布局。存在未保存进度时，「重试保存」仍优先于打开书籍的「重试」，成功后按同一来源返回；设置首页的保存重试成功后留在设置首页。

正文来源必须存在可恢复的已呈现或已保存位置。新书首帧显示失败、尚无任何确认位置时，统一回退书库类，按钮写「返回书库」，不承诺恢复阅读；错误提示和实际返回保持一致。

屏幕整屏或局部更新失败时，只有正文类写「返回将恢复已确认位置」，书库类写「返回将回到书库」，设置类写「返回将回到设置首页」。异步保存失败、书签失败、`show_error()` 和移除 TF 卡均按错误实际弹出时的页面记录来源；错误页再次出错保留已记录的来源。网络收尾页复用 `network_return_view` 判定类别，「继续离线阅读」也按该类别返回，迟到的网络结果不改变返回后的页面或位置。

| Settings、WifiSettings、PowerSettings、StorageSettings、InputSettings、SyncSettings、TextEntry、LockScreens、About、Update | 设置 | 设置及配置子流程；Wi-Fi 和同步账户即使由其他入口打开，仍属于设置；键盘只编辑 Wi-Fi 或同步账户字段 |
| Loading | 沿用进入前的类别 | 开书/详情、章节、图片、排版预览、同步位置换算和锁屏图片列表在进入加载状态前捕获来源 |
| Error | 沿用弹出时的类别 | 再绘制、重试保存失败或错误画面刷新失败不覆盖来源 |
| Sleeping | 沿用休眠请求开始时的类别 | `prepare_sleep()` 在等待背景工作前固定目的地；正文类无书时回书库 |
| NetworkClosing | 沿用收尾前页面的类别 | 复用 `network_return_view`，账户验证收尾属于设置，正文同步收尾属于正文 |
| PowerMenu | 沿用菜单前页面的类别 | `power_return_view`；菜单取消仍恢复原画面和草稿 |
| PowerOff | 不适用（终态） | 关机、重启和更新安装的收尾状态；输入、休眠和最终刷屏失败均不会走通用返回。分类函数保留菜单来源作为兜底，不为终态新增退出路径 |

除引导保留当前屏外，休眠与错误共用来源判定。书库类唤醒后仍保留文件夹和分页，设置类回设置首页，正文类沿用原正文恢复路径；设置、使用说明、传输页即使尚未打开书，也不会因无书而改为回书库。锁屏准备失败、简洁屏保回退与页脚提示不改变已捕获的目的地；设置首页同样只局部显示一次回退提示，不带书库翻屏控件。终止状态和持卡状态的专用处理保留。

词典及由查词打开的管理页属于阅读来源，设置中的词典管理仍属于设置来源；返回查词保留正文与选区，休眠唤醒回正文，不恢复词典临时状态。对应生命周期见[架构](architecture.md)。
