# 界面实现说明

本文说明各页面的行为、状态与失败处理。产品取舍见[当前决定](../planning/decisions.md)，颜色、字体、线框、尺寸和组件外观见[设计系统](../design/system/README.md)，实现与验收状态见[开发状态](../development-status.md)。坐标、尺寸、阈值、文案和翻译以源码为准，本文不重复记录。

## 共通规则

画布为 684 × 1216 竖屏，黑白／灰阶、方角、实线，不使用虚线（D39）。可点击控件为实线框或黑底；不可用控件只显示淡色文字，不注册热区。单独的黑底按钮表示推荐操作，相连一组中的黑底表示当前项（D47），一屏最多一块黑底。删除、清除或替换写明动作，推荐项为「取消」。单选用圆点表示选中，保存状态用「当前」「待保存」文字表示，不再叠加外框。

顶栏左侧为「‹ 上一级名称」，后接粗体标题。「›」只用于进入子页的行，立即执行的动作使用按钮。多行文字不拆开英文单词、数字和路径，结束标点不置于行首。

界面文案遵守 [AGENTS.md](../../AGENTS.md#面向用户的说明) 的面向用户说明规则，存储介质统一称「TF 卡」。错误与空状态写清发生了什么、影响和下一步，只陈述已确认的原因；任务、锚点、字段和驱动原因码只写诊断日志；未分类错误不推断为文件损坏。版本、书名、时间、百分比和地址来自运行时数据。

提示使用页脚区，有多屏时暂时替代中央页码，下一次输入时清除。翻屏页脚的不可用方向留空。

阅读位置只显示「已保存」或「尚未保存」，依据 StoreAck；上传确认对应实际发送的 revision 与账户；显示忙碌来自显示事务。异步完成不等于已呈现，已呈现不等于已保存。

字体分工：书库中的书名、文件夹名、继续阅读信息，以及详情和管理确认中的内容文字使用全局阅读默认字体；书内目录、章节名、书签摘录和同步位置名称使用当前书实际使用的正文字体；菜单、按钮、状态、错误和帮助使用界面字体。所选字体缺字时显示空心方框，不逐字混用其他字体；书库字体无法打开时整段回退界面字体，保留用户偏好。单行文字在框内居中时按「中」字墨迹的垂直中心定位。

## 界面语言

首次开机引导和「设置 → 语言」提供简体中文、繁體中文和 English。点选后先保存全局配置，成功后切换并重画；失败保留原语言并允许重试。正文、原书目录、书名和用户文件名保持原文。引导、内置说明和 Wi-Fi 传书页使用所选语言。维护方法见[界面语言](localization.md)。

## 输入与刷新

K2 在所有可交互页面立即全刷当前画面，绕过像素相同优化，不关闭、取消、确认或退出传输（D03）。本文其余章节不再重复这条规则，只写例外。休眠准备期间忽略触摸和 K1/K2/K3，仅短按电源键取消，长按仍请求电源菜单，不重放忽略的输入（D43）。

| 上下文 | K1 / K3 |
|---|---|
| 正文 | 上一页 / 下一页；有脚注返回条时 K2 也不改成返回 |
| 书库、目录、书签、使用说明、释义与各类列表 | 上一屏 / 下一屏 |
| 工具、排版、确认、键盘 | 不操作背后页面 |
| 传输 | 按当前传输模式的可用项 |
| 休眠 | 由实际唤醒源决定，不假设 K2 可唤醒 |

正文左／中／右点按分别为上一页、打开工具、下一页。可翻页的上下文支持左滑向后、右滑向前；判定规则见 [D51](../planning/decisions.md#1-已确认的产品意图) 和 IN09。书库条目、「继续阅读」卡片和正文图片按住达到长按阈值即进入详情或查看，松手不再点击（D22）；文字长按进入查词。K1/K2/K3 没有长按动作。

一个输入序列只有一个消费者，打开、关闭和唤醒后的尾部事件不能穿透。刷新中的重复 K2 忽略；连续翻页最多保留一次后续翻页（D14）；屏幕键盘有单独的有序输入规则。忙碌时只保留当前状态实际允许的取消或返回入口。

### 非正文刷新

非正文页面的普通更新和页脚、进度、补图、键盘等局部更新，在显示基准有效时只驱动变化的像素；不改变扫描时序或刷新档位，也不承诺刷新时间随变化面积缩短。K2、基准失效、刷新失败后的恢复和二维码首次出现完整清屏。页脚更新和补图不推进正文位置或修订。

### 翻页效果

正文提供「关闭」「水波纹」「斜掠」「随点按位置」，默认关闭，不持久化。水波纹沿翻页方向横向展开；斜掠从翻页方向一侧的下角展开；「随点按位置」按点按高度选择上角斜掠、横向平扫或下角斜掠，回翻左右镜像，轻扫取按下时的高度，按键翻页平扫。效果只在普通正文刷新中播放，使用八灰阶波形；清晰档、K2、自动全刷和失败恢复仍完整刷新。

效果只改变显示过程：最终页面成功呈现后才推进位置和保存，中间帧不算已呈现。连续翻页可跳过剩余效果帧直接显示目标页。

## 书库与管理

文件夹排在书前面，降序时也是；条目状态为「文件夹」、百分比、「在读」或「未读」（D24）。绘制文件夹不扫描子目录计数。点书打开，长按进入详情。卡片和列表视图共用封面缩略图缓存；全白缩略图按无封面处理，写书名。

「继续阅读」卡片只在书库首页和多扫描根的根文件夹显示，且仅当有可继续的书。单一扫描根的内容直接显示在书库首页。排序在「最近阅读 / 书名升序 / 书名降序」间切换，写入全局设置成功后才采用；最近阅读首页不重复列出继续阅读中的书。历史文件不可读时本次扫描回退书名顺序并标明回退，不改写偏好。进度状态只为可见条目延迟读取。日期按 UTC+8 显示，未校时、未知及未来日期只显示进度。

「设置 → 书库 → 书库文件夹」可选置顶或「跟随最近」；后者按已记录的打开活动排序，不再次查询历史路径的文件状态，打开书籍时仍执行路径安全检查。

封面按 EPUB 3 `cover-image`、EPUB 2 `meta name="cover"`、guide 封面页依次查找，无声明时只接受第一个 spine 的单图片页。只处理当前屏可见的封面；输入大小、缓存容量和重试次数均有上限。暂时读取失败、内存不足或任务启动失败不记为无封面，按上限间隔重试；达到上限后提示可继续阅读，切换页面、视图或重新进入书库后再试。

详情不改变阅读会话。管理入口提供清除本地进度和删除原书，确认页写明书名与路径；删除保留伴随记录，清进度不修改远端，也不能被旧备份或 outbox 恢复。缓存清理只在「设置 → 存储」整体进行。文件范围与提交协议见[存储约定](storage.md)。

目录扫描区分正常结束、达到条目上限、部分读取失败和目录不可用：部分失败保留已读条目并提示列表可能不完整；没有可用条目时显示读取失败和「重试」，不显示为空目录。

默认书库 `Books/` 不存在时由 store 创建；自定义扫描根不自动创建，不存在时指出 `PicoPage/settings.toml` 的 `library.roots`。创建失败时，只有确认可用空间为 0 才说「已满」；FatFs 的 EACCES 同时可能表示写保护和满卡，未确认时按可能只读说明。

TF 卡不可用时按原因区分：启动时未检测到卡、无可识别文件系统、挂载失败、运行中拔卡；都提示重启并提供电源菜单入口，因为重新插卡后需要重启才能挂载。运行中拔卡时，书库直接显示该状态，其他页面先显示错误页并说明最近位置是否未保存，不提供无法成功的重试保存。

### 空书库

书库根目录没有书且没有继续阅读卡片时，显示三种放书方式：「USB 连接电脑」直接请求 USB 传输，「Wi-Fi 传书」直接请求热点传书，「直接放入 TF 卡」只是说明。下方可打开使用说明第 1 屏，说明页返回书库。从书库发起的 USB 或热点未启动、或 Wi-Fi 已关闭时，进入「网络与传输」页显示原因，左上角返回书库。

## 阅读、目录与书签

阅读工具顶栏显示章节名、书名与已读进度、时间与电量；打开或重绘时读取时间与电量快照。工具栏的「刷新模式」只打开刷新面板，不等于全刷。点工具栏以外的正文区收起工具。

目录中当前章节反白并标明当前位置，其他条目显示章起点的全书百分比；子条目在该章加载前不显示百分比；页数未知时按章节大小估算。标题最多两行，超出以省略号收尾，不覆盖相邻条目和控件。每屏按完整条目分页；剩余高度不足一行时平均分给本屏各行，末行贴住页脚。

### 快速跳转

目录面板的「目录 / 书签」左对齐排列；在目录标签下，点右侧的「快速跳转 ›」。子页在原面板内打开，显示目录总项数。「按目录序号」输入从 1 开始的目录序号，序言和卷标题也计入序号；预览显示目标标题、章节起点的全书进度和相隔项数。「按百分比」输入 0 至 100，按全书进度定位，预览显示目标所在的目录项。

没有目录时，目录空态说明可用「快速跳转」按全书进度定位，子页只提供百分比方式，不显示方式切换和「在目录中查看」。TXT 按原文的字节位置估算。EPUB 按顺序阅读的内容估算，已有完整页数时取阅读进度达到输入百分比的最早一页。目标所在的目录项按资源文件或 TXT 标题位置估计。

点「−」或「+」可微调 1。输入为空时，微调从当前位置开始。超出范围时，输入框标出可输入的范围，「−」或「+」直接回到最近的有效值。点「在目录中查看」会展开目标的上级目录并翻到目标所在屏。目标以左侧粗线和「目标」标出，当前目录项保留「当前」样式。翻屏、切换标签或收起面板会清除目标标记。

点「跳到此章」或「跳到此位置」会收起面板。能确认目标就是当前位置时，显示「已在当前位置」。按字节位置估算时，加载正文后再确认源位置，重合时沿用原有返回状态。目标页成功显示后，才按正文进度规则保存。可点正文顶部的「返回原位置」撤回，下一次成功翻页后返回条消失。

跳转子页忽略 K1、K3 和左右轻扫。开始输入后，刷新期间点按的数字、清空和退格按顺序执行。跳转和返回等操作需要在界面刷新后点按。关闭子页、切换标签、收起面板、进入休眠或切书时，清除输入草稿。

### 书签

工具顶栏右侧的书签开关直接添加或删除当前页书签，不另设确认。正文页有书签时在右上角页边显示角标。目录面板可切换「目录 / 书签」，切换状态保留到打开另一本书。书签列表显示章节名、创建时的百分比和页首摘要；书签文件损坏、版本较新或属于另一份内容时只显示原因，不提供跳转。

书签提交期间，进入需要读卡的页面前先处理提交结果；失败显示错误页并停止后续操作。文件被外部修改后重新读取并提示核对，避免再次点击反向执行已完成的操作。

### 正文图片与等待反馈

正文图片按 D36 渐进显示：先呈现文字和占位，首次开书的正文帧刷新成功后即可准备图片，后续翻页须短暂停留后才准备；仍在原页时局部补图。空闲时不预先准备下一页图片。翻页取消旧请求，旧结果不覆盖新页，补图不改变进度。缺图、解码失败或内存不足只在图片区域提示，不阻止阅读其余正文。

图片查看页可在原图和三档增强对比度间循环，每次打开从原图开始，不改变阅读位置。

跨章或跨分段时暂留原画面；短时间内完成则直接显示目标页，超时后在 worker 检查点暂停，显示一次等待提示与取消控件再继续。提示出现前没有隐藏的取消热区。目标页呈现失败不推进进度。开书和生成封面使用阶段提示，不做动画或进度轮询。资源与取消边界见[架构](architecture.md)。

### 阅读页脚

左侧在全书页码/总页数、全书百分比、章节序号/总章节数、当前章节名和「不显示」之间循环，默认页码。章节名与顶栏一致，缺失时显示「第 N 章」，过长单行省略且不覆盖右侧。页数统计未完成时页码模式显示统计状态，百分比按章节大小估算并取整；统计完成后显示两位小数。

右侧在电量、时钟和「不显示」之间循环，默认电量。时钟按 UTC+8 显示，系统时间不可用时显示「—」；启动时可从已校准的 PMU RTC 恢复，联网收到真实 NTP 回包后写回 RTC。切换到时钟不联网、不定时刷新，翻页或重画页脚时更新。

左右热区以页脚内的固定分界划分；跨越左右或正文/页脚边界的接触忽略。隐藏时保留热区和留白，不扩展正文区域。两侧模式只在当前会话内保留，切换不改位置、不写文件。页脚通知优先显示在左侧。

电量图标用五格表示大致余量，不显示百分比，不代表续航或已校准读数。没有有效读数且未充电时隐藏图标；PMU 报告正在充电时显示闪电，不以连接 USB 或电量满推断充电。充电状态变化后，只在阅读页空闲时局部更新页脚；有输入、刷新、加载、图片查看或休眠准备时延后，不新增定时器、弹窗或唤醒。

正文普通更新保持页脚中未变化的像素；临时缓冲分配失败时本次停用保持，照常刷新。页码对应当前排版中首个可见字符所在页，跳转后连续翻页可能重复或跳过页码；页数未知不阻塞正文；改排版后重新统计。长章节按分段读取，见[文档后端](document-runtime.md)与[图形排版](graphics-runtime.md)。

## 排版与字体

排版面板由收起条、工具标签、样式选择、参数卡片和底部两键组成。可调参数在卡片上直接「−」「+」，到达边界的一侧不可用；「字体」卡片进入字体选择；「全屏阅读」「对齐」卡片点按切换。底部左为「设为阅读默认」，右为主按钮：有可应用的改动时为黑底「应用到此书」，没有改动时为「完成」，预览无法应用时不可用。有草稿时「收起」换为「放弃修改」。超出界面步进范围但合法的文件配置仍可读取。字重能力见[图形运行说明](graphics-runtime.md)。

预览按真实正文页排版，面板覆盖页面下部；被面板切开的文字行整行隐藏，图片保持原尺寸和位置，不为面板重新分页。草稿与当前排版相同时直接沿用已绘制的正文像素，只刷新面板；改动参数后才重新排版预览。

预览只改草稿。「应用到此书」优先准备当前位置，从页首源锚点重新分页；取消不写文件。「使用阅读默认」删除本书覆盖，不等于恢复出厂设置；「设为阅读默认」只保存已确认有效的参数，影响继承默认的书，不覆盖已有单书设置；无效字体不能设为默认。切换样式后须先应用到本书，才能设为阅读默认。

EPUB 提供「原书排版」「统一排版」，TXT 提供「保留换行」「重排段落」。缺少设置时全屏开启，EPUB 使用原书排版，TXT 保留换行。原书模式可调字体、字号、页边距、全屏和字重（稍细 / 按原书 / 稍粗），行距、段距和首行缩进按原书；统一排版和 TXT 另有对齐（左对齐 / 两端对齐）。保存默认值时只写当前样式对应的参数，保留另一种样式的全局值；恢复默认保留本书的 EPUB 样式。

全屏正文使用原页脚区域，原页脚热区按正文分区处理。正文后面还有内容而剩余高度放不下下一行时，把余量均分到行间和图片间距，末行落在底部留白处；分页位置不变，章末页不拉伸。书签状态变化或出血图片补绘后重画书签标记。休眠准备等必要提示可临时覆盖底部，取消后恢复原像素。

### 分页字体选择

字体选择属于排版上下文：上方为基于当前位置和草稿的预览，下方为分屏字体列表。圆点标出正在试看的字体，「当前使用」标出进入排版时已应用的字体，两者互不替代。每次打开定位到草稿字体所在屏。翻屏只重绘列表，不加载字体、不重新排版、不启动图片任务；点选其他字体才更新预览，并将字重重置为常规。列表复用已有的 `Fonts/` 扫描结果。

「取消」在图片预览加载期间仍可用，恢复进入前的字体、字重及恢复默认意图，保留其他草稿，不自动重启已取消的准备任务。「选用此字体」只回到排版面板，不写配置。所选字体不可用时显示替代预览说明并禁用「选用此字体」。

## 设置、使用说明与关于

设置首页列出网络与传输、KOReader 同步、语言、阅读、书库、电源与休眠、存储，每行标题下显示当前摘要；其下为固件更新、使用说明和关于。固件更新行显示检查状态，设备分区与固件不匹配时显示需要重装。

- 阅读页：全局默认排版（通过当前打开的书预览，没有打开的书时不可用）、刷新档位、自动全刷间隔、翻页效果、立即全刷和离线词典。
- 书库页：默认视图和书库文件夹策略，成功提交后才生效，失败时说明仍生效的值。
- 存储页：分别显示书籍原文件、缓存与可用空间，读取失败或条目超过上限时显示「未知」。「清理全部缓存」保留书籍、设置和进度；统计和清理由内容 worker 执行，可取消，取消后提示部分缓存可能已删除；旧任务交还文件后才允许后续文件任务。

设置页保存失败时，整条页脚变为重试入口，保存成功后恢复。

### 使用说明

使用说明可从设置或空书库进入，每次从第 1 屏开始，返回来源页面。离线、无 TF 卡或无用户字体时可读，不新建文件。内容随固件维护，覆盖按键、触摸、书签、页脚、传书、联网、接续、休眠与更新。演示区域只改变帮助状态，不修改正文、书签或配置；满屏示例使用与正文相同的热区边界和页脚轮换顺序，演示值明确标为示例。

### 首次开机引导

引导依次为语言选择、欢迎、阅读练习和工具栏说明，结束或跳过后进入书库，空书库负责说明放书。没有联网、账户或授权步骤，不生成示例书。使用说明第 1 屏可重新观看。

语言页选择后先保存再切换，失败保留原语言并可重试；点击当前项和排队的旧输入不触发保存。练习是不依赖书籍的模拟阅读页，任务依次为翻到下一页、翻回上一页、打开工具栏、收起工具栏，分区、按键和轻扫与正文一致；在最后一页继续往后翻也进入下一步，只用按键也能走完。练习不读写书籍、位置或同步。

首次判定在应用初始化、打开字体前进行。`PicoPage/settings.toml` 的 `[onboarding].done = true` 只在完成或跳过时通过 store 提交；首次保存语言时写入 `in_progress = true`，该标记有效且未完成时重启后从语言页继续。除此之外，存在任一旧设置、网络或同步配置、最近阅读记录（含备份）或书旁进度／单书配置即免引导，损坏文件也算旧用户证据。识别书旁记录只读 `Books/` 目录元数据，扫描范围有上限，出错或超限时保守免引导。写入失败照常进入书库，下次仍可引导。已有更新结果提示优先于引导。

重看从语言选择开始，结束入口改为返回使用说明，不读写完成标记。引导中休眠保留步骤与练习状态；错误返回时首次来源回书库，重看来源回使用说明。

### 关于

显示产品名、运行时版本与硬件、作者、官网及二维码，以及许可说明；版本和硬件只在本页显示。

## Wi-Fi、键盘与同步

Wi-Fi 密码和同步账户在设备键盘输入（D37）。默认允许无线不等于开机联网，已保存 SSID 不表示在线。连接、扫描与验证由 worker 执行，输入和绘制回调不等待网络。

### Wi-Fi 页

- 首页显示连接状态和连接方式，提供开关、连接方式、已保存网络、添加网络，以及按状态二选一的「立即连接」或「断开」；Wi-Fi 关闭时只留开关。
- 连接方式为单选列表（自动或指定某个已保存网络），点选立即生效。
- 已保存网络可更新密码或忘记；忘记指定网络时提示将改回自动。
- 添加网络进入时扫描一次附近的 2.4 GHz 网络，开放网络直接连接，其余进入密码页；也可手动输入名称。已保存数量达到上限时只能更新已有网络。
- 连接中只能取消，取消后保留已输入内容。失败页写原因并说明网络没有保存；已连上但写入 `network.toml` 失败时说明已连上但下次开机不会自动连接，不写「无法连接」。

首页底部显示当前时间（UTC+8）和「校准」。Wi-Fi 关闭、无已保存网络或其他无线任务运行时校准不可用。校准可取消，返回和关闭 Wi-Fi 也会取消，取消后等待 worker 交还。校准成功表示已应用新的 SNTP 时间，随后写入 RTC 与 TF 卡。

### 屏幕键盘

- 字母、数字与符号、其余符号三层，覆盖全部可打印 ASCII；「大写」只作用于下一个字母；网址键盘提供常用网址片段。
- 回车键文字随场景变化，条件不满足时不可用（如 Wi-Fi 密码长度无效或名称为空）。
- 输入只刷新输入区，切换层只刷新键盘区，两者变化时一起刷新。按键没有按下反色。
- 字符键只改内存中的内容，在下一个空闲点一次画出。刷新期间的点按全部保留并按顺序执行，排队的回车也执行，其他排队控件忽略（`ReaderApp::keyboard_visible()`）。按键按当前输入内容判断，不按已画出的控件判断。
- 点按滑出按键则不输入。普通按键的命中区域延伸到键间隙中线。大小写和键盘层切换键的纵向命中范围与显示边界一致。退格删除一个完整字符。
- 密码默认明文，可隐藏或清空；超出输入框时显示末尾。草稿只在本次流程内保留，离开、休眠或保存成功后清除，不写入存储。

### KOReader 同步账户

「设置 → KOReader 同步」编辑服务地址、账户和密码。账户和密码都具备时可验证并保存；已保存且未修改时为「重新验证」，沿用已保存的密钥。状态区分未保存、已保存、已验证和验证未通过：文件里有账户只表示已保存，本次验证通过后才算已验证。只有服务器接受时才写 `sync.toml`；验证失败或取消时说明原账户是否保留。移除账户需要确认。有打开的 EPUB 时提供该书的同步入口。

### 同步面板

同步面板分「阅读进度」和「校准时间」两个模式：已配置账户的 EPUB 默认进入阅读进度，TXT 和未配置账户的 EPUB 默认进入校准时间；从 Wi-Fi 设置返回时恢复原模式。网络卡显示无线许可、已保存网络或连接方式。

- 阅读进度并排显示本机与远端位置。检查、再次检查和继续阅读在主按钮，上传等辅助操作在另一侧，避免再次点检查触发上传。
- 校准时间显示当前时间与上次实际应用的校准时间；时钟不可用或早于记录时显示记录的时间和提示。
- 检查、上传或校准期间只保留取消；离开面板、切换页签或休眠也会请求取消，并等待 worker 交还。
- 两端位置不同时，结果只显示在面板内，两张卡片分别提供「留在这里」和「跳到这里」，更靠后的一张标出。前后关系按远端位置映射后的章节、分段和段内偏移与本机当前页比较，不用服务器记录的百分比；远端无法映射时只显示服务器记录的约略百分比，不判断前后。
- 上传前确认：远端无记录时询问上传；远端有位置时写出两端位置，默认按钮为「取消」。
- 远端位置所在章节超出精确映射范围时，明确写出原因以及「没有跳转」或「没有上传」，不自动使用附近位置，不笼统归因于版本不同；兼容边界见[同步实现](sync-runtime.md#精确映射与明确拒绝)。
- 账户被拒时引导到账户设置；未设置账户、Wi-Fi 关闭和 TXT 都在面板内说明。指定网络连不上时说明没有改连其他网络，并提供本次改用自动。

整次查询与上传使用同一会话，等待用户选择有时限，超时后上传前先重新查询。上传取消或失败时提示结果未知；取消检查时提示本机位置没有改动。等待画面不随联网阶段反复刷新。位置准备任务创建失败时留在面板，允许重试或继续阅读，不改位置也不自动上传。

跳到远端后提供「返回原位置」，成功翻页后才清除；取消、呈现失败和 K2 保留已确认状态。

## USB 与 Wi-Fi 传书

传书入口在「设置 → 网络与传输」和空书库。USB 进入前先成功呈现准备画面、保存并交还 TF 卡，传输期间由电脑独占；准备失败按实际原因提示。开启后只说明传输已开启，不声称电脑正在使用；退出须在屏幕上确认并重启。见[USB 文件传输](usb-storage-runtime.md)。

Wi-Fi 传书支持设备热点和已保存网络两种方式，见[传书说明](../user/wifi-transfer.md)。会话页只显示本次地址和真实结果，二维码首次出现全刷，之后状态局刷；只有提交并回读成功才计数。传书中查看 Wi-Fi 状态不结束服务；更改许可或目标前先结束会话，收尾由 worker 确认。热点退出不自动恢复 STA。

## 固件更新

设备流程、来源验证、安装条件、取消时限和回滚见[固件更新实现](platform-runtime.md#固件更新)。

- 设备分区与固件不匹配时，引导备份 TF 卡并通过官网完整重装。
- 首页：无可安装版本时只提供检查；有可安装版本时显示更新日志摘录、完整日志入口、重新检查和下载安装。安装条件不满足时按钮为淡色但仍可点按，点按后重新判断并说明原因。
- 缓存清单只代表上次成功检查的结果；新一次检查失败时保留旧清单并显示失败原因，不把缓存描述为当前最新，也不记录当时与本机版本的比较。
- 检查过程按 Wi-Fi、互联网、更新服务器三步显示，失败时标出失败的一步并只陈述实际失败的原因（如没有取得网络时间、无法解析域名、HTTP 状态码），按钮按失败步骤给出 Wi-Fi 设置或重新检查。
- 更新日志支持标题、圆点列表和粗体，其他 Markdown 按纯文字显示；按块分屏，每屏都有下载安装入口。
- 清单中的进度或设置格式高于本机时，下载前须确认；取消确认不发起下载。
- 下载时只能取消，按固定进度间隔局部刷新；检查和下载期间电源键短按不响应。容量不足和不兼容只能返回，其他失败可重试。
- 校验通过后可重启安装或稍后（重启后需重新下载）；安装成功后首次开机显示版本和更新日志并回到书库，回滚到旧版本时在书库提示一次。

## 电源与休眠

休眠请求被接受后，先在原页页脚显示一次准备提示，提示刷新完成后再结束网络、保存进度、交还后台资源并准备休眠画面；不增加倒计时或进度刷新。准备期间只有短按电源键可以取消，长按电源键在页脚恢复和资源交还后打开电源菜单（D43）。真正无法准备时使用简洁屏保，唤醒后在页脚提示一次，不弹错误页；资源不足时可省略准备提示。

电源菜单提供关机、重启和取消。完整点按同一控件才执行，滑出即取消；菜单出现前的旧触摸不能触发按钮。选择后直接保存本地位置，不等待云同步；只有本地保存失败时提供「仍然关机／重启」或返回。最终画面不证明物理断电，见[平台实现](platform-runtime.md#电源键菜单与关机重启)。

休眠画面在书籍封面、保留正文、简洁屏保和自定义图片中选择，选择只改草稿，通过「保存设置」提交。「书籍封面」模式下，从正文及阅读工具休眠时显示当前书的封面，无封面时显示书名和作者；从其他页面休眠时显示内置书库插画。封面锁屏显示休眠和唤醒提示，电量低且未充电时提示充电；使用书籍封面时另显示当前章节名、已读进度，只有当前已保存进度已确认上传时才显示「已同步到云端」。

### 自定义锁屏

自定义图片可指定一张或按文件名轮播，并可开启「叠加当前画面」：开启后透明区域保留休眠前的画面，正文底图去掉整条阅读页脚；关闭时透明区域为白色。不透明图片保持完整白底。预览使用进入前画面的副本，不提交设置、不推进轮播；休眠准备提示不得进入最终底图，合成画面不保存到 TF 卡。文件限制、取消时限、缓存与资源约束见[自定义锁屏实现](platform-runtime.md#自定义锁屏)。

## 离线词典

「设置 → 阅读 → 离线词典」管理 `Dictionaries/` 中的词典：启用／停用、调整顺序和重新扫描。词典校验与索引按需自动处理，不向用户显示准备步骤。停用或缺失的词典不自动替换，保存失败保留旧设置。重新扫描可取消，翻页时不扫描。无词典或达到扫描上限时说明原因。

正文长按文字后显示选区，持续接触可跨行拖动，松手后查询一次。结果在短延迟内返回则直接显示，否则显示读取面板，耗时较长时说明首次使用可能需要建立索引；只按耗时切换一次提示。自动选词由 worker 匹配英文屈折候选或包含触点的中文候选；手动拖选只查精确选区，超出查询长度时提示缩短。端点手柄可拖动并交叉，抓取时保留手指偏移。文字长按优先于链接跳转；图片长按保留查看。

释义面板放在选区上方或下方空间较大的一侧，切到正文行时让出整行；两侧都不够时使用固定高度的上或下面板，选择遮挡选区较少的一侧。拖动时隐藏释义。面板底部为三行相连按钮表（D48）：范围调整、词典来源、释义翻页；不可用格保留位置但不注册热区。

- 范围格每次移动选区一端：英文点按按词、长按按字符，其他文字按字；不在端点保留空格和标点；字符类别按 Unicode 判断。因边界或查询长度上限无法调整时置灰。每次调整立即重新查询并重置来源导航。
- 来源导航按启用顺序向前或向后查询同一选词，跳过未收录或失败的来源，命中第一套有释义的词典即显示，不循环、不预查全部；该方向没有结果时保留当前释义并置灰。序号表示当前来源在可用来源中的位置，不是命中总数。点击词典名称可直接选择来源。
- 翻页按需排版，不预算总页数；同一词典中同名词头有多个条目时才提供「下一条」。出错时中间格变为重试。展开／收起以当前页的 Unicode 标量位置为锚点重建布局，成功后才提交；早期释义仍可回翻。

释义支持字段分隔、段落、列表、强调和原始换行，不加载外部图片、音频或脚本；含不支持内容时保留可显示文本并说明不完整，格式错误与未收录分开提示。查词及由查词打开的管理页属于正文来源；返回查词保留正文与选区，休眠唤醒回正文，不恢复词典临时状态。后续范围见[路线图 R15](../planning/roadmap.md#r15--离线词典与正文取词)。

## 错误、返回与恢复

字体相关失败显示具体原因和稳定编号 F00–F12，便于从用户截图区分；字体库提供原始错误码时附加 `[FT=N]`，涉及具体字符时附加 `[U+XXXX]`。编号与原因的对应见 `firmware/components/reader_app/font_error_message.h`。编号只描述已观察到的失败，不根据连续翻页推断内存不足。

错误页、休眠和网络收尾按弹出时的页面记录来源，分为正文、书库和设置三类，映射见 `ReaderApp::Impl::origin_for()`；不以是否打开了书代替页面来源。正文类恢复最后确认的位置，没有任何已呈现或已保存位置时改按书库类处理；书库类回书库并保留文件夹和分页；设置类回设置首页并丢弃未保存草稿。存在未保存进度时，「重试保存」优先于「重试」。错误页再次出错保留原来源，迟到的网络结果不改变返回后的页面或位置。休眠与错误共用来源判定，引导例外地保留当前屏。

## TXT 目录

TXT 使用正文工具栏的目录面板。识别到章节标题时显示平铺列表，首个标题之前显示「正文」，工具顶栏、章节页脚和新建书签跟随当前标题；未选项百分比按标题字节位置估计，点击标题从该处开始阅读。未识别到章节标题时，目录面板提供百分比跳转，正文仍以「正文」作为章节名。选中目录项并成功呈现正文后才保存新位置。识别规则与资源上限见[文档后端](document-runtime.md)。
