## 独立程序测量

使用 Read Pico 的 ESP32-S3、ESP-IDF 6.1 `fff9895c`、Xtensa GCC 15.2.0，配置 CPU 240 MHz、八线 80 MHz PSRAM、1,000 Hz tick。任务栈 32,768 字节、优先级 1，与现有内容 worker 一致。程序在每个样本的每次重复中重新构造样式表，CSS 原文和元素字段从 Flash 映射读取。每本书选择关联 CSS 最大的一个文档并取至多 256 个元素，保留父元素和行内声明。计算上下文为初始及根字号 16 CSS px、包含块宽度 600 CSS px。
