# 2026-11-01 · TXT 目录、自动全刷与连续翻页验证

## 结论与安装状态

本地分支 `feat/txt-toc-refresh-controls` 已实现均衡／快速自动全刷间隔 0–30（0 表示关闭），快速缺省值从 15 提高至 30；已有配置保持原值。TXT 目录识别四种既有编码的常见章节短标题，沿用现有目录和源位置，并补齐当前章节名称／序号。发现并修复了重复回翻挤出不同页边界历史、使非标准分页入口返回位置发生偏移的问题。

候选与最终固件合计 **5,190 次计分真机翻页**：长篇前进 **3,500 页**，经过 **166 个识别标题，其中 158 个正文章标题**；200 页回退及重新前进准确往返；最终干净固件另完成不主动停留的 500 页前进／500 页回退，并准确回到同一保存锚点。没有观察到新的错误页、崩溃、意外重启、显示失败、命令超时或队列溢出。

设备最终安装 `0.5.0+gbcd5f46` Diagnostic，应用 3,975,872 字节，来源提交 `bcd5f46ef734d9a11ccaa939158d2d61cb9e3162`。设备串号 `14:C1:9F:D1:7D:38`，实测为 `factory` 单应用槽 `0x10000/0x400000`；仅写应用槽，写入摘要与独立 `verify-flash` 通过，写前／写后前 64 KiB 逐字节一致。重启后 TF、工厂 VCOM 加载和应用帧正常，打开原书准确恢复到压力测试末位置。未发布或推送。

## 场景与判定

| 场景 | 实际结果 |
|---|---|
| UTF-8、GB18030、UTF-16LE／BE 自动目录 | 中文／英文／非 BMP 标题、跨 48 KiB 边界标题、目录点击的段内标量锚点与 host 独立核对一致；各 8 页前进／8 页回退及重开通过，共 64 次 |
| 非标准入口 40 页前进／40 页回退 | 修复前 app 回归稳定失败；修复后逐页锚点回归及真机最终锚点往返通过，共 80 次 |
| 真实长篇 3,500 页前进 | 每页均确认正文帧成功；每 100 页短暂停留核对保存锚点，按原书标题与分段定位；穿过 158 个正文章标题 |
| 回退 200 页后再前进 200 页 | 回退末位置匹配原第 3,300 页检查点，重新前进后匹配第 3,500 页检查点，共 400 次 |
| 快速模式间隔 0 | 70 页前进／70 页回退，共 140 次；定期全刷未触发，往返锚点一致，K2 仍全刷 |

| 最终固件章节序号页脚启用，500 页前进／500 页回退 | 两段均不主动等待停留保存；逐页确认刷新完成，1000 次后保存锚点与起点一致，K2 不改位置 |
| 最终固件重启与切书恢复 | 安装重启后打开原书、切至合成 TXT 后再返回，均恢复同一已保存源锚点；原书长度／CRC 不变 |
| 最终目录与当前章节显示 | 目录当前行、中文章节、英文重音标题与工具顶栏正确；真实样本顶栏与原书对应标题一致 |
