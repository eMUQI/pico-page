# EPUB CSS 解析与层叠原型

本说明对应 [Issue #108](https://github.com/eMUQI/pico-page/issues/108) 的 A 阶段独立原型。A 阶段的代码独立于阅读路径，实书统计、独立程序实测和阅读余量见[本批报告](baselines/2026-11-04-css-prototype.md)。原生接入试验的行为和限制见下节。

## 原生阅读接入试验

EPUB 的排版面板可按单书预览并应用「原书」。没有单书覆盖时沿用自定义排版。原书模式用现有正文及页数统计入口解析当前 XHTML，读取正文前关联的包内样式表和 `style` 元素，按源顺序追加到同一张表。正文元素的行内声明参与层叠。链接只接受适用的普通样式表及空、`all`、`screen` 媒体值。正文开始后出现的样式表、外部 URL 和除顶层 `@font-face` 之外的 at-rule 跳过。

样式规则、行内样式及 `@font-face` 描述中的不支持 at-rule 按独立语句或完整块跳过，再继续解析后续声明；不执行块内样式。跳过过程沿用扫描器的层级、取消和工作量限制。原书章节缓存及页数索引已更新版本，旧版结果需要重新解析和计数，阅读位置仍使用已保存的源锚点。

作者样式控制块及行内字号、行高、缩进、对齐、留白、可见性、粗体、斜体、下划线、基础分页提示、图片盒宽度和图片出血。字号以 16 CSS px 为基准，排版时统一按用户字号缩放。盒模型百分比按当前可用宽度解析，留白和字号受可读宽度及页高限制。行高按作者值排版，可小于字体自身的上下高度，但不小于该行最大字号。块内 `<br>` 只换行，不重复块的边距和首行缩进。

图片宽度与最大宽度支持 px、pt、em、rem 和百分比。原书分段解析时读取包内 PNG、GIF 和 JPEG 头部的像素尺寸，每张最多解压 64 KiB，单图章节不读取；同一本书打开期间按图片路径记住已读尺寸，尺寸随章节缓存保存；图文混排的图片按该宽高比确定盒高，从块顶开始放置，超出本页剩余高度时移到下一页，位于页首时缩小到可用高度。图片缺失或头部无效时沿用固定高度的盒子；头部读取遇到内存不足或 TF 读取错误时本次分段加载失败，不缓存降级版式。单图章节仍占满正文区。`duokan-bleed`、`qrbleed` 和 `bleed` 按值中的 top、right、bottom、left 记录出血方向并向子元素继承，只作用于图片：左右出血时盒子扩展到屏幕边缘；上出血仅在全屏阅读、图片位于页首时使图片从屏幕顶边开始，非全屏的顶部区域保留给书签标记。当前使用平面块布局，连续块的边距各自生效，嵌套盒布局和完整分页约束仍待实现。灰阶装饰、正文后的样式表和 `@import` 尚待支持。

原书模式解析 `font-family` 及顶层 `@font-face`。每张层叠表最多登记四个包内常规 TTF／OTF 字体，每份最多 2 MiB。按样式表所在资源解析相对地址，选择首个存在且符合范围的本地 `src`，跳过外部 URL、混淆字体、字体集合、带独立字重或斜体描述的字体及 `unicode-range`。CSS 的粗体和斜体仍使用既有合成规则。只准备当前分段可见文本引用的字体。逐字尝试 CSS 字体族列表、用户正文字体及既有缺字占位。分页计算记录实际字形选择，绘制和预取使用同一选择及字宽。

内容任务以 ZIP CRC 校验解压并写入 TF 卡上的可重建字体副本。FreeType 从副本随机读取，排版和绘制期间每组字体共用一个读取句柄，操作结束时交还。缓存损坏时从 EPUB 重建。字体暂时不可读时仍可用用户字体阅读，本次回退的页数不作为可信统计。[FreeType 流接口](https://freetype.org/freetype2/docs/reference/ft2-system_interface.html)

原书模式保留 XML 资源、节点编号及源偏移，隐藏内容仍可定位。恢复时优先选当前分段中其后的可见位置，其后无正文时回到本段最近的可见文本范围。全段无可见内容或资源、规则、匹配及样式数超过限制时回到基本排版并提示，整书统计中止。切换预览由现有内容任务读取目标模式下的源位置，完成后才可应用。放弃预览沿用已确认画面和进度。同步位置换算仍走独立的 Mapping 路径。

固件同一时间只准备一张层叠表。试验工作集按 512 KiB PSRAM 核算，最多 184 KiB CSS 原文、48 个来源、64 层祖先、32 KiB 祖先名称，以及每段 256 个唯一计算样式。预算计入四个可同时存活的分段样式列表、字体描述和分配余量。规则匹配每至多 64 个元素开启新批次，工作量先达到阈值时提前分批，既有内容任务负责取消和完成发布。ZIP 解压、字体表、正文、字形和图像各自按资源余量准入。单次 TF 读取与解压调用之间才可检查取消，实测间隔不能外推为时限。

原书模式使用独立版本的持久缓存。章节缓存按原书摘要、书脊项和分段记录正文、源锚点、计算样式及包内字体描述，单条载荷最多 2 MiB。前台取得的有效分段通过既有空闲任务写入，页数统计可以读入缓存分段。缓存缺失、校验失败或内存不足时重新解析原书。未命中缓存的长章后段仍沿用分段前缀读取。

页数索引另外绑定排版模式、算法版本、原书摘要、有效正文字体摘要和几何。字体暂时不可用时采用的回退版式不写入页数索引。原书的单图页面可缓存图层，包括图文混排中的单张图，图层键绑定原书摘要、图像资源和实际盒位置与尺寸。正文和页脚每次按当前版式绘制。缓存均可通过设备的「清理缓存」重建。

## 接口与所有权

私有头 `firmware/components/reader_document/css.h` 提供 `StyleSheet`、`Element`、`ComputedStyle`、`Context`、`WorkBudget` 和 `Checkpoint`。`StyleSheet::append` 按调用顺序增加作者样式；`compute` 接收当前元素、已计算的父样式、根字号和包含块宽度、行内声明及批次工作预算，输出已换算的样式。父元素、字符串和父样式由调用方持有；计算期间不得修改或释放。

实例由一个执行者独占，B 阶段应由既有 `content_worker` 调用，不新增任务，不在输入或绘制回调中解析。固定容量池使用 `new(std::nothrow)`，申请失败返回 `NoMemory`；计算过程不申请堆内存。构造时分配规则、选择器步骤、标识符及声明池，名称复制到池内，CSS 原文在 `append` 返回后可释放。`ComputedStyle` 为 60 字节，包含 px 长度、行高继承因子、枚举及少量标志；不包含 DOM、正文或字体对象。

`Checkpoint` 提供取消检查及可选阶段测量回调。扫描每至多 256 个源字节检查一次，匹配按工作计数至多间隔约 64 个单位检查；选择器解码、最多 128 个 token 的声明处理、20 项值计算和内存申请另有固定规模。回调、分配器阻塞与调度同样影响最长不可取消区间。独立程序记录实际取消回调之间的观测间隔，后续需覆盖阅读集成路径。取消不等于其他工作已经交还资源，调用方仍须沿用内容任务的完成发布协议。

## 选择器、层叠与词法

| 范围 | 原型契约 |
|---|---|
| 选择器 | 类型、通配符、类、ID、复合、逗号分组、后代、子元素；标签、类和 ID 按 XML 名称区分大小写 |
| 不支持的选择器 | 属性、兄弟、伪类、伪元素、命名空间等；分组中出现任一不支持或非法选择器时，整条规则无效 |
| 优先级 | 按 ID、类、类型计数比较；作者 `!important` 高于普通行内声明，同为 important 时行内优先；相同优先级按源顺序及声明顺序覆盖 |
| 继承 | 字号、行高、缩进、字重、字形、对齐、visibility、出血方向；其他属性初始值；支持 `inherit`、`initial`、`unset` |
| 分词 | 有状态扫描注释、字符串、URL token、数值、标识符、Unicode 和反斜杠转义；处理 CRLF；不使用正则解析 CSS |
| 恢复 | 未知或非法声明只跳过该声明；字符串、注释及嵌套中的分号和花括号不作为外层边界；EOF 按闭合规则处理可完成的声明，未完成的值拒绝 |
| `@import`、`@media` | 所有 at-rule 均整块或整句跳过，不解释内部声明，不调用加载器；导入深度为 0，循环、外部 URL、设备文件路径均不会触发资源读取 |

导入策略比 Issue #108 的完整功能建议更保守：本批外部 CSS 中未观察到 `@import`，`@media` 仅 2 次，因此原型不增加加载回调和导入状态。以后若支持本地导入，必须在包内路径校验、总字节、数量、循环、深度和取消契约齐备后单独扩展；不能直接复用调研脚本的 HTML 或导入处理作为固件逻辑。

## 属性与值支持表

| 属性 | 支持的值与计算基准 |
|---|---|
| `font-size` | 正长度；`px`、`pt`、`em`、`rem`、`%`；em／百分比基于父字号，rem 基于调用方提供的根字号，1 pt = 96/72 px |
| `line-height` | `normal`、非负无单位数、长度或百分比；em／百分比基于当前字号；无单位因子随子字号继承，长度和百分比形成绝对计算值后继承 |
| `text-indent` | 长度、百分比及无单位 0，可为负；百分比基于包含块宽度 |
| `margin-top/right/bottom/left` | 长度、百分比、无单位 0、`auto`，可为负；四边百分比均基于包含块宽度；auto 保留为位标志 |
| `padding-top/right/bottom/left` | 非负长度、百分比、无单位 0；百分比基于包含块宽度 |
| `margin`、`padding` | 1–4 个上述值，按上／右／下／左展开；单个 CSS 通用关键字可以展开；混合通用关键字、负 padding、函数或其他写法整条忽略 |
| `font-weight` | `normal`、`bold`、100–900 的整百数；当前压缩为两档，600–900 为 bold |
| `font-style` | `normal`、`italic` |
| `text-align` | `start`、`left`、`right`、`center`、`justify` |
| `display` | `inline`、`block`、`none`；B 阶段负责不呈现 none 子树 |
| `visibility` | `visible`、`hidden`；允许后代显式恢复 visible |
| `text-decoration` | `none`、单个 `underline`；装饰向后代传播由 B 阶段布局负责，不冒充普通继承 |
| `page-break-before/after` | `auto`、`always`、`avoid` |
| `page-break-inside` | `auto`、`avoid` |
| `duokan-bleed`、`qrbleed`、`bleed` | 一个或多个标识符，名称中含 `top`、`right`、`bottom`、`left` 即记录对应方向，如 `lefttopright` 或 `left top right`；长度值不参与；向后代继承 |

`font`、`border`、`background` 简写均不支持，不拆分应用。字体族及资源、颜色／灰阶、边框、背景、字距、列表、图片宽高、浮动、表格、竖排、伪元素和函数值等均未实现。`cm`、`mm`、`in`、`vh`、`vw` 虽在实书中出现，本原型仍拒绝，等待目标字体、屏幕比例与布局规则确定后再扩展。以上是 A 阶段当前输出契约，不是 B 阶段完整功能清单的缩减。

## 初始值与用户参数建议

原型的 CSS 初始字号为 16 px，行高 normal 使用 1.2 倍；间距和缩进为 0，display 为 inline，对齐为 start，普通字重、普通字形、可见、无装饰，分页提示为 auto。原型没有 UA 标签样式表，不能据此把所有正文元素当作行内排版。B 阶段需要单独提供段落／标题等默认块语义，并与作者声明分层。

建议原书模式保留用户设置的可用阅读区域；书内 margin／padding 在该区域内计算。用户字号作为整体比例，而不是逐项覆盖作者字号：先以逻辑 16 px 解析作者的绝对与相对关系，再在几何边界统一乘以用户字号／16。根字号必须由根元素的有效样式确定，根元素自身的 rem 按初始字号解析。原型不执行整体缩放，`Context` 仅提供计算基准。

原型默认将计算字号限制在 6–192 px，可由有效 `Context` 调整。该范围是保护原型输出的候选值，尚未通过真机可读性确认；B 阶段应在整体缩放后再次施加安全上下限，限制过大边距，保证至少一个可前进的正文行。其他长度目前以 float 输出，不得未经范围检查直接转为目标 32 位整数；上限 1,000,000 的源数值并不代表该几何可显示。

用户字体建议作为缺省／缺字回退；原书字体资源在 B 阶段单独实现，不将字体声明写回用户设置。模式、自定义参数与单书配置相互独立；本批未修改配置、默认值或界面。

## 降级与容量

| 项目 | 当前上限与结果 |
|---|---|
| 累计 CSS 原文 | 262,144 字节；当前输入超出剩余预算时整份拒绝，保留先前已完成规则 |
| 规则／选择器 | 512／1,024 |
| 选择器步骤／原子项 | 4,096／8,192；单选择器至多 8 个复合部分，每部分至多 16 个类型／类／ID 项；超复杂选择器整条规则拒绝并计数 |
| 名称池／声明池 | 32,768 字节／4,096 个展开后的声明；容量不足回滚正在构造的规则，返回 Limit，保留完整前缀 |
| token／语句 | 单 token 至多 256 个源字节，单个选择器列表或声明至多 128 个 token；超限拒绝对应规则／声明 |
| 嵌套 | 32 层；超过后返回 Limit，不保留正在构造的规则 |
| 输入元素 | 至多 64 层祖先；tag／id 各至多 256 字节，class 属性至多 4,096 字节；超限或环返回 InvalidInput |
| 匹配与样式数 | 每批默认 1,000,000 个工作单位、4,096 个样式；名称字节、类扫描、步骤和声明均计入，行内输入字节也计入；超限时当前元素返回初始／继承样式 |
| 行内声明 | 每次至多 4,096 字节，超限返回 InvalidInput |
| 分配或取消 | NoMemory／Cancelled；输出不包含未完成元素的部分匹配结果 |

池不扩容，构造期申请量可由 `Report::allocated_bytes` 观察；本机 64 位构建为 166,080 字节，不含分配器开销、CSS 输入、元素、旧／新代次重叠及调用方保存的结果。目标 32 位构建报告 162,956 字节固定池。独立程序另采样能力堆余量与连续块，完整数值见本批报告。最多保存 4,096 份计算样式另需 245,760 字节载荷，调用方也可以逐元素消费，不必全部驻留。

解析完成的前缀只供诊断与候选降级，B 阶段不能把局部规则当作完整原书样式而不反馈。建议同一排版代次固定降级方案，前台与页数统计一致；必要时回到自定义模式，保留配置及已保存位置。预算参考实书最大关联 140,285 字节、379 条规则、2,837 个原型声明，并与目标固定池及阅读内存快照对照。后续先验证单表、分批计算的 512 KiB PSRAM 试验预算，把旧新表、ZIP／字体／图片及其他并发占用纳入准入。解析与匹配耗时随规则和匹配工作变化，按实际关联样式身份复用解析结果。

## B 阶段接入建议

`document.cpp` 的 `ChapterParser` 目前只在 Mapping 路径保留 CSS。后续在原生读取路径中取得当前 XHTML 关联样式，沿 `content_job.cpp` 的内容执行者解析；不能合并整书所有 CSS。`document.h` 的 `TextBlock`／`TextRun` 需建立紧凑样式引用，分段时带上有效祖先描述、父计算样式、根字号及样式表身份，避免把分段起点误当根元素。

当前内容缓存是 `content-reading-v4`。接入样式后必须使其载荷／身份明确区分模式、支持版本和样式来源；分页与字形缓存另纳入影响几何的值、字体和回退方案。本批不修改任何缓存版本。共享样式表可在有界、单一所有者的生命周期复用，不能让前台和后台并发修改实例。

建议隐藏锚点仍保留原始 XML 身份；本机恢复优先选择同资源中原位置之后的首个可见正文，之后没有可见正文时选择之前的最近正文，均无正文时沿既有原生阅读路径继续并明确提示。它不是同步位置的近似映射，不自动上传。显示完成后才能保存新位置。

分页提示仅是计算样式中的枚举。B 阶段应优先满足强制分页、标题与后文关系；避免分页规则无法满足或块高于屏幕时允许拆分，保证正文前进，不因总页数未知或长块拒绝有效内容。显示失败、取消和保存失败仍沿既有呈现／持久化边界处理。

新模块目前不能替换 `mapping.cpp` 的 `CssProfile`。其隐藏内容、DOM 和源位置语义需要真实 CREngine／KOReader 对照，本批没有执行相关往返。

## 参考与采用理由

词法与层叠参考 [CSS Syntax Level 3](https://www.w3.org/TR/css-syntax-3/) 和 [CSS Cascade Level 4](https://www.w3.org/TR/css-cascade-4/)，原型只实现上文列出的子集。
