# EPUB 原书排版

原书排版是 EPUB 的默认排版，仍为试验功能，按书内 CSS 排版正文。本文说明支持范围、资源边界和降级规则；CSS 模块的接口见私有头 `firmware/components/reader_document/css.h`。

## 阅读行为

排版面板可按单书预览并应用「原书」或「统一」，「设为阅读默认」改变全局选择。原书模式经现有正文和页数统计入口解析当前 XHTML，按源顺序读取正文之前关联的包内样式表和 `style` 元素；正文元素的行内声明参与层叠。链接只接受普通样式表及空、`all`、`screen` 媒体值。正文开始后出现的样式表、外部 URL，以及除顶层 `@font-face` 外的 at-rule 都跳过（整句或整块，不执行块内样式）。

作者样式控制块与行内的字号、行高、缩进、对齐、留白、可见性、粗体、斜体、下划线、断词、基础分页提示、图片盒宽度和图片出血。

- **缩放**：作者样式以 16 CSS px 为基准解析，再整体乘以「用户字号 ÷ 16」，不逐项覆盖作者字号；盒模型百分比按当前可用宽度解析；书内 margin／padding 在用户设置的阅读区域内计算。缩放后再施加字号上下限并限制过大边距，保证至少有一个可前进的正文行。
- **行高**：按作者值排版，可小于字体自身高度，但不小于该行最大字号。块内 `<br>` 只换行，不重复块的边距和首行缩进。
- **对齐**：采用作者声明或继承的对齐；未指定时，语言为英语的普通段落默认两端对齐。英文两端对齐优先容纳完整单词，词距最少保留自然宽度的 80%，达到 200% 后保留右侧余量；段末和显式换行前用自然词距。逐行填词与分配余量参考了 [CrossPoint Reader 的实现](https://github.com/crosspoint-reader/crosspoint-reader/blob/develop/lib/Epub/Epub/ParsedText.cpp)。
- **断词**：`hyphens: auto` 只对英语文本启用规则断词；语言取最近祖先的 `xml:lang`／`lang`，没有时用 OPF 语言，带英国地区标记的用英式规则，其余用美式。插入的连字符只用于绘制，源锚点不变。
- **字重**：用户可在作者字重基础上微调轮廓（稍细／按原书／稍粗），保留粗体标记和分页。
- **图片**：宽度与最大宽度支持 px、pt、em、rem 和百分比。图文混排的图片读取 PNG／GIF／JPEG 头部的像素尺寸，按宽高比确定盒高，放不下时移到下一页，位于页首时缩小到可用高度；尺寸随章节缓存保存。头部缺失或无效时使用固定高度的盒子；读取头部遇到内存不足或 TF 错误时该分段加载失败，不缓存降级版式。单图章节占满正文区。
- **出血**：`duokan-bleed`、`qrbleed`、`bleed` 按值中的 top／right／bottom／left 记录方向并向后代继承，只作用于图片：左右出血时扩展到屏幕边缘；上出血只在全屏阅读且图片位于页首时从屏幕顶边开始。
- **书内字体**：解析 `font-family` 和顶层 `@font-face`，每张层叠表最多登记四个包内常规 TTF／OTF（每份有大小上限），选择首个存在且符合范围的本地 `src`；跳过外部 URL、混淆字体、字体集合、带独立字重或斜体描述的字体和 `unicode-range`。只准备当前分段可见文本引用的字体，逐字尝试 CSS 字体族、用户正文字体和缺字占位；分页记录实际的字形选择，绘制和预取使用同一选择。内容任务把字体经 CRC 校验解压为 TF 卡上的可重建副本，FreeType 随机读取副本；字体暂时不可读时用用户字体阅读，这种回退版式不写入页数索引。书内字体不写回用户设置。

布局是平面块布局，连续块的边距各自生效；嵌套盒布局、完整分页约束、灰阶装饰和 `@import` 不支持。

原书模式保留 XML 资源、节点编号和源偏移，隐藏内容仍可定位：恢复时优先选当前分段中其后的可见位置，没有时回到本段最近的可见文本。全段没有可见内容，或资源、规则、匹配、样式数超出上限时，回到统一排版并提示，整书统计中止。切换预览由内容任务读取目标模式下的源位置，完成后才可应用。同步换算仍走独立的 Mapping 路径（`mapping.cpp` 的 `CssProfile`），两者的隐藏内容与 DOM 语义须与真实 CREngine 对照后才能合并。

## 缓存与资源

章节缓存按原书摘要、书脊项和分段记录正文、源锚点、计算样式和包内字体描述，带独立的格式版本；页数索引另绑定排版模式、算法版本、原书摘要、有效正文字体摘要和几何。单图页面可缓存图层，键绑定原书摘要、图像资源和实际盒位置与尺寸。缓存缺失、校验失败或内存不足时重新解析原书。

同一时间只准备一张层叠表，工作集按 512 KiB PSRAM 核算（CSS 原文、来源、祖先、每段计算样式、字体描述与分配余量）。CSS 实例由内容任务独占，固定容量池用 `new(std::nothrow)` 一次分配，计算过程不申请堆内存，申请失败返回 `NoMemory`。规则匹配按工作量分批并检查取消；单次 TF 读取与解压调用之间才能检查取消，实测间隔不能外推为时限。CSS 原文、规则、选择器、声明、token、嵌套、祖先层数和匹配工作量的上限都在 `css.h` 中，超限时拒绝对应规则或回退到初始／继承样式，已完成的前缀只供诊断。长度以 float 输出，转为 32 位整数前做范围检查。

## 选择器、层叠与词法

| 范围 | 规则 |
|---|---|
| 选择器 | 类型、通配符、类、ID、复合、逗号分组、后代、子元素；标签、类和 ID 按 XML 名称区分大小写 |
| 不支持的选择器 | 属性、兄弟、伪类、伪元素、命名空间等；分组中出现任一不支持或非法的选择器时整条规则无效 |
| 优先级 | 按 ID、类、类型计数比较；作者 `!important` 高于普通行内声明，同为 important 时行内优先；同优先级按源顺序覆盖 |
| 继承 | 字号、行高、缩进、字重、字形、对齐、visibility、出血方向；支持 `inherit`、`initial`、`unset` |
| 分词 | 有状态扫描注释、字符串、URL、数值、标识符和转义，处理 CRLF；不用正则解析 CSS |
| 恢复 | 未知或非法声明只跳过该声明；字符串、注释和嵌套中的分号与花括号不作为外层边界 |
| at-rule | 除顶层 `@font-face` 外整块或整句跳过，不解释内部声明，不读取任何资源 |

初始值：字号 16 px，行高 normal 为 1.2 倍，间距与缩进为 0，display 为 inline，对齐为 start，普通字重与字形，可见，无装饰，分页提示为 auto。CSS 模块不带 UA 样式表，块语义由正文解析提供。

## 属性与值

| 属性 | 支持的值与计算基准 |
|---|---|
| `font-size` | 正长度；`px`、`pt`、`em`、`rem`、`%`；em 与百分比基于父字号，rem 基于根字号，1 pt = 96/72 px |
| `line-height` | `normal`、非负无单位数、长度或百分比；无单位因子随子字号继承，长度与百分比继承计算值 |
| `text-indent` | 长度、百分比、无单位 0，可为负；百分比基于包含块宽度 |
| `margin-*` | 长度、百分比、无单位 0、`auto`，可为负；百分比基于包含块宽度 |
| `padding-*` | 非负长度、百分比、无单位 0 |
| `margin`、`padding` | 1–4 个上述值；混合通用关键字、负 padding 或函数值时整条忽略 |
| `font-weight` | `normal`、`bold`、100–900；压缩为两档，600 起为粗体 |
| `font-style` | `normal`、`italic` |
| `text-align` | `start`、`left`、`right`、`center`、`justify` |
| `hyphens` | `none`、`manual`（默认，使用软连字符）、`auto`；可继承 |
| `display` | `inline`、`block`、`none` |
| `visibility` | `visible`、`hidden`；后代可显式恢复 visible |
| `text-decoration` | `none`、`underline`；向后代传播由布局处理 |
| `page-break-before/after` | `auto`、`always`、`avoid` |
| `page-break-inside` | `auto`、`avoid` |
| `width`、`max-width` | 仅用于图片盒 |
| `font-family` | 字体族列表，匹配 `@font-face` 登记的包内字体 |
| `duokan-bleed`、`qrbleed`、`bleed` | 标识符中含 `top`／`right`／`bottom`／`left` 即记录对应方向，可写成 `lefttopright` 或 `left top right` |

不支持：`font`、`border`、`background` 简写，颜色与灰阶、边框、背景、字距、列表、浮动、定位、表格、竖排、伪元素、函数值，以及 `cm`、`mm`、`in`、`vh`、`vw` 单位。
