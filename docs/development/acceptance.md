# 验收矩阵与测试证据

本页定义验收要求和数值目标，所有项目的初始状态为未执行；本文存在不代表已通过。执行结果和未测项只记录在[开发状态](../development-status.md)与[测试基准](testing-baselines.md)。行为细节见[界面说明](ui-implementation.md)和各运行时文档，本页只写判定标准。

证据类型：H = host 自动化；D = Read Pico 真机；K = 实际 KOReader 客户端；V = 实现截图／输入流程。四者不能互相冒充。`tools/check_handoff.py` 只检查文档。

## 核心发布验收

- **可复现构建**：按[开发环境](environment.md)准备固定工具链、BSP 与依赖，分别记录编译、自动化测试和真机结果。发布前核对安装与恢复说明、可分发样本及依赖许可。设备操作前按[固件指南](../../firmware/README.md#硬件与写入边界)核对授权和实际分区。
- **真机离线阅读**：在 Read Pico 上打开中文 EPUB，翻页、K2 全刷、修改字号并重启恢复；按下表核对输入、配置、保存与恢复、显示与电源，包括失败和取消。
- **真实双向接续**：用内容相同的原始 EPUB 在实际 KOReader 与 Read Pico 之间往返一次，两端字号不同，覆盖跨章位置和一次回读，按正文锚点及文本核对；按 SYNC01–SYNC03 分别记录。host 引擎对照只作补充。

1.0 的范围与兼容性条件见[版本管理](versioning.md#编号与兼容性)。单书单轮接续通过不代表下表全部同步场景或长期稳定性已验收。

### 章节缓存与跨章等待专项

同设备、书籍、字体和起点分别核对首次未缓存、反复进入章节、无停留快速往返、长章跨分段及回翻。热跨章不重新打开 EPUB、建立 ZIP 索引或解析 OPF 与目录；回到已显示的末页时正文像素、源锚点和返回栏几何一致；损坏、缺失和不匹配的缓存按原书恢复。低内存时先释放再重试一次，持续不足走错误与恢复入口，不丢已保存位置。

预准备分别覆盖完成、未完成、取消、任务启动失败和内存准入失败；只准备相邻一个分段，跳过非线性项，下一章含图时不提前解码；切书、改排版、休眠、USB 和迟到结果不发布旧正文。记录 `cache_chapter`、`chapter_prefetch_hits`、缓存命中与资源拒绝、内部 RAM／PSRAM 最低值和连续块。

缓存提交发生在正文成功呈现和必要保存之后。快速跨章不产生等待提示帧；超过 1 秒时 worker 确认暂停后只提示一次。用完整日志和 `tools/summarize_reader_perf.py` 比较操作至正文帧完成的耗时，报告样本数及 P50／P95／最大值，标注冷／热、是否预准备和是否连续无停留。

TXT 连续阅读压力专项：至少 200 章的样本连续前进至少 1,200 页、跨过至少 150 章，逐页确认位置前进；回退 200 页再前进 200 页时源锚点与此前相同；从恢复位置或目录标题进入后执行 40 页往返；刷新期间的快速输入只保留一次后续翻页；资源有界，无新错误页、崩溃、看门狗或队列溢出。

### 正文整页图片缓存资源专项

EP06 的 `gray-v1` 缓存路径覆盖旧格式命中、冷解码与热缓存逐像素一致、热命中不读原书、载荷与摘要损坏、截断、读取中和写入中取消。写入失败不发布部分缓存，提交前失败保留旧条目，本次已解码的图片仍可显示；缓存未命中不得绕过冷解码预算。真机另测 RAM／PSRAM 峰值、最大连续块、worker 栈及慢 TF 冷／热耗时。复现入口见[验证入口](../../tests/README.md)。

## 阅读响应性专项

以下是工程目标。串口诊断输入不能代替实体触摸，host、sanitizer 和桌面对照不能代替 D/K/V。

| 指标 | 目标 | 测量口径 |
|---|---|---|
| 面板空闲时释放输入到应用接收 | P95 ≤ 30 ms，P99 ≤ 100 ms | `input_wait/unqueued`；另测真实手指事件 |
| 位图命中的正文准备 | P95 ≤ 50 ms，P99 ≤ 100 ms | `stage/body_prepare_hit`，不含面板刷新 |
| 解压／解析取消检查间隔 | 约 10–20 ms | `zip/checkpoint_max`，读卡单独观察 |
| 同一图片再次显示 | 无重复 PNG／JPEG 解码 | 对照解码计数与灰阶缓存命中 |
| 统计干扰 | 翻页时延无明显恶化 | 同书同页段比较统计运行与停止 |

保存完整串口日志后运行：

```sh
python3 tools/summarize_reader_perf.py artifacts/reader-run.log
python3 tools/summarize_reader_perf.py artifacts/reader-run.log --json
```

至少分别记录普通中文连续翻页、长章后段恢复、跨章回翻、大 PNG、连续改字号、统计期间触摸、长任务快速连点、保存失败和切书后旧结果返回；每种保留样本量、P95/P99 及最大值。资源同时记录内部 RAM、PSRAM、各自最大连续块、各任务最低剩余栈和缓存分项；`cache_total` 是已知载荷估计，不是总堆用量。缓存不足时仍能阅读当前页，输入队列溢出恢复后仍能保存和休眠。

调整波形、CPU 频率策略或面板保持窗口前，先对比连续翻页、间隔翻页、长期停留、休眠与唤醒的能耗和空闲电流。局部重绘的 CPU 收益不能推导为面板刷新时间按面积下降。

## 证据格式与样本

每项记录测试 ID、版本或 commit、环境、样本摘要、执行命令、实际结果、证据路径和未覆盖边界。状态使用 `not_run`、`pass_host_only`、`fail`、`blocked`、`pass_hardware`，不用笼统的 `pass` 掩盖只测了 host。截图不代替日志，日志不代替光学和触摸验证。

合成的最小 EPUB 可以进仓库；用户自己的书籍放在本地私有目录，清单只留摘要。免费可读不等于允许再分发。完整测试字体通过固定版本的下载脚本取得。最小样本覆盖同名不同内容、跨章、CJK 与非 BMP 字符、内联与脚注、长段落和异常资源。真实 KOSync 账户与令牌、个人批注和整片备份不得进入测试输出。
