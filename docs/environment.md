# 开发环境与硬件记录

状态：待 Codex 在实际工作环境填写。本交接环境没有替用户安装 ESP-IDF 或编译固件。

## 核查顺序

先看仓库已有工具链说明/配置；检查 PATH、IDF_PATH、已有 EIM 管理配置与授权目录。
`idf.py` 不在当前 PATH 不等于没有安装。优先使用现有安装的导出环境方式，不另装“最新版”覆盖。
检查实际 `idf.py --version`、工具链、目标、Python 与构建命令；把确切命令记录下来。
早期设计依据的官方 README 写过 ESP-IDF v6.1，但不能由此伪造本仓库依赖锁；必须核验所选 commit。
