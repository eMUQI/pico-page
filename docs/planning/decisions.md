# 当前决定与资料优先级

本文只记录现行的产品决定。实现细节见各开发文档，实现与验收状态见[开发状态](../development-status.md)，后续候选见[路线图](roadmap.md)。被取代的决定只保留编号和取代关系，不作为实现要求。

## 固件设计原则

Pico Page 以目标设备上的性能、响应速度和阅读体验为首要优化目标。数据正确、可靠保存和硬件安全是前提；功能扩展和架构通用性服务于实际阅读需求。

- **当前阅读优先**：当前页呈现、输入反馈、必要保存和安全状态切换优先于预取、页数统计、封面生成等可选后台工作。资源不足或任务竞争时，先延后、减少或停用可选工作，保留正文、保存和错误处理能力。
- **响应以用户体验衡量**：关注从输入到可见反馈、内容成功呈现和后续操作的完整路径，同时考察最慢情况与连续操作。耗时准备先提供必要反馈，并遵守已确认的取消与输入规则；不以缩短等待为由改变用户选择或保存语义。
- **从问题出发，选择简单方案**：明确用户要完成的动作、正确性要求和设备资源边界，再选择能完整解决当前问题的最小方案。新增缓存、任务、抽象层或兼容路径须有明确需求或可验证收益，不为假设中的扩展提前建设通用框架。
- **以实测决定性能取舍**：在相同条件下比较目标设备上的响应耗时、尾部延迟、峰值内存和失败降级，覆盖冷／热缓存及资源不足路径。减少代码、分配次数或内存占用本身不足以证明体验改善；需要增加资源或复杂度时说明收益、预算和代价。数值目标见[验收](../development/acceptance.md)；host 结果不能替代真机结论。

| D47 | 黑底含义由结构决定 | 单独的黑底按钮表示推荐操作；相连一组中的黑底表示当前项；分开摆放的选项用单选圆点，开关用点按切换行；不可点的黑色标记只限「!」方块、下载进度条和休眠提示条 |
| D48 | 查词面板采用相连按钮表并提供选区调整 | 面板贴着选区放在空间较大的一侧，两侧都不够时使用固定的上或下面板，保证单行选区总有一侧被让开；底部三行依次为范围调整、词典来源和释义翻页；紧凑行高是词典面板的热区例外 |
| D49 | 书籍详情增加「封面」与「总页数」行 | 总页数由用户点按后计算，停留在详情时连续计算，离开时暂停并与阅读时的统计共用结果；单书可隐藏封面，不修改原书。设计与状态见路线图 R16 |
| D50 | 双 7 MiB OTA 布局通过电脑完整重装启用 | OTA 限于同一布局，保留双槽和失败回滚；旧清单路径保留 0.6.2，新布局使用独立清单。见[分区迁移方案](ota-partition-migration.md) |
| D51 | 左右轻扫翻屏与翻页 | 书库、目录、书签、使用说明和正文中左滑向后、右滑向前；非翻页上下文忽略；不增加开关或边缘手势；每次一屏，不循环。判定阈值以源码为准，边界测试见 IN09 |
| D52 | 阅读页脚左右独立切换 | 左侧循环页码、百分比、章节序号、章节名和不显示；右侧循环电量、时钟和不显示。电量用五格表示，充电时显示闪电，未知读数隐藏图标；时钟按 UTC+8 显示，不主动联网或定时刷新 |
| D53 | 无线按需使用 | 无线许可默认允许，但开机、阅读、翻页、退出书籍和唤醒不主动联网或同步；一次同步以查询、用户处置、上传或采用远端为完整会话；用户可临时保持 STA，休眠后释放、唤醒不恢复；热点退出不自动新建 STA |
| D54 | 休眠封面按需生成 | 阅读期间不预生成；休眠请求时由 worker 检查缓存，未命中再生成，每次请求只尝试一次；失败时显示书名。从非阅读页面休眠时显示内置书库插画 |
| D55 | 透明锁屏隐藏阅读页脚 | 开启「叠加当前画面」时正文底图清除整条阅读页脚，不把统计、进度、电量、时钟或通知带入锁屏；书库和设置底图不变 |
| D56 | EPUB 默认原书排版，全屏阅读默认开启 | 未单独设置过的配置升级后同样采用；「设为阅读默认」同时保存样式选择；TXT 使用统一排版 |
| D57 | 排版面板使用参数卡片 | 可调参数在卡片上直接加减，不使用滑块；一屏最多一块黑底，没有改动时没有黑底；预览为真实正文页由面板覆盖下部，不为面板重新分页。原书排版可调字重（稍细／按原书／稍粗），统一排版可选左对齐或两端对齐，两种样式的设置分别保存 |
