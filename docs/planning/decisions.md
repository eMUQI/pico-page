# 当前决定与资料优先级

本文整理已确认的产品决定；具体实现状态见 [开发状态](../development-status.md)。

## 固件设计原则

Pico Page 以目标设备上的性能、响应速度和阅读体验为首要优化目标。数据正确、可靠保存和硬件安全是前提；功能扩展和架构通用性应服务于实际阅读需求。以下原则指导开发取舍，不表示当前实现已达到全部目标。

- **当前阅读优先**：当前页呈现、输入反馈、必要保存和安全状态切换优先于预取、页数统计、封面生成等可选后台工作。资源不足或任务竞争时，优先延后、减少或停用可选工作，保留正文、保存和错误处理能力。
- **响应以用户体验衡量**：关注从输入到可见反馈、内容成功呈现和后续操作的完整路径，同时考察最慢情况与连续操作。耗时准备应先提供必要反馈，并遵守已确认的取消与输入规则；允许等待的场景沿用对应产品决定，不以缩短等待为由改变用户选择或保存语义。
- **从问题出发，选择简单方案**：按第一性原理明确用户要完成的动作、正确性要求和设备资源边界，再按奥卡姆剃刀选择能完整解决当前问题的最小方案。新增缓存、任务、抽象层或兼容路径须有明确需求或可验证收益；复杂度与维护成本应与收益相称，不为假设中的扩展提前建设通用框架。
- **以实测决定性能取舍**：在相同条件下比较目标设备上的响应耗时、尾部延迟、峰值内存和失败降级，覆盖相关的冷／热缓存及资源不足路径。减少代码、分配次数或内存占用本身不足以证明体验改善；需要增加资源或复杂度时，说明收益、预算和代价。数值目标见 [验收](../development/acceptance.md)，实际测量见 [开发状态](../development-status.md)；host 结果不能替代真机结论。

### 2026-10-09 · 阅读页脚独立切换（Issue #21）

正文页脚左侧依次切换全书页码/总页数、全书阅读百分比、章节序号/总章节数、当前章节名、不显示；右侧独立切换电量、时钟、不显示（2026-10-17 用户新增）。隐藏后点击原热区继续循环，页脚留白和必要提示保留，不扩展正文区域。阅读页脚的百分比四舍五入：页数统计完成前显示整数，完成后固定保留两位小数，均不显示「估算」（2026-10-10 用户更新）。当前章节名沿用阅读页顶部的目录名称，无可用名称时显示「第 N 章」；长名称单行省略，不占用右侧状态区（2026-10-10 用户新增）。此规则细化 D16 的显示方式；页码仍来自当前排版的全书统计，点击状态区不改变阅读位置。时钟暂按北京时间（UTC+8）显示；启动时在系统时间未设置的情况下从有效 PMU RTC 恢复，沿用已有按需联网校准，并在收到真实 NTP 校时后空闲写回 RTC（2026-10-11 用户授权）。PMU 未校准、复位或读取失败且系统时间不可用时显示未知。开机、阅读和切换页脚时钟不主动联网或定时刷新屏幕，只在翻页或重画页脚时更新时间。用户主动连接 Wi-Fi 并取得 IP 后顺便启动校时，不等待校时结果才完成连接或传书；也可在「Wi-Fi 设置」中明确发起一次校准，临时借用网络并在结束后释放，已有手动保持的连接不受影响（2026-10-15 用户确认提交 PR，待真机验证）。点击切换时局部刷新底部整条页脚；K2 或显示基准失效仍使用全刷。

### 2026-10-09 · Wi-Fi 与手动同步（Issue #18）

无线许可默认允许，但开机、阅读、翻页、退出书籍和唤醒不主动联网或同步。用户发起同步、配网或传书时按需联网；一次同步以查询、用户处置、上传或采用远端为完整会话。用户可明确连接并临时保持 STA，任务借用后不关闭；主动断开、禁止无线或休眠后释放，唤醒不恢复。固定使用用户明确选择的 SSID，不根据信号强弱换网；选择与最近成功连接记录分离。（2026-10-10 由 D37 修改：默认按信号强弱自动选网；「指定」方式保留本句的行为。）查看 Wi-Fi 状态不结束传书。热点退出后不自动新建 STA；原手动连接意图暂停，需明确连接恢复。具体状态、时限和验收边界见 [平台运行](../development/platform-runtime.md) 与 [Wi-Fi、键盘与同步](../development/ui-implementation.md#wi-fi键盘与同步)。

### 2026-10-10 · 休眠封面按需生成（Issue #30）

阅读期间不主动预生成休眠封面。用户请求休眠（含空闲超时休眠）时，内容 worker 才检查休眠封面缓存，未命中再生成。书库缩略图继续异步批量加载。空闲时间留给必要保存、下一页预取和页数统计。封面是可选的锁屏增强：无封面、资源损坏、内存不足、超时取消或任务启动失败时，等 worker 交还资源后显示书名并休眠。每次休眠请求只尝试一次，不在阅读期间重试。首次冷缓存休眠的耗时待真机测量；是否恢复有限的预生成另行决定。具体流程见 [架构](../development/architecture.md)，验收见 [验收](../development/acceptance.md) PW05。

### 2026-10-10 · 左右轻扫翻屏与翻页

用户确认实现左右轻扫：书库、目录、书签、使用说明和正文沿现有翻页动作处理，左滑下一屏/页，右滑上一屏/页。页脚 UI 与翻屏控件本轮不变，默认 K1/K2/K3 映射不变，不增加轻扫开关或边缘手势。此决定覆盖 R14 中本轮移除页脚按钮及仅限主页的旧计划。

松手时用末点减按下点计算 dx、dy：横向位移至少 60 px、接触不超过 700 ms，且 `abs(dx) * 100 >= abs(dy) * 173` 时认定轻扫。两轴位移均小于 60 px 时仍以按下点派发点按；达到 60 px 而不满足轻扫条件的接触忽略。按 2026-10-29 更新的 D22，书库长按达到 600 ms 且采样接触在两轴上均不超出按下点 28 px 时即进入详情，后续松手不再触发点按或轻扫；正文图片按住达到阈值即触发的路径保留。阈值手感与误触率待真机确认。

轻扫经 `Input::Next/Previous` 和统一输入映射入口路由；工具、排版、确认等非翻页上下文忽略，不操作背后正文。每次只翻一屏，不循环；书库首尾无变化时不重画。忙碌、过期接触和合并规则沿用原实现，正文按 D14 保留一次后续翻页，保存遵守 D15。
