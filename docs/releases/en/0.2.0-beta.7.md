## Added

- Added **Reading** and **Library** settings pages for default layout, refresh behavior, and library sorting.

## Improved

- Reorganized the main Settings page by feature and added summaries of current settings.
- When you check for firmware updates, the device shows progress for Wi-Fi, internet access, and the update server separately. If the check fails, it shows which step failed.
- Improved the firmware download and write process to reduce download time and better coordinate downloads with screen updates, touch input, and power status checks.

## Fixed

- Fixed an issue where the reason for a failed update check could disappear after reopening the update page.
- Clarified the status of cached update results so you can distinguish the last check from the current check.
- Fixed an issue where canceling a Wi-Fi book transfer could affect later screen refreshes.

## Notes

- The firmware is still in testing and features may change.
- Install or update firmware only from picopage.wulu.zone. The device cannot tell whether firmware comes from the official source. Firmware from another source may be unsafe.
