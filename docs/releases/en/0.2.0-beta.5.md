## Added

- Wi-Fi settings now show the time and offer a **Calibrate** action. The device automatically sets the clock from the network when it connects to Wi-Fi.

## Improved

- Improved cache hits and cache write timing for EPUB chapters, reducing the wait when you reopen a chapter. The device shows a waiting message if loading the next or previous chapter is slow.
- Improved decoding for some PNG images and started filling in images earlier on the first reading screen. EPUBs with images take less time to open for the first time.
- Increased the default automatic full refresh interval to 25 reading screen updates in Balanced mode and 15 in Fast mode. Existing global and per-book settings keep their previous values.
- When you request sleep, the device first shows **Preparing to sleep. Press power to cancel**, then saves your reading progress and disconnects from the network.
- The reading footer now shows the charging state.
- The hotspot transfer page now explains what to do if your iPhone reports no internet connection.

## Fixed

- Fixed EPUBs with many chapters sometimes failing to open because the book metadata or table of contents was too large. If the table of contents is damaged or too large to process, the reader tries to use the chapter list instead.
- Fixed a possible error when parsing invalid EPUB metadata and improved chapter file lookup.

## Update notes

- Devices running 0.2.0-beta.1 cannot update over the network. Reinstall first using the installer at picopage.wulu.zone.

## Notes

- This is a beta release and features may change.
- Install or update firmware only from picopage.wulu.zone. The device cannot tell whether firmware comes from the official source. Firmware from another source may be unsafe.
