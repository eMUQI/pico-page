## Improved

- While the device prepares a sleep image, only pressing the power button again cancels sleep. Touch input and K1, K2, or K3 are ignored during this time.
- After an error, going back returns you to the reading page, library, or Settings, depending on where the error occurred. The error page shows **Resume reading**, **Back to library**, or **Back to settings** accordingly.
- If the device goes to sleep in the library or Settings, it returns there when it wakes.
- When the library, contents, bookmarks, Settings, and similar screens refresh, they update only the areas that changed. This reduces flicker on unchanged items such as the **Continue reading** cover when you turn a screen. K2 still fully refreshes the current screen.

## Update notes

- Devices running 0.2.0-beta.1 cannot update over the network. Reinstall first using the installer at picopage.wulu.zone.

## Notes

- This is a beta release and features may change.
- Install or update firmware only from picopage.wulu.zone. The device cannot tell whether firmware comes from the official source. Firmware from another source may be unsafe.
