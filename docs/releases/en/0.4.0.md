## Improved

- Custom sleep images support **Overlay on current screen**. A transparent PNG can show the reading page underneath. You can preview image settings before saving them.
- When a sleep image overlays the reading page, it hides the reading footer. The footer returns when you cancel sleep or wake the device.
- Reduced memory use when preparing transparent PNG sleep images and improved the reliability of caching and image rotation.

## Fixed

- Reduced footer flicker during ordinary page turns and fixed cases where page turns triggered an extra full refresh.
- Fixed background chapter parsing and page counting triggering watchdog warnings and interfering with screen refreshes.
- Corrected wrapping for long titles and trailing punctuation in the table of contents, as well as the reading percentage display.
- The option to return to the position before syncing now closes promptly after you turn a page from the synced position. The option stays available if the page turn fails or is canceled.
- Fixed an issue where updates from development builds could skip the prompt to confirm a data format change.

## Notes

- The firmware is still in testing and features may change.
- Install or update firmware only from picopage.wulu.zone. The device cannot tell whether firmware comes from the official source. Firmware from another source may be unsafe.
