## Added

- EPUBs use **Publisher layout** by default. This supports common book styles, some embedded fonts, and images that extend to the page edge. To use your own line spacing, paragraph spacing, and indentation, switch to **Uniform layout** in **Layout**. TXT files always use Uniform layout.
- **Full screen** is on by default. It hides the fixed footer and shows bookmarks at the top of the page. Turn off **Full screen** in **Layout** to restore the footer.

## Improved

- The Layout panel uses cards for direct adjustment of font size and page margins. The preview shows a full page of text and images. Choose **Apply to this book** or **Set reading defaults**.
- When paginating, the space left at the bottom of a page can be distributed between lines if it is too short for another line.
- Reduced repeated work when preparing some EPUB chapters. The device skips redundant refreshes when the page looks the same. You can still press K2 for a full refresh.

## Fixed

- Fixed a restart that could occur when reopening some large EPUBs if memory allocation failed.
- Fixed cases where an edge-to-edge image could cover the bookmark marker after the image finished loading in full screen. Also fixed some timing issues when starting a screen refresh.

## Compatibility

- After upgrading from 0.5.1, layout options you have never set use the new defaults. Your reading progress and applicable per-book settings still apply.
- Back up your TF card before returning to 0.5.1. The older version cannot read settings files that contain the new layout options. If you saved these options, remove `original_epub` and `fullscreen_reading` from `PicoPage/settings.toml` and the affected books' `.picopage/settings.toml` files before using the older version.

## Notes

- Publisher layout is still experimental. If a book's styles do not work well on the small screen, switch to **Uniform layout**.
- Install or update firmware only from picopage.wulu.zone. The device cannot tell whether firmware comes from the official source. Firmware from another source may be unsafe.
