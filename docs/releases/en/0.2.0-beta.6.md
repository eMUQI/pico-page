## Added

- You can hide either side of the reading footer. Tap the same spot to show it again.

## Improved

- The font picker shows four fonts per screen in a paged list with a reading preview.
- The page turn effects are now **Off** and **Ripple**. The default is **Off**.

## Fixed

- Corrected the ripple direction when going back a page. It now runs in the opposite direction to the ripple when going forward.

## Update notes

- Devices running 0.2.0-beta.1 cannot update over the network. Reinstall first using the installer at picopage.wulu.zone.

## Notes

- This is a beta release and features may change.
- Install or update firmware only from picopage.wulu.zone. The device cannot tell whether firmware comes from the official source. Firmware from another source may be unsafe.
