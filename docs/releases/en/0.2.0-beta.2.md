## Fixed

- Fixed the **Update server did not respond** message from **Check for updates**. Version 0.2.0-beta.1 could not verify the update server's certificate and could not update over the network.
- If your device runs 0.2.0-beta.1, reinstall once using the installer at picopage.wulu.zone. After reinstalling, you can update over the network.

## Notes

- This is a beta release and features may change.
- The device does not verify the firmware publisher's signature. Get firmware only from picopage.wulu.zone.
