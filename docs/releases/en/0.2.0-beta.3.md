## Added

- Wi-Fi transfer now accepts fonts in TTF or OTF format and sleep screen images in PNG or JPEG format. Fonts go in `Fonts/` and sleep images go in `LockScreens/`.
- After ending the transfer, choose an uploaded font in **Layout** without restarting the device.
- You can add files to the transfer page during or after an upload. Added files wait in the queue and upload in order. On a computer, drag files anywhere onto the page.

## Improved

- With **Custom image** selected, the device prepares the image if needed before showing it and going to sleep. It uses the simple sleep screen only if the image cannot be prepared. If preparation takes more than 1 second, the footer shows a message. You can cancel sleep by operating the device while it waits.
- Sleep image rotation skips damaged images and images that exceed the byte or pixel limit.
- If an image cannot be shown, the device shows a one-time footer message after waking instead of opening an error page.
- When the transfer status changes, the device refreshes only the status area below the QR code.
- If the selected font lacks a character, the character appears as an empty square. Each missing Han character takes up the width of one Han character.

## Fixed

- Fixed a screen refresh failure that could interrupt an incoming Wi-Fi transfer.
- Fixed a case where the device could wake to the reading page when it went to sleep in the library and could not show a sleep image. It now returns to the library.
- Fixed the **Continue reading** card disappearing after turning to the next library screen.
- Fixed horizontal lines appearing briefly over keys when switching case, numbers, or symbols on the Wi-Fi password keyboard.

## Update notes

- After the update, the device recalculates the total page count for each book. Your reading progress is unaffected.
- Devices running 0.2.0-beta.1 cannot update over the network. Reinstall first using the installer at picopage.wulu.zone.

## Notes

- This is a beta release and features may change.
- Install or update firmware only from picopage.wulu.zone. The device cannot tell whether firmware comes from the official source. Firmware from another source may be unsafe.
