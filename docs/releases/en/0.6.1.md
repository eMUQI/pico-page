## Improved

- When resuming a long TXT book from sleep, the device reads less of the file to restore your last position.
- Reduced repeated work when resuming an EPUB after waking, if the file has not changed.

## Fixed

- Fixed an issue where the computer sometimes could not find the device's serial port after exiting USB file transfer and restarting.
- Fixed a case where the USB serial port stopped responding after a device reset.
- Fixed a startup failure that the power-on self-test could cause.

## Notes

- Install or update firmware only from picopage.wulu.zone. The device cannot tell whether firmware comes from the official source.
