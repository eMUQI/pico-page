## Notes

- This is the first Pico Page beta, for testing network updates and full firmware installation. Features may change.
- The device does not verify the firmware publisher's signature. Get firmware only from picopage.wulu.zone.

## Reading

- Open EPUB and TXT files directly from the TF card. TXT files can use UTF-8 or GB18030 encoding.
- Use the table of contents and internal links. View images inline or open them in the image viewer.
- Adjust the font, size, weight, and line spacing. You can set them separately for each book.
- Choose Clear, Balanced, or Fast refresh mode and adjust the automatic full refresh interval.
- Turn pages with the buttons, by tapping the footer, or by swiping left or right.

## Library and book transfer

- The library shows books and folders in `Books/` in a list or cover view.
- Transfer books by USB file transfer, the device's hotspot, or a saved Wi-Fi network.
- Reading progress and settings are ordinary files on the TF card. Reinstalling the firmware preserves them.

## Reading positions with KOReader

- You can manually sync reading positions in both directions for the same EPUB in KOReader and Pico Page.
- The device offers to jump only when it can match the reading position exactly.

## Device

- For the sleep screen, choose the book cover, leave the reading page visible, or use a simple sleep screen or a custom image.
- Hold the power button to shut down or restart.
- Open **Settings → Firmware update** to check for and install updates. If installation fails, the device returns to the previous version.
- **Settings → Help** provides offline instructions.
