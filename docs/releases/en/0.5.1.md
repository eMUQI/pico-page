## Added

- TXT files automatically detect common chapter headings. You can jump to a chapter from the table of contents and see the current chapter in the reading toolbar and footer.

## Improved

- You can set the automatic full refresh interval for Balanced and Fast modes to 0 to disable periodic full refreshes. The default interval in Fast mode is now 30 reading screen updates. Existing settings keep their previous values. You can still press K2 for a full refresh.
- The reading footer shows a five-segment battery icon, with a lightning bolt while charging. The icon is hidden if the device cannot read the battery level.
- When the reading font fails to load or render, the device shows the reason and error code.

## Fixed

- Fixed library covers failing to retry after a temporary load error, some covers staying blank, and TXT files incorrectly reporting a cover generation failure.
- Fixed a case where repeated page turns in either direction could return to the wrong position after jumping from the contents or resuming reading.
- Fixed an incomplete handoff of the USB serial port during light sleep and improved serial port recovery on wake.

## Notes

- The firmware is still in testing and features may change.
- Install or update firmware only from picopage.wulu.zone. The device cannot tell whether firmware comes from the official source. Firmware from another source may be unsafe.
