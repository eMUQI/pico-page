## Improved

- The device automatically retries a firmware download if no data arrives for a short time or the connection drops. If the server supports resuming downloads, the same download can continue from where it stopped.
- Help now covers bookmarks, hiding the footer, and updating firmware. It also updates the instructions for canceling sleep, backing up files, and meeting the charging requirements.
- The built-in tap example lets you hide and restore the footer just as you would while reading.

## Fixed

- Corrected outdated or unclear instructions in Help about canceling sleep and the conditions for installing firmware.

## Notes

- The firmware is still in testing and features may change.
- Install or update firmware only from picopage.wulu.zone. The device cannot tell whether firmware comes from the official source. Firmware from another source may be unsafe.
