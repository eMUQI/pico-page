## 新增

- EPUB 默认使用「原书排版」，支持常见的书内样式、部分内嵌字体和贴边图片。想用自己的行距、段距和缩进，可在「排版」中切换到「统一排版」。TXT 始终使用统一排版。
- 全屏阅读默认开启，收起固定页脚，书签显示在页面顶部。在「排版」中关闭「全屏阅读」，即可恢复页脚。

## 改进

- 排版面板改用参数卡片，可直接调整字号和页边距。预览按整页正文排版并显示图片，可选择「应用到此书」或「设为阅读默认」。
- 分页时，页底不足一行的余量可分配到行间。
- 减少准备部分 EPUB 章节时的重复处理。正文画面相同时省去重复刷新，仍可按 K2 手动全刷。

## 修复

- 修复部分大型 EPUB 在重新打开时因内存分配失败而重启的问题。
- 修复全屏贴边图片补图后可能遮住书签标记的问题，以及部分屏幕刷新启动时的时序问题。

## 兼容性

- 从 0.5.1 升级后，未设置过的排版选项使用新的默认值。已有的阅读进度和适用的单书设置继续生效。
- 如果需要退回 0.5.1，先备份 TF 卡。旧版无法读取含新排版选项的设置文件。若这些选项已保存，请从 `PicoPage/settings.toml` 和相关书籍的 `.picopage/settings.toml` 中删除 `original_epub` 和 `fullscreen_reading` 两项，再使用旧版。

## 说明

- 原书排版仍处于试验阶段。书内样式不适合在小屏阅读时，可切换到「统一排版」。
- 请只从 picopage.wulu.zone 安装或更新固件。设备无法识别固件是否来自官方，其他来源的固件可能不安全。
