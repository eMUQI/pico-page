## 升级

- **从 0.6.2 或更早版本升级到 0.7.0，需要用电脑重装一次。** 本版改用双 7 MiB 固件分区。重装前，设备上的「固件更新」最多提供 0.6.2，可能仍显示「已是最新版本」。
- **用 USB 数据线连接 Read Pico。** 在电脑上用 Chrome 或 Edge 打开[官网安装页](https://picopage.wulu.zone/install/)，按提示安装 0.7.0。

## 变更

- 增加繁体中文和英文界面。首次启动可以选择语言，之后也可在设置中切换。
- 英文 EPUB 的原书排版在未指定对齐方式时，普通正文行优先两端对齐，段尾自然留白。英文 TXT 可以按书选择「重排段落」，合并段内换行。
- 封面锁屏显示当前章节和阅读位置。从书库或设置进入休眠时，显示内置书库插画。低电量时，锁屏会提示充电。
- 阅读工具顶部显示时间和电量。两端阅读位置不一致的提示集中在同步面板。

## 修复

- 校正部分页面上封面锁屏与阅读工具的进度显示，并让锁屏章节名跟随当前书籍的正文字体。
