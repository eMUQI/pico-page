## 新增

- 新增「阅读」和「书库」设置页，集中管理默认排版、刷新方式和书库排序。

## 改进

- 重新整理设置首页，按功能分组，并显示当前设置摘要。
- 检查固件更新时，分别显示 Wi-Fi、互联网和更新服务器的进度；失败时提示具体步骤。
- 优化固件下载与写入流程，减少下载等待，并改善下载与屏幕刷新、触摸及电源状态读取之间的协调。

## 修复

- 修复更新检查失败后，重新进入更新页可能丢失失败原因的问题。
- 修正缓存检查结果的提示，避免将上次检查结果误认为本次检查结果。
- 修复取消 Wi-Fi 传书后可能影响后续屏幕刷新的问题。

## 说明

- 固件仍处于测试阶段，功能还可能调整。
- 请只从 picopage.wulu.zone 安装或更新固件。设备无法识别固件是否来自官方，其他来源的固件可能不安全。
