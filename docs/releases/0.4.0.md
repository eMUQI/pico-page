## 改进

- 自定义休眠图片支持「叠加当前画面」，透明 PNG 可保留底下的阅读画面；支持预览尚未保存的图片设置。
- 叠加阅读画面时，休眠图片隐藏阅读页脚，取消休眠或唤醒后恢复页脚。
- 降低透明 PNG 锁屏准备时的内存占用，改善缓存准备和轮播的稳定性。

## 修复

- 减少普通翻页时页脚闪烁，修复部分翻页触发额外全刷的问题。
- 修复后台章节解析和页数统计可能触发看门狗告警、干扰屏幕刷新的问题。
- 修复目录长标题换行、末尾标点和阅读百分比的显示问题。
- 从同步位置继续翻页后，及时收起返回同步前位置的入口；翻页失败或取消时保留入口。
- 修复开发版本更新时可能跳过数据格式变更确认的问题。

- 固件仍处于测试阶段，功能还可能调整。
