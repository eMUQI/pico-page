## 升级

- 0.7.0 可以在设备上通过「固件更新」升级到 0.8.0。
- **0.6.2 或更早版本需要用电脑重装一次。** 用 USB 数据线连接 Read Pico，在电脑上用 Chrome 或 Edge 打开[官网安装页](https://picopage.wulu.zone/install/)，按提示安装 0.8.0。

## 新增

- 「翻页效果」新增「斜掠」。下一页从右下角展开，上一页从左下角展开。
- 「翻页效果」新增「随点按位置」。点按正文上部或下部翻页时，从对应页角斜掠；点按中部时横向展开。轻扫按手指按下的位置选择，按键翻页横向展开。
- EPUB 原书排版新增「字重」，可选「稍细」「按原书」「稍粗」，保留原书的粗体层次。
- EPUB 统一排版和 TXT 新增「对齐」，可选「左对齐」或「两端对齐」，默认左对齐。
- 「同步」面板新增「校准时间」，显示当前时间和上次校准时间，点「立即校准」联网校时。也可以在「设置 → Wi-Fi」中校准。

## 变更

- 水波纹和斜掠翻页改用八灰阶波形，每次翻页的绘制时间缩短约 0.1 秒。开启翻页效果时，随正文刷新的插图也按八灰阶显示。

## 修复

- 修复原书排版丢失段首空格或书内首行缩进的问题。
- 修复长 TXT 的段落跨越内部分段时，后半段被当作新段落缩进的问题。
