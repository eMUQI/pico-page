## 说明

- 这是 Pico Page 的第一个测试版，用于验证联网更新和整片安装。功能还可能调整。
- 设备不验证固件发布者的签名。只从 picopage.wulu.zone 获取固件。

## 阅读

- 直接打开 TF 卡上的 EPUB，以及 UTF-8、GB18030 编码的 TXT。
- 目录、内部链接、正文图片和图片查看。
- 字体、字号、字重、行距可调，单本书可以单独设置。
- 清晰、均衡、快速三档刷新模式，自动全刷间隔可调。
- 按键、页脚点按和左右轻扫翻页。

## 书库与传书

- 书库显示 `Books/` 中的书和文件夹，有列表和封面两种视图。
- 三种传书方式：USB 文件传输、设备热点、已保存的 Wi-Fi。
- 阅读进度和设置是 TF 卡上的普通文件，重装固件不会丢失。

## KOReader 位置接续

- 与 KOReader 互相接续同一本 EPUB 的阅读位置，由你手动发起。
- 只在位置能够精确对应时提供跳转。

## 设备

- 休眠画面可选书籍封面、保留正文、简洁屏保或自定义图片。
- 长按电源键可以关机或重启。
- 「设置 → 固件更新」检查并安装新版本，安装失败时回到原来的版本。
- 「设置 → 使用说明」提供离线说明。

## 已知问题

- 同步开始时屏幕偶尔刷新失败，重试仍失败会进入「屏幕更新失败」页。
- 单段文字超过约 8 千字时，同步位置可能与 KOReader 不一致。
- 含表格等复杂结构的章节不提供位置接续。
- TXT 不支持位置接续和 UTF-16。
- 插入或更换 TF 卡后需要重启设备。

## 兼容性

- 进度文件格式为 2，配置文件格式为 1。
