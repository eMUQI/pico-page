## 升級

- 0.7.0 可以在裝置上透過「韌體更新」升級至 0.8.0。
- **0.6.2 或更早版本需要用電腦重新安裝一次。** 用 USB 資料線連接 Read Pico，在電腦上用 Chrome 或 Edge 開啟[官網安裝頁](https://picopage.wulu.zone/zh-hant/install/)，按照提示安裝 0.8.0。

## 新增

- 「翻頁效果」新增「斜掠」。下一頁從右下角展開，上一頁從左下角展開。
- 「翻頁效果」新增「隨點按位置」。點按正文上方或下方翻頁時，從對應頁角斜掠；點按中間時橫向展開。輕掃依手指按下的位置選擇，按鍵翻頁橫向展開。
- EPUB 原書排版新增「字重」，可選「稍細」「按原書」「稍粗」，保留原書的粗體層次。
- EPUB 統一排版和 TXT 新增「對齊」，可選「左對齊」或「兩端對齊」，預設左對齊。
- 「同步」面板新增「校準時間」，顯示目前時間和上次校準時間，點「立即校準」連網校時。也可以在「設定 → Wi-Fi」中校準。

## 變更

- 水波紋和斜掠翻頁改用八灰階波形，每次翻頁的繪製時間縮短約 0.1 秒。開啟翻頁效果時，隨正文更新的插圖也以八灰階顯示。

## 修正

- 修正原書排版遺失段首空格或書內首行縮排的問題。
- 修正長篇 TXT 的段落跨越內部分段時，後半段被當成新段落縮排的問題。
