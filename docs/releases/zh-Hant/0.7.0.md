## 升級

- **從 0.6.2 或更早版本升級至 0.7.0，需要用電腦重新安裝一次。** 本版改用雙 7 MiB 韌體分割區。重新安裝前，裝置上的「韌體更新」最高只提供 0.6.2，可能仍顯示「已是最新版本」。
- **用 USB 資料線連接 Read Pico。** 在電腦上用 Chrome 或 Edge 開啟[官網安裝頁](https://picopage.wulu.zone/zh-hant/install/)，按照提示安裝 0.7.0。

## 變更

- 新增繁體中文和英文介面。首次啟動時可選擇語言，之後也可在設定中切換。
- 英文 EPUB 採用「原書排版」時，若未指定對齊方式，一般正文行優先採用兩端對齊，段尾最後一行自然留白。英文 TXT 可依書籍選擇「重排段落」，合併段落內的換行。
- 封面鎖屏會顯示目前章節和閱讀位置。從書庫或設定進入休眠時，顯示內建的書庫插畫。電量偏低時，鎖屏會提示充電。
- 閱讀工具頂部顯示時間和電量。兩端閱讀位置不一致的提示集中在同步面板。

## 修正

- 校正部分頁面上封面鎖屏與閱讀工具的進度顯示，並讓鎖屏章節名稱使用目前書籍的正文字型。
