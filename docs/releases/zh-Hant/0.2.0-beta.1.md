## 說明

- 這是 Pico Page 的第一個測試版，用於驗證網路更新和整片安裝。功能可能調整。
- 裝置不驗證韌體發行者的簽章。請只從 picopage.wulu.zone 取得韌體。

## 閱讀

- 可直接開啟 TF 卡上的 EPUB，以及 UTF-8 或 GB18030 編碼的 TXT。
- 支援目錄、內部連結、正文圖片，以及圖片檢視。
- 可調整字型、字級、字重和行距，也可為個別書籍另外設定。
- 可選擇清晰、均衡或快速三種刷新模式，並調整自動全刷間隔。
- 可用按鍵、點按頁腳或左右輕掃翻頁。

## 書庫與傳書

- 書庫會顯示 `Books/` 中的書籍和資料夾，可選擇清單或封面檢視。
- 可透過 USB 檔案傳輸、裝置熱點或已儲存的 Wi-Fi 傳書。
- 閱讀進度和設定是 TF 卡上的一般檔案，重新安裝韌體不會遺失。

## 與 KOReader 接續閱讀位置

- 可手動發起同步，與 KOReader 互相接續同一本 EPUB 的閱讀位置。
- 只有在閱讀位置能精確對應時，才會提供跳轉。

## 裝置

- 休眠畫面可選擇書籍封面、保留正文、簡潔屏保或自定義圖片。
- 長按電源鍵可關機或重啟。
- 在「設定 → 韌體更新」檢查並安裝新版本。安裝失敗時會回到原本的版本。
- 「設定 → 使用說明」提供離線說明。
