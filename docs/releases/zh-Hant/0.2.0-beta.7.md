## 新增

- 新增「閱讀」和「書庫」設定頁，可集中管理預設排版、刷新方式和書庫排序。

## 改進

- 重新整理設定首頁，依功能分組，並顯示目前設定摘要。
- 檢查韌體更新時，會分別顯示 Wi-Fi、網際網路和更新伺服器的進度。若失敗，會提示發生問題的步驟。
- 改善韌體下載與寫入流程，縮短下載等待時間，並改善下載期間與畫面刷新、觸控及電源狀態讀取的協調。

## 修正

- 修正更新檢查失敗後，重新進入更新頁可能看不到失敗原因的問題。
- 修正快取檢查結果的提示，以免將上一次的結果誤認為本次結果。
- 修正取消 Wi-Fi 傳書後，可能影響後續畫面刷新的問題。

## 說明

- 韌體仍在測試階段，功能可能調整。
- 請只從 picopage.wulu.zone 安裝或更新韌體。裝置無法識別韌體是否來自官方，其他來源的韌體可能不安全。
