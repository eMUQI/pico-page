## 改進

- 自定義休眠圖片支援「疊加當前畫面」。透明 PNG 可保留底下的閱讀畫面，尚未儲存的圖片設定也可預覽。
- 疊加閱讀畫面時，休眠圖片會隱藏閱讀頁腳。取消休眠或喚醒後會恢復頁腳。
- 減少準備透明 PNG 鎖屏時的記憶體用量，改善快取準備和輪播的穩定性。

## 修正

- 減少一般翻頁時的頁腳閃爍，並修正部分翻頁觸發額外全刷的問題。
- 修正背景章節解析和頁數統計可能觸發看門狗警告、干擾畫面刷新的問題。
- 修正目錄中的長標題換行、末尾標點和閱讀百分比顯示問題。
- 從同步位置繼續翻頁後，及時收起回到同步前位置的入口。翻頁失敗或取消時會保留入口。
- 修正開發版本更新時可能略過資料格式變更確認的問題。

- 韌體仍在測試階段，功能可能調整。
