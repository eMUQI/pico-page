## 改进

- 准备休眠图片时，只有再按一次电源键才会取消休眠。触摸屏幕和按 K1、K2、K3 不再取消休眠，也不会操作原页面。
- 出现错误后点返回，回到出错前所在的正文、书库或设置，不再一律进入正文。错误页按钮相应显示「恢复阅读」「返回书库」或「返回设置」。
- 在书库或设置页休眠，唤醒后回到书库或设置。
- 书库、目录、书签、设置等页面刷新时，只更新有变化的部分，减少翻屏时「继续阅读」封面等不变内容的闪烁。按 K2 仍全刷当前画面。

## 更新须知

- 装有 0.2.0-beta.1 的设备不能联网更新，需先在 picopage.wulu.zone 的安装页重新安装。

## 说明

- 这是测试版，功能还可能调整。
- 请只从 picopage.wulu.zone 安装或更新固件。设备无法识别固件是否来自官方，其他来源的固件可能不安全。
