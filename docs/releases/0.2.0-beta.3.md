## 新增

- Wi-Fi 传书可以上传字体（TTF、OTF）和锁屏图片（PNG、JPEG）。字体存入 `Fonts/`，锁屏图片存入 `LockScreens/`；结束传书后不用重启，就能在「排版」中选用新字体。
- 传书网页在上传过程中和上传结束后都可以继续选择文件，电脑上还可以把文件拖到页面任意位置；新加的文件排队依次上传。

## 改进

- 自定义锁屏图片还没准备好时，休眠会先等它准备完成再显示，不再直接改用简洁屏保。等待超过 1 秒时页脚显示提示，这时操作设备可以取消休眠。
- 锁屏轮播跳过损坏或超出限制的图片。
- 锁屏图片无法显示时，唤醒后只在页脚提示一次，不再弹出错误页。
- 传书时设备只刷新二维码下方的状态区。
- 所选字体缺少某个字时，统一显示为空心方格，汉字占一个字的宽度。

## 修复

- 修复 Wi-Fi 传书接收文件时屏幕刷新失败、传输随之中断的问题。
- 修复从书库休眠、锁屏图片未能显示时，唤醒后回到正文而不是书库。
- 修复书库翻到下一屏后「继续阅读」卡片消失。
- 修复 Wi-Fi 密码键盘切换大小写、数字或符号时，按键位置短暂出现横线。

## 升级须知

- 升级后各书的总页数会重新统计一次，阅读进度不受影响。
- 装有 0.2.0-beta.1 的设备不能联网更新，请先在 picopage.wulu.zone 的安装页重新安装。
