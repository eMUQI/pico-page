## 新增

- Wi-Fi 传书支持上传字体（TTF、OTF）和锁屏图片（PNG、JPEG）。字体存入 `Fonts/`，锁屏图片存入 `LockScreens/`。
- 上传的字体在结束传书后即可在「排版」中选用，无需重启设备。
- 传书页在上传过程中和上传结束后都可以继续添加文件，新添加的文件排队依次上传。在电脑上可以把文件拖到页面任意位置。

## 改进

- 休眠画面为「自定义图片」时，如果图片尚未准备好，设备先准备图片，再显示并进入休眠；只有无法准备时才改用简洁屏保。等待超过 1 秒时页脚显示提示，等待期间操作设备可以取消休眠。
- 锁屏图片轮播时跳过损坏的图片，以及文件大小或像素超过上限的图片。
- 无法显示锁屏图片时，设备在唤醒后的页脚提示一次，不再显示错误页。
- 传书状态变化时，设备只刷新二维码下方的状态区。
- 所选字体缺少某个字符时，该字符显示为空心方框；缺少的汉字占一个汉字的宽度。

## 修复

- 修复 Wi-Fi 传书接收文件期间屏幕刷新可能失败，并导致传输中断。
- 修复在书库页休眠且锁屏图片无法显示时，唤醒后可能进入正文而不是回到书库。
- 修复书库翻到下一屏后「继续阅读」卡片消失。
- 修复 Wi-Fi 密码键盘切换大小写、数字或符号时，按键位置短暂出现横线。

## 更新须知

- 更新后，设备重新统计各书的总页数。阅读进度不受影响。
- 装有 0.2.0-beta.1 的设备不能联网更新，需先在 picopage.wulu.zone 的安装页重新安装。

## 说明

- 这是测试版，功能还可能调整。
- 请只从 picopage.wulu.zone 安装或更新固件。设备无法识别固件是否来自官方，其他来源的固件可能不安全。
