## 工作分工

1. 主线：共享 C++17 输入与会话核心、recording display、host 构建与纵向集成。
2. 平台：查找现有 ESP-IDF/EIM，核验官方 BSP 及逐组件许可证，建立并编译最小工程。
3. 存储：真实文件提交/恢复、TOML 配置读取、受限缓存清理。
4. 内容：合成 EPUB 与有界解析探针，核验原书身份和源位置；调研真实 KOReader 协议。

## 验证重点

- 输入序列只消费一次；正文 K2 全刷，面板 K2 安全关闭/取消；忙碌时不积累全刷。
- 显示成功确认才产生可保存记录；书籍、会话、排版、请求代次匹配。
- 帧失败使基准未知；仅 UI 或全刷不增加阅读修订；保存确认对应准确版本。
- 配置出错不重写原文件；缓存清理不删除 prepared/记录/原书；中断写入可恢复有效正式记录。
- EPUB 畸形输入有界拒绝；自己生成的位置不能冒充实际 KOReader 对照。

只为这些有实际风险的行为添加紧凑检查，不为简单转发或构建配置增加测试框架。各模块先运行窄检查，再运行一次集成验证；最终记录区分 host、编译和真机结果。
