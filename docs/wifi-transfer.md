# Wi-Fi 传书

当前实现支持通过设备热点上传 EPUB、UTF-8 或 GB18030 TXT，不需要路由器或预先配置 Wi-Fi。
修正版已安装，手机经设备热点上传 909,849 字节并完成 TF 卡回读校验、保存和退出会话；大文件与异常恢复仍待验收。

1. 在设备上打开“设置 → 网络与传输 → Wi-Fi 传书”。设备先保存阅读进度，再开启热点。
2. 用手机扫描热点二维码，或在手机、电脑的 Wi-Fi 设置中连接屏幕显示的热点并输入密码。
   热点没有互联网连接，请保持连接。电脑也可以直接在浏览器打开 `http://192.168.4.1`。
3. 打开屏幕上的传书页，选择一个或多个 EPUB、UTF-8 或 GB18030 TXT，然后点击“上传”。文件按顺序传输到 TF 卡的 `Books/`。
4. 等待浏览器显示保存成功。上传进度达到 100% 后，设备还需完成写入和回读校验。
5. 在设备上点击“结束传书”。设备关闭热点并重新扫描书库，无需重启。

## 范围与失败处理

- 每个文件为 1 字节至 64 MiB，仅支持 EPUB 和 UTF-8/GB18030 TXT；不提供下载、删除、覆盖或断点续传。
- 同名文件不覆盖。需要导入另一个版本时，先在电脑上改名。
- 网络中断、点击取消或结束传书后，当前文件可能已经保存但未收到回包。请先在书库核对，再重试。
  已成功上传的文件保留；未提交的临时文件在正常退出处理程序时删除。
- 断电可能留下未完成的临时文件。重新上传同名书籍时，设备自动清理该目标的临时文件并从头接收，无需改名或手动清理。
  已保存的正式书籍仍不会被覆盖；临时文件清理失败时，网页明确提示检查存储卡。
- 文件扩展名与传输完整性会检查；EPUB 内容可解析性及 TXT 编码在实际开书时检查。
- TXT 支持 UTF-8（可带 BOM）和 GB18030，不支持 UTF-16 或 KOReader 位置同步。无 BOM 时优先尝试 UTF-8，再尝试 GB18030；其他编码可能误判或无法打开。
- 传书会话期间暂停阅读、同步和自动休眠；用完后请点击“结束传书”。电源键会请求结束会话，再按既有流程休眠。
- K2 始终立即全刷当前画面，不取消传输。结束传书会等待正在执行的存储提交返回，不保证瞬时退出。

## 实现与验收边界

沿用热点与 DNS 服务；HTTP 服务只在用户开启会话时运行。上传使用本次会话的随机令牌与自定义请求头，
不开放跨域访问；文件名限制为单个文件名，存储层另行检查目标路径。
浏览器先发送无文件体的预检查请求；会话失效、正式文件同名或临时文件清理失败时，先显示错误，不发送整本书。
服务端每次接收最多 2048 字节，复用 `FileStore::begin_import`，执行 CRC32、同步、回读与拒绝覆盖的发布流程。
