# Wi-Fi 传书

设备支持两种 Wi-Fi 传书方式，都可上传 EPUB、UTF-8 或 GB18030 TXT：

- **经设备热点**：不需要路由器或预先配置 Wi-Fi。传书期间，手机连着设备热点，暂时不能上网。
- **经已保存的 Wi-Fi**：设备和手机连同一个网络，手机传书时仍能上网。需要先在“Wi-Fi 与同步账户”中保存网络。

经设备热点的修正版已安装，手机上传 909,849 字节并完成 TF 卡回读校验、保存和退出会话；
大文件与异常恢复仍待验收。经已保存的 Wi-Fi 传书、逐本列表和新版配置页尚未在设备上验证。

## 经设备热点传书

1. 在设备上打开“设置 → 网络与传输”。未保存 Wi-Fi 时点“Wi-Fi 传书”，已保存时点“经设备热点传书”。
   设备先保存阅读进度，再开启热点。
2. 用手机扫描热点二维码，或在手机、电脑的 Wi-Fi 设置中连接屏幕显示的热点并输入密码。
   热点没有互联网连接，请保持连接。电脑也可以直接在浏览器打开 `http://192.168.4.1`。
3. 打开屏幕上的传书页，选择一个或多个 EPUB、TXT。选择后立即开始上传，文件按顺序保存到 TF 卡的 `Books/`。
4. 浏览器逐本显示结果。设备屏幕显示已保存的数量和最近一本的书名。
5. 在设备上点击“结束传书”。设备关闭热点并重新扫描书库，无需重启。

## 经已保存的 Wi-Fi 传书

1. 在设备上打开“设置 → 网络与传输”，点“经已保存的 Wi-Fi 传书”。
   设备连接附近信号最强的已保存网络。连接失败时留在本页，页脚显示原因；可以改用设备热点传书。
2. 确认手机或电脑连着屏幕上写明的网络，然后扫描二维码，或在浏览器输入屏幕上的完整地址，
   例如 `192.168.1.23/k7m2qa`。斜杠后的字母和数字每次会话随机生成，只输入 IP 地址打不开传书页。
3. 之后的上传和结束步骤与经设备热点传书相同。

## 传书页

- 选择后整批列出，每本一行：等待、校验中、上传中（百分比和进度条）、保存并回读、已保存或未上传。
- 同名、格式不支持、超过 64 MiB 或空文件标记为“未上传”，跳过这本，继续下一本。
- 连接中断、超时或设备存储出错时整批停止，剩余的书标记为“整批已停止”。
- 上传中途中断的书显示“结果未确认。可能已经保存，请先在书库核对”，并提供“重试”。
  这本书已经保存时，重试会提示书库里已有同名文件。
- 点“停止上传”中断当前这本，其余不再上传。
- 本批结束后显示已保存与未完成的数量，点“继续选择书籍”开始新的一批。
- 电脑浏览器窗口较宽时，可以把文件拖入选择区。

## 范围与失败处理

- 每个文件为 1 字节至 64 MiB，仅支持 EPUB 和 UTF-8/GB18030 TXT；不提供下载、删除、覆盖或断点续传。
- 同名文件不覆盖。需要导入另一个版本时，先在电脑上改名。
- 网络中断、停止上传或结束传书后，当前文件可能已经保存但未收到回包。请先在书库核对，再重试。
  已成功上传的文件保留；未提交的临时文件在正常退出处理程序时删除。
- 断电可能留下未完成的临时文件。重新上传同名书籍时，设备自动清理该目标的临时文件并从头接收，无需改名或手动清理。
  已保存的正式书籍仍不会被覆盖；临时文件清理失败时，网页明确提示检查存储卡。
- 文件扩展名与传输完整性会检查；EPUB 内容可解析性及 TXT 编码在实际开书时检查。
- TXT 支持 UTF-8（可带 BOM）和 GB18030，不支持 UTF-16 或 KOReader 位置同步。无 BOM 时优先尝试 UTF-8，再尝试 GB18030；其他编码可能误判或无法打开。
- 传书会话期间暂停阅读、同步和自动休眠；用完后请点击“结束传书”。电源键会请求结束会话，再按既有流程休眠。
- K2 始终立即全刷当前画面，不取消传输。结束传书会等待正在执行的存储提交返回，不保证瞬时退出。
- 经已保存的 Wi-Fi 传书时，同一网络中的其他设备只要知道屏幕上的完整地址，也能打开传书页。传完请及时结束传书。

## 实现与验收边界

HTTP 服务只在用户开启会话时运行。经设备热点时沿用热点与 DNS 服务；经已保存的 Wi-Fi 时不开热点、
不运行 DNS 服务，传书页只在随机路径上提供。上传使用本次会话的随机令牌与自定义请求头，
不开放跨域访问；文件名限制为单个文件名，存储层另行检查目标路径。
浏览器先发送无文件体的预检查请求；会话失效、正式文件同名或临时文件清理失败时，先显示错误，不发送整本书。
设备用不同的 HTTP 状态码区分只涉及这一本的拒绝和需要停下整批的错误，见 [板级运行说明](platform-runtime.md)。
服务端每次接收最多 2048 字节，复用 `FileStore::begin_import`，执行 CRC32、同步、回读与拒绝覆盖的发布流程。
