# 初版运行说明

## 桌面版

在仓库执行 `sh tools/run_host.sh`。它使用当前工程的原生 C++ 阅读逻辑，打开 684 × 1216 灰阶画布。显示窗口只是硬件显示接口的替代，不代表墨水屏波形、残影、触摸或耗电已经验收。

依赖：CMake 3.20+、C/C++17 编译器、Python 3.11+、pkg-config、SDL2、OpenSSL 和 libcurl。本机现有环境已验证。Linux 可用系统包 `libsdl2-dev libssl-dev libcurl4-openssl-dev pkg-config`；Linux host CI 已有运行记录，具体批次见开发状态；CI 不验证 SDL 交互和真机行为。字体及 FreeType 由 `tools/setup_fonts.py` 下载固定版本并核对 SHA-256，不会安装或替换全局工具链。

1. 启动后，书库直接显示 `Books/` 内的书和文件夹；如需阅读子文件夹中的书，先进入对应文件夹。
2. 点击一本 EPUB，等待正文显示。成功显示后才写入进度。
3. 点击左侧或按 K1 上一页，点击右侧或按 K3 下一页。
4. 点击中部打开工具。K2 在所有可交互页面全刷当前画面，不移动阅读位置。
5. 在排版面板调整参数。步进只改变预览，按钮的作用如下：
   - 「应用」：保存为此书的覆盖设置。
   - 「设为阅读默认」：修改全局设置。
   - 「恢复默认」：将预览改为全局值；仍需点「应用」才删除此书的覆盖设置。
   - 「取消预览」或「收起」：放弃预览。

   K2 只全刷当前画面，不取消草稿。
6. 书库中的最近阅读会使用已保存位置。空格可在桌面版模拟睡眠和唤醒。

打开排版或刷新面板时会重新读取设置文件。排版以最新有效文件作为草稿；取消仍保留正在阅读的排版和位置。文件无效时停止编辑并保留原文。单独更改刷新档不会覆盖或立即应用电脑手改的字体、行距等参数。「恢复默认」后仍可继续调整；应用会保留最终草稿值，其余与全局相同的字段恢复继承。

关闭窗口会重试保存尚未保存的进度；遇到保存错误应先使用设置中的重试入口并检查卡目录。演示内容是原创测试文字，不包含个人 EPUB。原始 EPUB 不被改写。

## 设备用卡和固件

本地演示卡位于 `.local/card`。实际卡需 FAT 文件系统，推荐按以下结构准备：

```text
Books/                         EPUB、TXT；文章可放 Books/Articles/
Fonts/                         用户字体和各自许可证
PicoPage/settings.toml          普通阅读配置
PicoPage/network.toml           私密 Wi-Fi 配置，可选
PicoPage/sync.toml              私密 KOSync 配置，可选
```

将演示卡中的字体和许可证复制到实际卡对应目录；按需复制 EPUB 和配置，不能覆盖已有个人数据。正文默认字体可写 `Fonts/LXGWWenKai-Regular.ttf`。内置字库只保障 UI 和错误提示，不能代替完整中文字库；TF 卡上没有可用正文字体时，正文使用内置字体（3,500 个常用字，见[字体说明](graphics-runtime.md)）。页面包含内置字体未覆盖的字符时照常显示，缺少的字符显示为方框，状态栏提示复制完整字体。偏好字体缺失而备用完整字体存在时会明确提示回退。

`sh tools/build_firmware.sh` 生成 `firmware/build/pico_page.bin`。本地构建使用 `partitions.build.csv` 的 4 MiB 单应用配置（与设备 ota_0 槽同大），以容纳 EPUB、字体、Wi-Fi 和 TLS。实际读取的设备为两个 4 MiB OTA 槽，与本地 CSV 不同。**当前不要直接执行构建日志中的 flash 命令。**作者设备的核对过程、写入范围和当前状态见[设备检查记录](device-validation.md)和 [开发状态](development-status.md)。

## 手动 KOReader 接续

详细字段、来源和映射限制见 [同步实现记录](sync-runtime.md)。在私密的 `PicoPage/sync.toml` 中配置服务及账户；设备联网还需[平台说明](platform-runtime.md) 中的 `PicoPage/network.toml`。这两个文件已被 Git 忽略，不要混入普通配置导出或公开日志。主机使用现有网络，不读取 Wi-Fi 配置。

1. 两端使用内容完全相同的原始 EPUB，并确认配置的 CREngine DOM 版本与 KOReader 相符。
2. 打开工具中的同步，点击「检查远端位置」。检查不会自动跳转或上传。
3. 精确映射成功时，可选择跳转。只有目标正文实际显示成功后，才保存新位置。
4. 要以本机位置更新远端，点击上传并再次确认。仅发送已保存版本。
5. 取消会停止尚未发送的任务，并丢弃旧回包。已经发出的上传仍可能在服务端生效；结果不确定时先重新检查，不自动重试覆盖。

当前对照覆盖普通 XHTML、中文、内联元素、空白、非 BMP 字符和跨章位置。普通 CSS、DOCTYPE 和两个公开鲁迅 EPUB 的正文已纳入实际引擎对照；媒体及复杂 CSS/DOM 仍有明确拒绝范围，详见同步记录。真实 KOReader 客户端、账户服务与 Read Pico 的双向接续没有完成验收。

## 初版限制

- 正文采用有界分段解析，当前页优先排版；有效长章节可跨段处理，不因整章超过单段预算而拒绝。首次原文件 SHA-256 校验需要顺序读整书。
- EPUB 样式使用统一正文排版。PNG、基线 JPEG 及受支持的简单 SVG 图片容器作为独立内容块参与分页，按原图比例绘制；图片前后的文字可排在同一页，文字不环绕图片，只含一张图片的章节使用整个正文区域。缺失、损坏或不支持的图片显示明确占位，保留媒体元素锚点，允许继续阅读。具体图片资源限制见 [图片实现](image-runtime.md)；表格、复杂 SVG 和 CSS 仍有降级或拒绝范围。
- 已有列表/封面卡片、目录折叠、电量状态、单本详情、USB 文件传输和 Wi-Fi 传书；Wi-Fi 密码和同步账户的设备端输入尚未在真机验证。设备短按电源使用浅睡，不等于断电关机。
- 设备屏幕方向、物理全刷、触摸热区、SD 异常、内存峰值、掉电恢复与睡眠耗电均待真机验证。
- 桌面图像是实际渲染输出；不能作为真机可用性的替代证据。

图片页与正文共用页面规划，用于正常呈现、上一页重建和排版预览。图片的预览、K2 全刷和重新开书保留同一源锚点；只有真实呈现成功后才确认并保存新的阅读位置。

## 刷新与休眠设置

阅读工具中的「刷新」修改当前书的设置；设置首页中的「显示与刷新」修改阅读默认，保留本书已有覆盖。均衡与快速的自动全刷间隔可分别设为 1–30 页，清晰模式每页全刷。选择快速后须点「改用快速」；K2 只刷新当前画面，不确认、不保存、不取消。

在「设置 → 电源与休眠」选择书籍封面、保留正文、简洁屏保或自定义图片，调整休眠时间后点击「保存设置」。0 表示关闭自动休眠；取消保留原设置。无可用封面时使用书名和作者，保存失败时不进入休眠。可手改全局 `[power]` 的 `auto_sleep_minutes`（0–240）和 `sleep_screen`（cover/reading/simple/custom）；自定义图片使用 `sleep_image` 指定文件名，空字符串为轮播。刷新间隔分别为 `[display]` 的 `balanced_full_refresh_pages` 与 `fast_full_refresh_pages`。旧固件会将新增字段视为不支持；回退固件前应备份并检查配置。

长按书库中的一本书进入单本信息。查看详情会校验所选原书，较大的 EPUB 可能需要等待；此操作不改变当前书的已保存位置。


## 书籍管理

长按书库中的一本书，进入书籍详情。「清理本书缓存」只清理本书内存封面与分页起点，不删除用户记录，也不承诺释放 TF 空间。「清除本地阅读进度」与「删除原书文件」均需屏幕确认，K2 不执行确认。清除后下次从头阅读，远端记录不变；删除原书保留伴随目录，重新放回相同 EPUB 后可恢复记录。若提示外部修改或操作未完成，请检查文件并重新打开详情核实，不把失败当作已经删除或清除。清除状态采用 schema 2，旧固件会拒绝打开该记录；格式及部分失败边界见 [存储约定](storage.md)。

自定义图片放入 TF 卡 `LockScreens/` 根目录，在「选择图片 / 轮播」页选择后返回并保存。支持 PNG/JPEG，推荐 684×1216；文件不超过 2 MiB。保存后留在设备界面等待空闲转换。缓存未就绪或图片不可用时本次显示简洁屏保，唤醒后提示。完整限制见 [R4](roadmap.md#r4--自定义锁屏)。
