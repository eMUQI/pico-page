# 可用初版实施任务

用户在 G0/G1a 交付后明确要求能够直接运行使用的初版本。本轮目标扩大到真实阅读完整流程，不再使用 CODEX_START 中的首批阶段终点作为停止条件。

## 必须贯通

- 同一 C++ 程序在 host 预览和 ESP-IDF 上使用原 EPUB、真实字体、完整行分页。
- 卡上文件入口、打开/翻页、目录、工具、排版应用/取消、刷新模式、K2 立即全刷。
- 成功显示后保存、重开恢复；设置修改保护外部编辑与原文；失败有可见状态。
- Read Pico 官方驱动接入，读取工厂校准，显示/输入/TF/休眠遵循实际硬件接口。
- KOReader 内容身份、真实源位置对照与 KOSync 候选/确认流程；不得把 HTTP 成功当接续完成。
- 按原设计截图核对，交付构建/启动/卡文件准备说明及实际运行证据。

## 并行分工

平台适配、原生 EPUB 后端、字体与灰阶绘制分别实现；主线负责应用编排、现稿界面、配置保存、host 可执行程序、固件入口及集成。后续同步模块单独核对协议与上游客户端。
