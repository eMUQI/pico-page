# 离线词典界面优化

2026-10-24 确认的实现范围。沿用现有黑白、方角与正文字体，不新增阅读后端。本文记录设计约束；完成状态与验证结果见开发状态。

- 释义面板根据最终选区选择上方或下方，避免遮挡选中的文字。拖动期间隐藏面板，松手后查词；正文位置保持不变。
- 选区采用反色文字、细连接线与圆形端点。可见端点与触摸区域分离，保留宽裕热区，不改变跨行、交叉端点与输入取消规则。
- 面板顶部放词头、释义页码和关闭；底部相连按钮表依次为选区范围、来源（可打开词典选择列表，显示当前来源在启用列表中的位置）和翻页／展开（2026-10-28 D48 修订）。
- 成功结果不常驻重新查询；错误提供重试。只有存在多个词条结果时才提供词条切换，编号不得与词条正文中的编号义项混淆。
- 展开／收起以当前释义文本位置衔接，不跳回词头。旧位置和布局在新排版成功前保留，失败后可重试或退出；新布局仍可向前访问全部释义。
- 词典选择列表直接选择启用来源，显示名称与当前状态；取消恢复原结果。管理入口沿用现有词典管理，返回时保留正文与选区。无词典时提供配置入口。
- 全屏释义不显示正文统计页脚；关闭恢复原正文底图和进度。K2 保持立即全刷，K1／K3 在释义中只翻释义，在列表中翻列表。

实施复用既有 ContentJob、字体与绘图组件，不新增任务或长期整屏画布。词典元数据扫描和释义重排在原 worker 中执行，沿用代次校验、取消和资源准入。个人书籍与私有词典不提交；设计稿中的释义和正文仅为排版示意。

验收覆盖上下方面板、圆形端点拖选、多词典选择及取消、管理往返、单条与多条结果、长释义展开／收起和翻页失败恢复。复用现有 app／dictionary 回归、host Debug／sanitizer 与标准固件构建，另以真实书籍生成本地画面对照；真机触摸和显示效果单列。
