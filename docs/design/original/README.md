# Pico Pages · 界面交接包 v1

项目名：**Pico Pages**（暂定）。运行于 Read Pico 硬件的 EPUB 阅读固件。

日期：2026-10-05
对象：固件 UI 实现（Codex 或开发者）
配套：《Read Pico 阅读固件：程序架构设计 v0.1》《界面设计交接说明 v0.1》

本目录是 `reader_ui` 的实现依据。数值以 **684 × 1216 竖屏设备像素** 为单位，未经真机验证，全部可调。

## 阅读顺序

1. 本文件：范围、边界、实现顺序
2. `tokens.json`：灰阶、字号、间距、线宽、尺寸
3. `input.md`：触摸分区、K1/K2/K3、命中与防穿透规则
4. `screens.md`：每个页面与状态（S01–S12），附对应 PNG
5. `actions.md`：语义动作表（★ 为建议新增，需架构侧确认）
6. `fields.md`：UI 依赖的状态字段，含建议新增项
7. `copy.md`：全部界面文案，按页面编号
8. `png/`：原像素状态图，文件名即状态编号，如 `S02-3.png`
9. `reference/`：设计稿源文件，仅作对照，**不要从中复制代码或示例数据**

## 硬约束

- UI 只发送语义动作、渲染状态快照；不直接访问 SD、NVS、HTTP 或 EPD 驱动（架构 §3、§4）。
- 刷新由 `reader_display` 决定。UI 只提交更新区域与意图（见 `screens.md` 每节的“更新区域”）。
- 不做任何动画、滑入、淡出、旋转加载、骨架屏或惯性滚动。一次交互只提交一次最终帧。
- 状态不能只靠灰度区分：选中、禁用、忙碌、错误都至少有两种非灰度特征（虚线、加粗、反相、文字、符号）。
- 示例数据（书名、百分比、时间、地址）只用于画面。所有值来自真实字段，未知就显示“未知”或留空，不伪造。
- 首版不出现：书城、推荐、统计、深色主题、PDF/Karakeep 入口、设备端 EPUB 转换。

## 已确定的交互决定

- 工具面板：顶栏（返回书库 · 书名 · 同步状态）+ 底部一行五个入口（目录 / 排版 / 同步 / 刷新 / 全刷）；子面板用标签页切换，一次只有一层。
- 排版：参数格 + 单个步进器；步进只预览当前屏，点“应用”才全书重排。作用域默认“此书”。
- **阅读页 K2 = 立即全刷**。工具面板只能轻点正文中部打开；面板内 K2 = 关闭。
- 冲突：手动同步发现时直接进入 S07；自动检查发现时只标记顶栏状态。
- 休眠画面默认显示书籍封面，无封面时显示文字默认封面。
- 书库支持列表 / 卡片两种视图（全局偏好）。
- Wi-Fi 只支持 2.4 GHz。

## 建议实现顺序

| 阶段 | 内容 | 对应 |
|---|---|---|
| 1 | tokens、基础组件（按钮、列表行、顶栏、标签栏、步进器、提示） | tokens.json、screens.md §组件 |
| 2 | 阅读页 + 工具面板 + 排版 | S02、S03、S05 |
| 3 | 同步状态与冲突 | S06、S07 |
| 4 | 目录、刷新设置 | S04、S08 |
| 5 | 书库与单本详情 | S01 |
| 6 | 连接导入、设置、休眠、通用提示 | S09–S12 |

每个阶段的验收：主机预览中所有列出的状态都能复现；近似黑白下仍可区分选中与禁用；没有一次操作多次提交帧。刷新效果、残影、触摸手感只以真机为准。
