## S05 排版（标签页）

进入排版时顶栏收起，让出预览区。

| 编号 | 状态 | 要点 |
|---|---|---|
| S05-1 | 当前值 / 预览 | 左上标签“当前排版”或“预览 · 尚未应用”；“已应用”虚线不可点；恢复默认只改数值 |
| S05-2 | 重排中 | 左上反相“正在重新排版”；参数全部禁用；“取消，恢复原排版” + 禁用“重排中” |
| S05-3 | 字体不可用 | 字体名删除线 + “字体不可用”；预览用替代字体；“无法应用” |
| S05-4 | 进阶 | 参数格换成“‹ 基本 · 段距 · 首行缩进”；段距 0–1 行步长 0.2；缩进 0/1/2 字 |

更新区域：预览区 + 参数格 + 步进器（连续点击合并）；应用完成后整屏。

## S06 同步（标签页）

三格对应 `save_state` / `sync_state` / `remote_candidate + mapping_quality`。

| 编号 | 状态 | 顶栏状态 | 主要操作 |
|---|---|---|---|
| S06-1 | 未配置 | 描边“未配置” | 设置同步（→ S10-2） |
| S06-2 | 离线待同步 | 描边“待上传” | 检查并同步（可点）；接续/上传禁用“需联网” |
| S06-3 | 进行中 | 描边“同步中” | 禁用“同步中”；取消同步；阶段“第 1 步 / 共 2 步” |
| S06-4 | 已上传 | 描边“已上传” | 只在服务器确认后显示；不写“另一台设备已同步” |
| S06-5 | 鉴权失败 | 反相“登录失效 ›” | 重新配置 |
| S06-6 | 定位无法映射 | 描边“未能对应” | 保留此处 / 转到附近（约 N%），附近跳转前压入历史 |
| S06-7 | 原书不匹配 | 描边“暂未同步” | 查看书籍详情；不提供按文件名匹配的快捷开启 |

更新区域：状态三格 + 顶栏状态。

## S07 同步冲突

手动同步或上传发现不同位置时直接出现；自动检查只标记顶栏（S03-2）。K1/K3 不作用，K2 = 继续此处。

| 编号 | 状态 | 要点 |
|---|---|---|
| S07-1 | 可解析 | 此设备 / 另一设备两卡；按钮等权重；“继续此处”不改动服务器；底部“上传此处，替换远端位置 ›” |
| S07-2 | 仅近似 + 时间未知 | 无章名只显示约 N%；“章节无法确认 / 阅读时间未知 / 本机收到 10:42”；按钮“转到附近位置” |
| S07-3 | 操作中 | 本机卡虚线“已记入跳转历史”；取消 / 禁用“跳转中” |
| S07-4 | 上传替换确认 | 说明替换前后的值；不删除另一设备的记录；取消 / 上传并替换 |

## 已知偏差与待验证

1. 20px 小标签与禁用原因低于交接说明辅助信息 22px 下限，建议真机检查后统一到 22px。
2. 目录行高 86px，略低于 88px 热区起点。
3. 浅灰分隔线 #CFCFCF 在近似黑白下消失，快速模式需实看。
4. 唤醒来源、K1/K2/K3 实际排列待板级确认。
5. 提示阈值、自动全刷间隔、翻页区宽度、扫描计数刷新频率均为占位值。
6. 图标仍为文字符号。
