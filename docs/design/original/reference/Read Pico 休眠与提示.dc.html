S12 · 通用提示组件
提示分四级：普通提示、警告、可重试错误、不可恢复错误，另有确认框。每一级只配一个最相关的下一步。模态框打开时，K1/K3 不作用于背后的正文；K2 执行安全关闭或取消。以下组件按 684px 宽、实际高度绘制。
S12-1 · 普通提示（不打断）
已从本机删除轻触关闭
贴在底部，不遮正文中部。不定时自动消失，因为消失本身也要刷新一次；它会在下一次操作（翻页或点按）时一并清除。
S12-2 · 警告（低打扰）
!
暂时无法连接，不影响继续阅读
详情
用于自动操作失败，例如自动同步。用反相方块里的“!”加文字区分，不只靠颜色。阅读页上更常见的形式是只改变顶栏状态，不弹出这一条。
S12-3 · 可重试错误
此处尚未保存，请检查存储
写入存储卡失败。当前页仍可阅读，翻页后会再尝试保存。
重试
关闭
标题直接写结果，说明里写原因和现在的状态。主按钮放在左侧，用反相。不写“数据已丢失”之类无法确认的结论。
S12-4 · 不可恢复错误
这本书无法打开
阅读包已损坏，需要在电脑上重新处理后再导入。本机阅读位置已保留。
返回书库
导出诊断信息
不提供“重试”，只给一个去处。诊断导出是次要的文字链接，不和主按钮并列。
