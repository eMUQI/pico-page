# 输入与热区

## 阅读页触摸分区（初始值）

```
┌──────────┬──────────────┬──────────┐
│  上一页  │   打开工具   │  下一页  │
│   30%    │     40%      │   30%    │
├──────────┴──────────────┴──────────┤
│ 页脚 88px：点按切换 本章页码/全书百分比 │
└────────────────────────────────────┘
```

- 左右轻扫为辅助翻页。宽度与手势阈值待握持测试，可在设置中调整。
- 设计稿中不绘制分区边框（见 `png/` 中的热区标注仅为说明）。

## 命中规则

1. 显式命中区（脚注、链接、图片、按钮）优先于背景翻页区。脚注热区 ≥ 88 × 88，可见标记更小。
2. 一次输入只执行一个动作：滑动不触发脚注；抬手关闭面板不穿透成翻页。
3. 打开面板或模态框后，第一次抬手只用于关闭，不传给下层。
4. 唤醒输入只唤醒，被吞掉，不传给任何页面。
5. 正文长按首版不绑定功能。重要动作都有可见入口。
6. 重排中、跳转中、同步中的按钮禁用，不排队提交。
7. 首版不用长按区分功能，不支持组合键；多键同时触摸时忽略本次输入。
8. 误触过滤（最短接触时间、最小间隔）由真机测试确定。

## 电容键 K1 / K2 / K3

K1/K2/K3 为逻辑命名，实际空间顺序与标识待板级确认。

| 场景 | K1 | K2 | K3 |
|---|---|---|---|
| 正文阅读 S02 | 上一页 | **立即全刷**（ForceRefresh）。全刷进行中时忽略；有返回条时也不执行返回 | 下一页 |
| 工具面板 S03 | 不作用 | 关闭面板 | 不作用 |
| 排版 S05 | 不作用 | 收起并恢复原排版（= 取消） | 不作用 |
| 目录 S04 / 书库 S01 | 上一屏 | 收起 / 返回上层 | 下一屏 |
| 冲突 S07、确认框 S12 | 不作用于背后 | 安全选项（继续此处 / 取消） | 不作用于背后 |
| 传输 S09 | 文件列表上一屏 | 结束传输（有写入时先确认） | 文件列表下一屏 |
| 休眠 S11 | 以板级确认的唤醒来源为准，唤醒后吞掉本次输入 | 同左 | 同左 |

后果：只靠三个按键无法打开工具面板；脚注返回只能点顶部返回条。
