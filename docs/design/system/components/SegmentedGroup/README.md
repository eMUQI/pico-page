# SegmentedGroup

相连的一组选择格，格与格共用边线，当前项为 `ink` 黑底，用来在少量互斥选项中切换。

依据 `firmware/components/reader_app/app_library.cpp` 的列表／卡片切换与 `app_impl.h` 的 `tabs()` 整理；电源页休眠样式按 D47 采用本组件，固件尚未实现。

## 结构

- 外框和格间分隔线均为 2 px `ink`，格子之间没有空隙。
- 当前项为 `ink` 黑底，文字用 `paper`、加粗；其他格为白底 `ink` 文字。
- 可排成一行（「列表｜卡片」、工具标签）或网格（电源页休眠样式 2 × 2，每格 306 × 92）。
- 尺寸随所在位置：书库工具行用紧凑规格（可见 60 px、文字 22 px，热区 88 px）；页面中的选择组用普通规格（格高至少 88 px、文字 28 px）。

## 规则

- 只用于互斥、少量（2–4 项）、点按即切换当前项的选择。选项多于 4 个，或需要说明文字时，用 ChoiceRow。
- 黑底在这里表示「当前项」，与单独主按钮的「推荐操作」靠结构区分：选择格总是相连，主按钮总是单独摆放。同一组内只有一格黑底。
- 不用本组件表示开关；开关用 ValueRow 的切换行。
- 调用方提供选项文字、当前项、每格尺寸和动作 ID。
