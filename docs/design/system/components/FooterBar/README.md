# FooterBar

从 y 1120 起的 96 px 页脚，供翻屏条和页面提示共用。

依据 `firmware/components/reader_app/app_impl.h` 的 `footer_bar()` 手写的静态示意。

## 规则

- 翻屏分区与正文点按区一致：x 205 左侧为上一屏，x 479 起为下一屏，以 2 px `ink` 竖线分隔。文字从 x 36 起、到 648 止。
- 中间以 `secondary` 显示「N / M」。有多屏时提示暂时占用中间，两侧翻屏保留。
- 不可用的方向留空，不注册热区。
- 只有一屏且有提示时，提示横跨整行；两者都没有时页脚为空，也不画横线。
- 下一次输入清除提示；K2 不清除。
- 提示写明发生了什么和下一步，使用 `description`：「进度未保存，请检查 TF 卡后重试」。
