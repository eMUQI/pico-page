# TypographyGrid

排版面板的 4 × 2 参数格，下方一个步进器调整当前选中的参数。

依据 `firmware/components/reader_app/app_settings.cpp` 中排版面板绘制代码手写的静态示意。

## 结构

- 每格 150 × 80，间距 12 px（`space-12`），占 x 24–660；两行位于 y 780 和 872。
- 格内上方为名称（`description`），下方为当前值（24 px 粗）。
- 选中格为 3 px `ink` 外框；其他格和「恢复默认」为 1 px `ink` 外框。
- 步进器位于 y 976：「−」「+」为 150 × 88 的按钮，符号 40 px，分别对齐第一列和最后一列；中间数值使用 `title`。

## 规则

- 到达范围边界时该侧步进键不可用：不画框，符号用 `disabled`，无热区。
- 步进只预览当前屏。「应用到此书」（主按钮）正式保存；「设为阅读默认」为次按钮。
- 范围：字号 28–56 按 2，行距 1.35–1.65 按 0.05，页边距 24–52 按 4，段距 0–1 行按 0.2，首行缩进 0／1／2 字。
