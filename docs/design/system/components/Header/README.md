# Header

104 px 顶栏：左侧返回格写明上一级页面，后接粗体页面标题，底部为 3 px `ink` 横线。

依据 `firmware/components/reader_app/app_impl.h` 的 `header()` 和 `app_drawing.cpp` 的 `reading_header()` 手写的静态示意。

## 结构

- 返回格：「‹ 」加上一级名称（「‹ 书库」「‹ 设置」，工具面板上为「‹ 正文」），x 28，`label`。从左端到标题前都是热区。
- 标题：`title`（32 px 粗），在返回格后 28 px，中间不加竖线。书库子目录保留「‹ 上一级 | 文件夹名」。
- 阅读顶栏：章节名用 `reading-chapter`（本书正文字体，粗体），下方书名与百分比用 `reading-meta`、`secondary`。
- 徽标：黑底标签（148 × 54，文字 `caption`），只用于读者需要处理的状态：「尚未保存」「位置不同 ›」。徽标可点，点按进入同步面板。

## 规则

- 标题过长时以单个「…」截断，不换行。
- 调用方提供标题、上一级名称及返回动作，并通过 `right_edge` 为右侧操作格留出位置。
