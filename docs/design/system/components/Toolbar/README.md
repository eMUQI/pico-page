# Toolbar

阅读工具页底部 136 px 的一行五个入口，每格为 40 px 绘制图标加 28 px 文字。

依据 `firmware/components/reader_app/app_bookmarks.cpp` 的 `draw_toolbar()` 和 `app_drawing.cpp` 的 `tool_icon()` 手写的静态示意。

## 入口

| 入口 | 图标（固件绘制） |
|---|---|
| 目录 | 三条 30 px 横线，线宽 3 px，间距 9 px |
| 排版 | 文字「Aa」 |
| 同步 | 上下箭头，线宽 2 px |
| 刷新模式 | 左半实心的圆环 |
| 全刷 | 3 px 方框内一个实心块，表示整屏重画 |

## 规则

- 每格宽 137 px（最后一格 136），格间为 2 px `ink` 分隔线，顶部为 3 px 横线。所有文字使用 `label`（28 px）；「刷新模式」宽 112 px，放得下。
- 工具栏只在点按正文中区时打开；下方正文不重排。
- 图标由固件按像素绘制，不读取文件。新增图标保持 `icon-visual`（40 px）和 2–3 px 线宽。
- 入口及顺序固定，调用方无需提供参数。
