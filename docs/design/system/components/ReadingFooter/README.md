# ReadingFooter

正文下方从 y 1128 起的 88 px 页脚：左侧为阅读位置，右侧为电量或时钟，点按切换。

依据 [UI 说明](../../../../development/ui-implementation.md)「阅读页脚」和 `reading_footer.h` 手写的静态示意。

## 规则

- 左侧循环：全书页码／总页数 → 全书百分比 → 章节序号／总章节数 → 当前章节名 → 不显示。右侧循环：电量 → 时钟（HH:MM，UTC+8，未知时为「—」）→ 不显示。左侧热区 x < 540，右侧 x ≥ 540。
- 统计完成前百分比四舍五入为整数（「27%」）；完成后保留两位小数（「5.00%」）。
- 统计页数期间显示「正在统计页数」，失败显示「页数未知」。页数不阻塞正文。
- 电池为 46 × 22 px 外框加 3 px 端子，线宽 2 px，整体右边界 x=648，不显示百分比。内部固定五个位置，每格 6 × 14 px，间距 2 px，四周内缩 4 px；只从左向右绘制剩余的实心格，没电的位置留白，不画空格边框。0% 显示空框，1–20%、21–40%、41–60%、61–80%、81–100% 分别显示一至五格；格数仅表示大致余量，不代表续航时长或读数已校准。
- 充电时以静态闪电替代全部电量格。没有有效电量且未报告充电时隐藏图标，不显示问号，也不以空框代替未知读数；保留原热区。
- 实心格使用灰阶 5（#555555），外框、端子和充电闪电保持灰阶 3（#333333）；浅色只用于降低填充的视觉重量，不表达不可用状态。
- 隐藏的一侧保留空白和热区，正文不扩展到页脚。
- 页脚提示显示在左侧，下一次输入时清除。
