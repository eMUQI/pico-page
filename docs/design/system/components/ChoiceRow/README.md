# ChoiceRow

116 px 单选行：选中时填实的圆环、粗体标题和一行说明，选中行右侧显示状态文字。

依据 `firmware/components/reader_app/app_impl.h` 的 `choice()` 手写的静态示意。

## 状态

| 状态 | 圆环 | 状态文字 |
|---|---|---|
| 已选中并保存 | 实心圆点 | 「当前」，`description`，`ink` |
| 已选中、尚未保存 | 实心圆点 | 「待保存」，`description`，`ink` |
| 未选中 | 空心圆环 | 无 |

## 规则

- 一个含义一个标记：圆点表示选中哪一项，文字表示是否已保存。行和文字都不加外框或黑底。
- 圆环直径 36 px、线宽 3 px，圆心在 x 62；选中圆点直径 20 px。除词典选区端点外，这是界面中唯一的圆形（`radius-round`）。
- 标题 `label-strong`，说明 `description`、`secondary`。右侧留 120 px 给状态文字。
- 选择后立即生效的列表（如 Wi-Fi 连接方式）不显示状态文字。
- 文件列表：从一列文件中选一个时（字体选择、锁屏图片），改用文件行：名称在左，`label`（不加粗）最多两行；状态文字和圆圈在右，圆圈线宽 2 px、圆心 x 624；行高 90 px，有说明时 116 px；行下有 2 px `rule` 分隔线。读者先看到文件名，圆圈作为次要标记。同一页的其他选项（如「按文件名轮播」）也用文件行，不与左侧圆点的标准行混用。
- 分开摆放的选项按钮不用黑底表示选中，一律改用本组件。
- 调用方提供标题、说明、y、是否选中以及选择是否待保存。
