# 设计系统

Pico Page 运行在 Read Pico 墨水屏阅读器上：684 × 1216 竖屏、16 级灰阶、三个按键（K1、K2、K3）和触摸。本文是设备界面的视觉规范，所有规则服务于同一目标：当前页清楚易读、操作立即响应，读者始终知道阅读位置是否已保存。

除另行说明外，尺寸均为 684 × 1216 画布上的**设备像素**。[`tokens.json`](tokens.json) 记录全部色值、字号、间距、线宽和尺寸；[`components/`](components/) 下每个组件有使用规则（`README.md`）和可在浏览器中打开的静态预览（`preview.html`，按半尺寸显示）。

产品取舍以[产品决定](../../planning/decisions.md)为准；页面行为、输入和刷新以 [UI 说明](../../development/ui-implementation.md)为准；本文维护颜色、字体、线框、尺寸与组件外观。[原始设计](../original/README.md)只作历史基线。

## 原则

- **纸面优先。** 白色 `paper` 底、`ink` 文字、方角。不做深色主题、渐变、阴影，设备界面不用彩色。
- **一次交互只提交一帧。** 不做动画、滑入、淡出、旋转加载、骨架屏或惯性滚动。唯一的动态是可选的「水波纹」翻页效果，默认关闭。
- **状态不只靠灰度区分。** 选中、不可用、忙碌和失败除灰度外还要有形状差异：有无外框、线宽、圆点、符号或文字。近黑白刷新时 `disabled` 会显示为黑色，此时仍须分得清。
- **可点就有框。** 读者能点的控件一定有 `ink` 外框或 `ink` 底色。不可用控件去掉外框，文字改用 `disabled`，不注册热区。
- **一个含义一个标记。** 不用外框、底色和标签重复表达同一状态。单选圆点表示选中，文字说明是否已保存。
- **只用实线（D39）。** 不使用虚线。
- **只显示运行时数据。** 书名、时间、百分比和地址来自真实字段；未知时显示「未知」「—」或留空，不编造。

## 文案

界面使用简体中文，按 [Tech-Doc-Style-Chinese](https://github.com/Fenng/Tech-Doc-Style-Chinese) 书写：准确、简洁、克制。

- 控件名、网络名和引用文字用「」，嵌套用『』，如「应用到此书」。
- 中文与英文、数字之间留半角空格：「38 px」「TF 卡」「Wi-Fi 设置」。
- 存储介质统一称「TF 卡」，不写「存储卡」。
- 错误与空状态写清发生了什么、影响和下一步，只陈述已确认的原因：「进度未保存，请检查 TF 卡后重试」。
- 保存状态只有「已保存」和「尚未保存」，未收到确认不得宣称已保存。
- 加载中的短标签保留单个「…」；截断也只用一个「…」。
- 不拆开英文单词、数字和路径，结束标点不置于行首。
- 任务名、锚点、驱动错误码和英文库错误只写入日志。
- 不用 emoji。使用的符号：「‹」返回、「›」进入子页、「·」分隔、「−」「+」步进。

## 颜色

设备使用面板 16 级灰阶中的五级（0 为黑，15 为白）。引用名称，不直接写灰阶编号。

| 名称 | 灰阶 | 用途 |
|---|---|---|
| `ink` | 1 | 文字、所有控件外框、主按钮底色、当前标签、顶栏徽标、状态文字 |
| `secondary` | 3 | 说明、提示、阅读顶栏书名、页数 |
| `disabled` | 5 | 不可用控件文字（不画框）；分组标签；未进行的检测格外框 |
| `rule` | 12 | 只用于 2 px 列表分隔线，装饰用 |
| `paper` | 15 | 背景；黑底上的文字 |

- 正文和界面文字使用 `ink` 或 `secondary`，置于 `paper` 上；黑底上的文字使用 `paper`。
- 控件外框一律用 `ink`。较浅的灰在近黑白刷新时会消失或变黑，不能承担控件轮廓。
- `rule` 在近黑白刷新时会消失，不得用来表示状态。
- `site-*` 只用于官网。`site-accent` 是整套设计中唯一的彩色，不得用在设备上。

## 字体

- **正文：`body` 字体族（霞鹜文楷）。** 用于书籍正文、章节标题、阅读顶栏和书库中的书名。默认 `body` 为 38 px、行距 1.5；读者可在 28–56 px 间按 2 调整，行距 1.35–1.65 按 0.05 调整。书内目录、章节名和书签摘录使用本书所选的正文字体。
- **界面：`ui` 字体族（思源黑体 / Noto Sans SC）。** 用于菜单、按钮、状态、错误和帮助；内置子集为「Pico Page Fallback」，共 4,085 个字符。界面字号不随正文字号变化。
- 界面文字行高为字号 + 8（`space-8`）。页面标题、数值、当前标签和单选标题加粗，不用斜体。
- 界面字号只有四档，按角色选用，不按空间临时缩放：`title` 32 粗（页面标题、步进器数值）· `label` 28 与 `label-strong` 28 粗（所有控件与行标题）· `description` 24（第二行、数值、提示、页脚、状态文字）· `caption` 20（只用于顶栏徽标、书签格等尺寸固定的位置）。放不下时缩短文字或加宽位置，不缩小字号。阅读字号（`chapter-title`、`body`、`reading-chapter`、`reading-meta`）不在此列。
- 缺字显示为空心方框，固件不逐字混用其他字体。正文缺字时提示「部分字符无法显示，可在排版中更换字体」。

字体文件不随本目录提交：界面字体见 `firmware/components/reader_graphics/fonts/PicoPageFallback.otf`；正文字体来自 `web/public/downloads/LXGWWenKai-Regular-v1.520.zip`，在线设计系统中的「Pico Page WenKai」是按固件 `common_characters.txt` 与 `fallback_characters.txt` 用 `pyftsubset` 生成并改名的 WOFF2 子集，遵循 OFL 1.1。

## 布局与间距

- 网格单位 4 px（`space-4`）。带框元素占 x 24–660（`space-24`）；文字从 x 36 起、到 648 止（`space-36`）。
- 固定区域：顶栏 0–104（`top-bar`），页面页脚从 y 1120 起（`footer-bar`，96），阅读页脚从 y 1128 起（`reading-footer`，88）。两种页脚高度不混用。
- 行高：`list-row` 104，`choice-row` 116，目录行 86。按钮 88（`button`）或 96（`button-large`）。
- 触控目标高度至少 88 px。正文点按区：左 30 % 上一页，中 40 % 打开工具，右 30 % 下一页。
- 所有翻屏列表的分界为 x 205 和 479，与正文点按区一致。

## 线框、圆角与状态

- 全部使用 `radius-none`。`radius-round` 只用于单选圆环、圆点和词典选区端点。
- 线宽表达状态：无框 = 不可点 · `border-hairline` 1 px 未选中的格子 · `border-regular` 2 px 次按钮、分隔线、检测格 · `border-emphasis` 3 px 顶栏底线、选中的格子、失败的检测格 · `border-pressed` 6 px 按下的单帧。
- **黑底表示「点这里」。** 只用于推荐操作（`.pp-btn--primary`，每个区域最多一个）、当前标签和顶栏徽标；状态文字不加黑底。失败检测格上的「!」方块是唯一不可点的黑色标记。
- **不可用：** 不画框，文字用 `disabled`，无热区；有原因时用原因替换文字，如「已应用」「无法应用」。
- **危险操作：** `ink` 实线框，按钮文字写明动作（「删除原书」「清除进度」）；旁边的推荐项为「取消」。
- **已保存与待保存：** 单选圆点表示选中，旁边以 `description` 写「当前」或「待保存」，不加框或底色。
- **需要处理：** 顶栏黑底徽标（「尚未保存」「位置不同 ›」），点按进入处理位置。仅告知的状态用文字，不用黑底。
- **失败：** 加粗外框和「!」方块，并用文字写明失败内容。
- 「›」只出现在进入子页的行上；立即执行的动作使用按钮。

## 输入与刷新

- **所有可交互页面 K2 = ForceRefresh：** 立即全刷当前画面，不关闭、确认、取消或退出 USB，也不清除提示。
- K1／K3 在有背后内容时翻页或翻屏；工具、排版和确认上下文中不操作背后页面。
- 书库、目录、书签、使用说明和正文支持左滑向后、右滑向前。
- 一个输入序列只有一个消费者；打开或关闭图层的点按尾部事件不穿透。
- 提示放在页脚，下一次输入时清除。不使用居中弹窗；确认使用底部面板或整页。

完整规则见 [UI 说明](../../development/ui-implementation.md)。

## 图标

- 工具栏和状态图标由固件按像素绘制，视觉尺寸 40 px（`icon-visual`），线宽 2–3 px：目录（三条线）、排版（「Aa」）、同步（上下箭头）、刷新模式（左半实心圆环）、全刷（框内实心块），以及书签和电池。
- 词典使用七个 Phosphor regular 图标，见 `firmware/components/reader_app/third_party/phosphor/`，离线预先光栅化为 40 × 40 的 4 位掩码，以 `ink` 或 `disabled` 合成。
- 不用 emoji 和图标字体。新图标沿用同样的尺寸和线宽，并须在近黑白刷新时可辨认。

## 图像

- `web/public/assets/screens/` 是使用合成数据的 host 渲染截图，只作布局参考。
- 书籍封面和正文图片转换为面板灰阶；休眠画面默认显示书籍封面，无封面时显示文字封面。
- 产品名以文字「Pico Page」呈现，没有标志图形文件。

## 官网

官网使用独立的 `site-*` 色板：暖色 `site-bg` 底，正文用 `site-sans`，文字标识用 `site-serif` 粗体，代码用 `site-mono`。焦点为 3 px `site-accent` 外框、外移 3 px。官网文案面向读者介绍产品，开发状态留在仓库文档中。

## 固件尚未实现的规则

以下规则按 [D46](../../planning/decisions.md) 于 2026-10-28 采纳，固件在实现前仍按旧样式绘制：

- 不可用控件：固件仍绘制 2 px `disabled` 外框和 26 px 文字。
- 排版参数格：固件仍用灰阶 9（#999999）绘制未选中格的外框，格名为 22 px。
- 单选行：固件仍绘制 3 px／2 px 外框和黑底「当前」「待保存」标签。
- 界面字号：固件另外使用 30、26、25、23 和 22 px，按「字体」一节归入 `title`、`label`、`description` 和 `caption`；顶栏徽标由 22 px 改为 20 px。
- 检测格：固件仍以虚线绘制未进行的格子，失败格没有「!」。
- 工具标签与工具栏：固件的标签仍写「刷新」，工具栏「刷新模式」仍为 26 px。
