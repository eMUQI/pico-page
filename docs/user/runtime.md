# Pico Page 使用指南

本页说明 Read Pico 上的日常操作。安装请使用[官方安装页](https://picopage.wulu.zone/install/)，也可阅读[官网使用文档](https://picopage.wulu.zone/docs/)；设备中的「设置 → 使用说明」无需联网即可查看。源码构建与桌面运行分别见[固件开发指南](../../firmware/README.md)和[桌面开发指南](../../tools/host/README.md)。

Pico Page 正在快速迭代，功能和界面会随版本更新。各版本的变化见[更新日志](https://picopage.wulu.zone/changelog/)。

## 开始阅读

安装会清除设备内部闪存并替换原有固件、分区表和内部设置；TF 卡不受影响。安装前先阅读安装页的恢复说明，备份需要保留的数据。

1. 按官方安装页的步骤安装 Pico Page。
2. 准备 FAT 文件系统的 TF 卡，将 EPUB、TXT 放入 `Books/` 或其子文件夹。
3. 将 TTF、OTF 字体放入 `Fonts/`。完整中文字体可从[官网](https://picopage.wulu.zone/#fonts)下载。
4. 插回 TF 卡后重启设备。设备不支持热插拔，取出或插入 TF 卡后都需要重启。
5. 在书库点按一本书打开，点按文件夹查看其中的书。
6. 轻点正文中部，打开「排版」并选择字体，点「应用到此书」或「设为阅读默认」。

启动时，设备会尝试创建缺少的 `Fonts/`、`LockScreens/` 和 `Dictionaries/`；使用默认书库时也会创建缺少的 `Books/`。已有目录和文件保留；只读或存储卡已满等情况可能导致创建失败。

再次打开同一本书时，设备恢复已保存的位置。书库顶部的「继续阅读」打开上次阅读的书。首次打开需要读取和校验原文件，较大的书可能需要等待；总页数尚未算出时，仍可继续阅读。

内置字体包含 3,500 个常用汉字，未覆盖的字符显示为方框。没有可用的 TF 卡字体时，正文使用内置字体并提示添加完整字体；偏好字体缺失而备用完整字体可用时，会提示回退。

## 阅读统计

在书库首页点「阅读统计」查看本机累计阅读时长、读过的书及每日记录。在书籍详情点「本书统计」可查看单本书的记录。EPUB 和 TXT 共用同一套计时规则。默认同一页累计停留满 5 秒才计入，单次最多计入 120 秒。设备尚未校时时，阅读时长归入「日期未知」。

在「阅读统计 → 统计设置」可以调整最短停留时间和单次上限，或关闭采集。关闭后保留已有记录。统计保存在 TF 卡上；迁移时一并保留书籍的伴随目录和 `PicoPage/data/statistics/`。

## 界面语言

首次使用先在独立页面选择「简体中文」「繁體中文」或「English」，点「继续」进入欢迎页；欢迎页左上可返回修改。之后也可在「设置」列表中点「语言」，该行位于「阅读」之前，下方显示当前语言。保存成功后立即切换，重启后保留；保存失败时保留原语言，引导页可检查 TF 卡后重试，设置页则需重新打开后重试。书籍正文、书名、文件名和阅读进度保持原样。Wi-Fi 传书页在开始传书时采用设备语言。

## 按键与触摸

以下为默认映射，自定义按键尚未实现。

| 操作 | 结果 |
|---|---|
| K1 / K3，或点正文左侧 / 右侧 | 上一页 / 下一页 |
| 正文左右轻扫 | 翻页 |
| 点正文中部 | 打开阅读工具，在书签按钮左侧查看时间和电量 |
| K2 | 立即全刷当前画面 |
| 长按书库中的一本书 | 查看书籍详情 |
| 长按正文图片 | 放大查看图片 |
| 短按电源键 | 休眠；休眠后按电源键唤醒 |
| 长按电源键 | 打开关机、重启菜单 |

在书库、目录、书签和使用说明中，K1、K3 和左右轻扫用于翻屏。工具和排版面板打开时，K1、K3 不翻动背后的正文。图片查看中，右上角可切换对比度，左上角返回原页，不改变阅读位置。

K2 在所有可交互页面只全刷，不移动阅读位置、不关闭面板、不取消预览、不确认操作，也不退出传输。屏幕刷新期间重复 K2 会被忽略。准备休眠期间有单独规则，见[休眠与关机](#休眠与关机)。

## 排版与刷新

轻点正文中部 →「排版」，可按当前排版样式调整字体、字重、字号、行距、页边距、段距、首行缩进和对齐。调整先显示预览，此时尚未保存。

每个参数卡片右侧的「−」「+」直接调整这一项；点「字体」卡片选择字体，点「全屏阅读」卡片在开和关之间切换。

EPUB 默认使用原书排版。点「统一排版」，按你设置的字重、行距、段距和首行缩进排版。EPUB 和 TXT 默认开启全屏阅读，点「全屏阅读」卡片切到「关」，恢复页脚和上下留白。切换后点「应用到此书」，正文从当前文字位置重新排版。全屏时，书签标记显示在页面右上角的留白内。

TXT 默认「保留换行」。如果英文小说在一段内频繁出现短行，可点「重排段落」预览，再点「应用到此书」。此选项只保存在当前书，合并符合散文折行特征的行，保留空行和已识别的章节标题。阅读诗歌或其他依赖原有换行的内容时，可切回「保留换行」。

原书排版按书内 CSS 显示文字、插图和包内字体。除了调整字体、字号和页边距，也可以用「字重」把字形调成「稍细」或「稍粗」，同时保留原书的粗体层次。选「按原书」恢复原有字重。行距、段距和首行缩进沿用书内样式。支持范围见[原书排版](../development/original-layout.md)。

统一排版的 EPUB 和 TXT 默认左对齐。想让正文两侧对齐时，点「对齐」卡片切到「两端对齐」，再点「应用到此书」。原书排版的对齐方式沿用书内样式。

- 「应用到此书」：只保存为当前书的设置。
- 「设为阅读默认」：修改全局默认，包括全屏和样式；其他书已有的独立设置继续保留。在 TXT 中保存时不改变样式。
- 「恢复默认」（面板顶部右侧）：把预览改为全局默认值；再点「应用到此书」才清除本书的对应覆盖。仍可继续调整后应用。
- 「完成」：没有改动时收起面板。
- 「放弃修改」：放弃本次预览，恢复原排版。

排版或刷新面板打开时会重新读取配置。文件无效时停止编辑并保留原文件。单独更改刷新模式不会覆盖或立即应用电脑手改的字体、行距等参数。

在阅读工具的「刷新模式」中修改当前书，在「设置 → 阅读」中修改阅读默认。清晰模式每页全刷；均衡、快速模式的自动全刷间隔可分别设为 0–30 页，0 表示不自动全刷。选择快速模式后需点「改用快速」确认。有残影时按 K2 全刷。

## 书签与页脚

1. 轻点正文中部打开工具，点右上角「加书签」标记当前页；当前页已有书签时可点「删书签」删除。
2. 打开「目录」，切换到「书签」，点一条记录跳转。

每本书最多保存 100 个书签，只保存在本机，不随 KOReader 同步。

点正文页脚左侧可依次切换页码、百分比、章节序号、章节名和不显示；右侧可依次切换电量、时钟和不显示。两侧互不影响，隐藏后点原位置恢复。电量使用最多五个实心格表示大致余量，不显示百分比；充电时显示静态闪电，没有有效电量且未报告充电时暂不显示图标。

## 传书与联网

| 方式 | 操作与范围 |
|---|---|
| 读卡器 | 在电脑上管理 TF 卡文件，插回设备后重启 |
| USB 文件传输 | 连接电脑后，在「设置 → 网络与传输」中开启；可管理 TF 卡全部文件 |
| 设备热点传书 | 手机或电脑连接设备热点，用浏览器上传，无需路由器 |
| 已保存的 Wi-Fi 传书 | 设备和手机或电脑连接同一网络，打开设备显示的完整地址上传 |

USB 传输结束时，必须先在电脑上安全弹出 TF 卡，再在设备上退出并确认重启。电脑仍在写入时不要拔线或重启。步骤和异常处理见 [USB 文件传输](../development/usb-storage-runtime.md)。

Wi-Fi 传书可上传书籍（EPUB、TXT，最大 64 MiB）、字体（TTF、OTF，最大 32 MiB）和锁屏图片（PNG、JPEG，最大 2 MiB），同名文件不覆盖。结束传书后重新扫描书库和字体，无需重启；新字体需要在「排版」中手动选择。Wi-Fi 传书不接收词典文件；词典请通过读卡器或 USB 复制。步骤与失败处理见 [Wi-Fi 传书](wifi-transfer.md)。

在「设置 → 网络与传输 → Wi-Fi 设置」中添加网络，连接成功后才保存。仅支持 2.4 GHz 网络，最多保存 5 个。Wi-Fi 开关打开不代表已连接；同步和传书按需联网，用完断开。手动点「立即连接」后保持在线，直到断开或休眠。

Wi-Fi 页底部显示时间，时区固定为 UTC+8。联网时可自动校时，也可点时间区域的「校准」；网络必须能访问互联网。显示「尚未校准」时，不能把 Wi-Fi 已连接当作校时成功。

## 离线词典

支持 StarDict 2.4.2 和 3.0.0。词典需自行准备，并保留其许可证；固件不附带词库。

1. 用读卡器或 USB 将一套词典的完整文件夹放入 TF 卡根目录的 `Dictionaries/`，例如 `Dictionaries/English/main.ifo`。同一套文件须保留相同名称前缀，包含 `.ifo`、`.idx` 和 `.dict`，也支持 `.ifo.gz`、`.idx.gz` 和 dictzip 格式的 `.dict.dz`；有同义词文件时一并保留 `.syn` 或 `.syn.dz`。不要只复制压缩包。
2. 安全退出 USB 传输并重启，或插回 TF 卡后重启。打开「设置 → 阅读 → 离线词典」，必要时点「重新扫描」。
3. 启用需要的词典，用上移、下移调整查询顺序。最多启用 32 套；显示扫描不完整时，减少目录层级或词典数量后重扫。
4. 在 EPUB 或 TXT 当前页长按文字，可保持按住并跨行拖选，松手后查询。释义面板中可拖动选区端点，或用起点、终点按钮调整；英文点按按词调整，长按按字调整，中文按字调整。
5. 点词典名称两侧的切换图标切换来源，点词典名称选择指定来源；用「展开／收起」调整释义显示范围。K1、K3 翻释义页，关闭面板恢复正文，K2 仍只全刷。

选词最多 64 个 Unicode 字符且不超过 255 个 UTF-8 字节。索引展开后最多 64 MiB，单条原始释义最多 128 KiB；超限或可用内存不足时会报错，不代表未收录。首次使用或清缓存后的查询可能较慢，可关闭取消。释义显示基础文本，不加载外部图片、音频或脚本；部分格式会简化并提示。

## 与 KOReader 接续位置

前提：两端使用内容完全相同的原始 EPUB，以及同一 KOSync 服务和账户。设备账户在「设置 → KOReader 同步」中填写并验证。两端的页码可以因排版不同而不同，接续依据原文位置。

1. 在设备上打开这本 EPUB，轻点正文中部 →「同步」。
2. 在「阅读进度」中点右侧的「检查远端位置」。设备只查询，不自动跳转，也不自动上传。
3. 精确映射成功且两端位置不同时，同步面板会显示两端位置。选择「留在这里」可回到当前页。选择「跳到这里」后，设备会在新页面成功显示后保存新位置。回到正文后，如需再次比较两端位置，请重新检查。
4. 如需用本机位置更新远端，点「上传本机位置…」，在确认页核对后上传。只发送已经保存到 TF 卡的位置。

取消会停止尚未发送的任务，但已发出的上传仍可能在服务端生效。结果不确定时，先重新检查远端，不要直接重试覆盖。

无法精确换算的位置会明确提示，不按百分比猜测跳转。部分复杂 XHTML 可离线阅读，但无法接续；TXT 和本地书签不参与同步。手改账户配置时还需核对 CREngine DOM 版本，字段、兼容范围和验证记录见[同步说明](../development/sync-runtime.md)。

## 校准设备时间

轻点正文中部，打开「同步 → 校准时间」。面板显示当前时间（UTC+8）和上次校准时间。点「立即校准」联网校时。无线关闭时可点「打开 Wi-Fi 并校准」。没有已保存网络时，先从「Wi-Fi 设置」添加。校准结束后设备会释放临时连接，手动保持的连接继续可用。也可从「设置 → Wi-Fi」底部发起校准。

## 休眠与关机

短按电源键请求休眠，电源键用于唤醒，K1/K2/K3 不用于唤醒。设备先保存阅读位置，保存失败时不进入休眠；休眠是浅睡，不是断电关机。

准备休眠期间，屏幕提示可按电源键取消：再短按一次取消，长按仍打开电源菜单。触摸和 K1/K2/K3 均忽略，K2 此时不全刷。

在「设置 → 电源与休眠」选择画面、调整自动休眠时间，再点「保存设置」。0 表示关闭自动休眠。画面可选书籍封面、保留正文、简洁屏保或自定义图片。选择「书籍封面」后，从正文或从正文打开的排版、目录等页面休眠时显示当前书籍的封面，封面不可用时显示书名和作者。从书库、设置或「设置 → 阅读 → 默认排版」休眠时显示内置书库插画。进入休眠时，若电量为 20% 或更低且设备未在充电，封面下方会显示「电量低，请充电」。

使用自定义图片：

1. 将 PNG、JPEG 放入 TF 卡根目录的 `LockScreens/`。推荐 684 × 1216，每张不超过 2 MiB；完整尺寸与数量限制见[自定义锁屏](../development/platform-runtime.md#自定义锁屏)。
2. 在电源与休眠设置中选择「自定义图片」，进入「选择图片 / 轮播」指定一张或使用轮播。
3. 如需让透明 PNG 保留底下的画面，开启「叠加当前画面」。半透明区域混合显示，JPEG 和不透明 PNG 沿用原显示；叠加正文时隐藏阅读页脚，取消休眠或唤醒后恢复。
4. 点「预览」查看当前草稿，返回后点「保存设置」生效。预览不会保存设置或推进轮播。

图片在空闲时准备，休眠时未准备好会等待。图片损坏、缺失或准备失败时使用简洁屏保并提示；修正文件后可重新保存设置。资源限制和重试规则见[自定义锁屏](../development/platform-runtime.md#自定义锁屏)。

长按电源键，或从电源与休眠设置打开关机、重启菜单。选择后先保存本地进度；只有保存失败时才询问是否仍要继续。USB 传输须先安全退出，网络任务须先结束。菜单的「取消」保留原状态。

## 固件更新

联网更新前，先保存能访问互联网的 Wi-Fi 并打开 Wi-Fi 开关，结束同步、传书或书籍加载。请保持设备正在充电，或电量不低于 20%；下载和安装期间不要强制断电或重启。

1. 打开「设置 → 固件更新」，点「检查更新」。
2. 查看版本与更新说明，点「下载并安装」；下载期间可在屏幕上取消。
3. 校验通过后，点「重启并安装」。点「稍后」不会切换固件，但关机或重启后需要重新下载。

0.6.2 及更早的 Pico Page 通过电脑完整重装一次，即可切换到采用双 7 MiB 分区的版本。旧版的「固件更新」只检查旧布局版本。重装会清除内部闪存，若需保留其中的数据，请在安装前备份。TF 卡上的书籍、阅读进度和 Pico Page 设置会保留。在电脑上打开[官方安装页](https://picopage.wulu.zone/install/)重装。早期 `0.2.0-beta.1` 无法验证更新服务器证书，亦可通过安装页重装。

请从官方站点安装或更新。当前设备不具备固件来源签名验证能力；下载摘要校验不能替代来源认证。更新的实现见[固件更新实现](../development/platform-runtime.md#固件更新)。

## 文件与备份

```text
Books/                          EPUB、TXT，可建子文件夹
Books/示例.epub.picopage/        示例.epub 的进度、书签和单书设置
Fonts/                          字体
LockScreens/                    自定义休眠图片
Dictionaries/                   StarDict 词典及其许可证
PicoPage/settings.toml           阅读与设备配置
PicoPage/network.toml            Wi-Fi 配置，含密码
PicoPage/sync.toml               同步配置，含账户凭据
PicoPage/data/                   上次打开、最近阅读和锁屏轮播记录
PicoPage/cache/                  可重建缓存
```

移动或备份书籍时，一并保留原书旁的 `<完整文件名>.picopage/` 目录，否则进度、书签和单书设置不会跟随。完整备份还应保留 `PicoPage/`、字体、词典和锁屏图片；缓存可以重建，不能替代阅读记录。备份应在设备退出文件使用、电脑安全取得 TF 卡后进行。

`network.toml` 与 `sync.toml` 含凭据，不要放入公开日志、问题附件或普通配置分享。手工修改配置只改需要的字段，不覆盖其他设置；格式见[存储约定](../development/storage.md)和[配置示例](../examples/README.md)。降级固件前备份数据并核对格式，旧版本可能拒绝读取新字段或记录。

长按书库条目进入详情，可以清除本地阅读进度或删除原书；缓存在「设置 → 存储」中整体清理：

- 清除本地进度需要屏幕确认，下次从头阅读，远端位置不变。
- 删除原书需要屏幕确认，并保留伴随目录；把同一本书放回原文件夹并使用原文件名后，可以恢复记录。
- 缓存通常无需手动清理。需要释放空间或排查缓存异常时，可在「设置 → 存储」选择「清理全部缓存」；书籍、设置和阅读进度保留，首次重新开书或查词可能较慢。等待时可以取消，取消前可能已清理部分缓存。
- 外部修改或操作未完成时，先检查文件并重新打开详情核实，不把错误提示当作已经删除或清除。

设备在正文停留后保存已显示的位置，离开正文、休眠、USB 传输或同步前也会保存。设备提示「进度未保存，请检查 TF 卡后重试」时，先检查 TF 卡，再点「重试保存」。

## 格式与兼容范围

- TXT 支持 UTF-8（可带 BOM）、GB18030，以及带 BOM 的 UTF-16LE／UTF-16BE。无 BOM 时先尝试 UTF-8，再尝试 GB18030；UTF-16 必须保留 BOM，其他编码可能误判或无法打开。TXT 会从常见中文章节标题及英文 Chapter／Part 等带编号短标题自动生成目录；没有识别到章节时保留「正文」入口。
- EPUB 默认使用原书排版，可切换为统一排版；有效长章节按段处理，当前页优先，不等待整书排完。原始 EPUB 不被改写。
- 图片与前后的文字可排在同一页，文字不环绕图片；仅含一张图片的章节使用整个正文区域。缺失、损坏或不支持的图片显示占位，允许继续阅读，具体范围见[图片说明](../development/image-runtime.md)。
- 表格、复杂 SVG 和复杂 CSS 有降级或拒绝范围；不支持复杂文字塑形和双向文字。
- PDF、批注、高亮、插件、阅读统计和多主题尚不支持。计划见[路线图](../planning/roadmap.md)，不构成版本承诺。
