补测发现并修复两个原型问题：Expat 的延迟解析可在最终输入中暂停，原实现会把中间段误标为末段；大 XML 注释还会使暂停状态保留大量内部缓冲。1 MiB 注释样本在未限制版本中观察到约 4.23 MB 的暂停堆增量。因此，仅对续读路径限制尚无完整 XML 事件的输入最多 64 KiB；超过时停止续读并释放状态，有效正文仍可由原路径读取。最终回退测试送入 XML 65,536 字节后停止，采样堆峰值增量 635,600 字节，失败后游标和额外 miniz 分配均为零；原路径成功读完 4 段、168,000 个含段落分隔符的标量。此限制针对未处理输入，不能冒充 XML 或总堆的硬性大小上限；结构和元数据仍受既有预算约束。
