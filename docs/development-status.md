# 开发状态

本页列出主线的当前实现和待验证项，只在实现或验收状态变化时更新。各项改动的范围、命令和结果见对应 PR 与 Git 历史；公开实测报告按[测试基准](development/testing-baselines.md)记录。

## 当前状态（2026-11-07）

最近发布版本为 **0.5.1**，功能和兼容范围见[发布说明](releases/0.5.1.md)。主线包含尚未发布的改动；合入主线不表示对应硬件专项已经验收。

- **阅读**：TXT 自动目录与章节显示、连续回翻位置修复和全屏阅读已合入。正文页底部不足一行的余量均分到行间。全屏阅读的桌面验证覆盖 TXT 和 EPUB 原书模式的源锚点保持、单书设置与阅读默认，真机显示和触摸待验收。
- **原书排版（试验）**：EPUB 可按书启用，沿用正文、页数统计与源锚点恢复路径。支持作者 CSS 的基础文本与块样式、包内 TTF／OTF、块内 `<br>`、作者行高、图片宽高比与 `duokan-bleed` 出血；章节、页数索引及单图图层使用独立版本的持久缓存。已在 Read Pico 上用一本含 3,884 个正文文档的实书核对模式切换、连续翻页、跨章、重开位置和全屏图片贴边。冷开仍有明显等待。支持范围见[原书排版](development/original-layout.md)，性能见[实机对照](development/baselines/2026-11-06-original-layout-performance.md)。
- **显示**：翻页效果重选和自动全刷间隔边界上的无效操作不再刷新；显示基准有效时，像素相同的普通更新被跳过，见[定向对照](development/baselines/2026-11-06-refresh-noop.md)。光学、能耗和长期稳定性未验收。LCD 双供数任务的启动竞态（#49）已修复，见[复现与修复](development/baselines/2026-11-05-https-display-gate.md#后续复现与本地修复)。
- **同步**：一份原创 EPUB 已完成 Read Pico 与官方 KOReader 经 HTTPS 服务的不同字号跨章往返、回读、重开及不支持结构保护，见[定向接续验收](development/baselines/2026-11-05-koreader-roundtrip.md)。单轮结果不外推到其他书籍和结构。
- **界面与电源**：均衡／快速自动全刷间隔 0–30、五格电量、正文字体错误编号、书库封面暂时失败重试和 USB 浅睡串口交接修复已合入。
- **性能**：[0.5.1 与主线对照](development/baselines/2026-11-04-v051-main-performance.md)中常规翻页中位数接近，未观察到整体提速。[EPUB 阶段对照](development/baselines/2026-11-05-epub-device-stages.md#106-阶段覆盖与最终对照)中实书 A 普通版首翻中位数由 3.643 s 降至 3.234 s；正文跨章仍可能等待数秒。样本有限，不据此给出整机性能结论。
- **许可与发布**：项目代码采用 GPL-3.0-or-later 及 ESP-IDF 二进制库链接许可，第三方组件保留各自许可，见[许可说明](../LICENSING.md)与[依赖审查](development/dependency-review.md)。固件组件清单与本地隐私扫描已于 2026-11-06 完成；公开仓库与 Release 迁移按[公开发布检查](development/publication.md)执行。

## 待验证与后续工作

具体场景和数值目标以[验收清单](development/acceptance.md)为准。以下项目尚未完成完整验收，短时单机结果不替代对应专项。

- **词典**：真实触摸与端点拖选、面板遮挡、冷／热查询、深词条重排、慢卡取消、句柄释放、动态内存峰值，以及休眠／USB 交还；镜像增长需结合目标资源实测评估。
- **阅读与显示**：章节与图片缓存的同条件设备对照、正文跨章长等待、全书页数统计、非正文保持、页脚与翻页效果、充电、键盘、轻扫、字体选择、持续阅读及低内存降级；中文正文两端对齐。
- **电源与存储**：长期休眠、串口唤醒枚举、电源键取消、透明锁屏冷／热轮播、保存失败、真实断电、时钟故障、TF 掉电与 USB 异常交接。
- **网络、同步与更新**：更多真实书籍和结构的 KOReader 接续、多轮稳定性与异常恢复、[独立短扫观察](development/baselines/2026-11-05-https-display-gate.md#剩余短扫)、跨分段上传百分比、OTA 坏包／取消／续传、断电与回滚，以及手机传书的大字体和超限场景。
- **界面**：其余页面字号和紧凑热区，近黑白／快速档下的不可用与失败状态，书签、内置说明和书库的完整真机验收；设计待办见[设计系统](design/system/README.md#固件尚未实现的规则)。后续功能见[路线图](planning/roadmap.md)。
- **发布与维护**：随固件发布的许可汇编、公开仓库权限和部署身份迁移；固件托管的首次上传过慢问题尚未定位，见[固件托管](development/firmware-hosting.md)。
