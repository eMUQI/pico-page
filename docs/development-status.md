# 开发状态

## 当前摘要（2026-11-04）

最近发布版本为 **0.5.1**，功能和兼容范围见[发布说明](releases/0.5.1.md)。主线可能包含尚未发布的改动，合入或发布不表示所有硬件专项已经验收。

当前主线已包含 TXT 自动目录与章节显示、连续回翻位置修复、均衡／快速自动全刷间隔 0–30、五格电量、正文字体错误编号、书库封面暂时失败重试，以及 USB 浅睡串口交接修复。架构、实现边界和组件职责见[开发文档](README.md)。

[0.5.1 与主线的合成样本实机性能对照](development/baselines/2026-11-04-v051-main-performance.md)显示，常规翻页中位数接近，未观察到整体提速；两版正文跨章时均出现过数秒等待，主线首步预取状态仍有差异。小样本和 host 优化结果不能扩展为确定的整机性能结论。

项目代码采用 GPL-3.0-or-later 及 ESP-IDF 二进制库链接许可，第三方组件保留各自许可，见[许可说明](../LICENSING.md)与[依赖审查](development/dependency-review.md)。公开仓库迁移、Release 迁移和官网读回仍按[公开发布检查](development/publication.md)执行，不从本地整理结果推定已经完成。

EPUB 原书排版的 A 阶段已有独立 CSS 解析与层叠原型，供后续接入原生阅读。现阶段已完成 host、固件构建、匿名调研和 A 阶段实机测量。三本实书副本跨章后恢复了起始锚点，原应用通过独立校验及启动核对。见[候选说明](development/css-style-prototype.md)与[调研报告](development/baselines/2026-11-04-css-prototype.md)。

### 2026-11-04 · EPUB CSS 解析与层叠原型

基于 `23fc560` 增加独立的 CSS 词法、选择器匹配和层叠计算。计算样式为 60 字节，解析池有固定容量，工作量和样式数按批限制。取消与超限保留可判断的结果，计算阶段无需堆分配。接口以既有内容执行者为所有者，阅读和同步仍使用原有实现。支持范围、降级规则及 B 阶段接入建议见[候选说明](development/css-style-prototype.md)。

以 22 本 EPUB、39 份外部 CSS 和 2,382 个 HTML/XHTML 做只读调研。最大单文档关联为 140,285 字节、379 条规则。所有关联集合完成原型解析，拒绝和跳过单独计数。调研脚本、合成测试和独立测量程序可重跑，公开数据见[匿名报告](development/baselines/2026-11-04-css-prototype.md)。

本机使用 AppleClang 21、ESP-IDF 6.1 `fff9895c`、Xtensa GCC 15.2.0 和固定 BSP。`cmake --build build/host --parallel 4`、`ctest --test-dir build/host --output-on-failure` 与独立 ASan／UBSan 构建均为 36/36。本机运行时明确不支持 LSan，Linux CI 执行泄漏检查。原型缺陷先由行为用例复现，再修复词法恢复、上下限和拒绝时的继承回退。最终含 URL 样例的 30 秒变异运行 184,492 轮，无 sanitizer 报告。`sh tools/build_firmware.sh`、Diagnostic 构建及合成／私有输入的独立 ESP32-S3 程序均通过。构建来源、镜像摘要和原始日志保留在本地证据中。
