### 2026-11-06 · 原书排版对齐块内换行、行高与图片出血，正文页底部均分余量

维护者对比实书第一章后，指出章节标题间距、正文行距和题图位置与原书差距明显。用该书单章样本在 host 开启原书排版复现，定位到四处适配缺口：块内 `<br>` 被当作新块，标题的上下边距各算一遍；行高取作者值与字体自身上下高度的较大者，`line-height: 130%` 在 Noto Sans SC 下实际约 145%；图文混排图片使用 `min(页高/2, 480)` 的固定盒并垂直居中，1080×710 题图上下各多出约 39 px；`duokan-bleed`／`bleed` 未解析，全屏时题图仍保留 24 px 顶边距与左右各 36 px 边距。

原书模式下 `<br>` 改为同一块内的强制换行，前后空白折叠，不重复块边距和首行缩进；自定义排版仍按原逻辑分块。作者样式的行高不再被字体上下高度撑大，以该行最大字号为下限。原书分段解析后读取图文混排章节中 PNG、GIF、JPEG 头部的像素尺寸，每张最多解压 64 KiB，图片缺失或头部无效时退回原固定盒，读取遇到内存不足或 TF 读取错误则本次章节加载失败，交给既有的内存不足重试和页数统计延后处理，不把降级版式写入缓存；单图章节不读取；同一本书打开期间按图片路径记住已读尺寸（最多 256 项），重复的章首题图只读一次。尺寸与新增的出血方向随原书章节缓存保存，章节缓存升为 `content-original-v3`，页数索引升为 `original-pagination-v3` 并在几何中记录顶部出血条件。图片按宽高比定高、从块顶放置；左右出血扩到屏幕边缘，上出血仅在全屏、图片位于页首且无返回栏时从屏幕顶边开始，非全屏的顶部区域保留给书签标记。`ComputedStyle` 仍为 72 字节。

执行上下文仍为既有内容任务；图片头读取发生在原书章节冷解析中，每张图的 ZIP 读取与解压调用不可中断，图片之间检查取消。新增临时内存为不超过 64 KiB 的头部缓冲及 miniz 解压缓冲，按 `memory_room` 准入；尺寸表随文档对象释放，PSRAM 优先分配。

维护者另指出全屏底部空白偏多。真机测量（42 px、130% 行高）顶部墨迹距屏幕 30 px，底部空白 47 px：上下留白同为 24 px，差额来自放不下下一行的余量（约 21 px），自定义 1.5 倍行高时底部为 57 px。正文页之后还有内容、剩余高度不足一行时，把余量均分到各行与图片之间，末行落在底部留白处；分页、页数和位置不变，章末页不拉伸，全屏与非全屏均适用。

验证环境为 AppleClang 21.0.0、Python 3.14.7、EIM ESP-IDF 6.1.0 与 BSP `5f3406d`。新增合成样本 `original-layout.epub`，文档回归核对块内换行文本与块归属、PNG／JPEG 尺寸、出血继承及自定义模式不读取尺寸；应用回归核对题图出血位置和宽高比、标题两行相接、换行后不缩进、100% 行高、图片紧接正文及全屏顶边；CSS 回归核对三种出血写法与继承，文档回归另核对重复加载命中尺寸表、头部读取准入失败时整段返回内存不足且恢复后仍取得尺寸，应用回归核对长章首页末行贴到底部留白、首行位置及分页终点不变，两处缓存版本回归随之更新。最终代码 host Debug 完整 CTest 36/36 通过（78.34 秒），独立 `build/sanitized` ASan／UBSan 36/36 通过（153.67 秒），仅有第三方 cJSON、miniz 的既有告警，未验证 LSan。`eim --do-not-track true run "sh tools/build_firmware.sh" v6.1` 完整通过，最终版本 `0.5.1+g584c232.dirty`，源码摘要以 `0d6885501189` 开头，镜像 0x3e0090 字节、SHA-256 以 `244c1c054383` 开头，4 MiB 应用槽余 0x1ff70 字节；构建后仅修改本记录。593 项交接检查及 `git diff --check` 通过。

真机为 Read Pico（ESP32-S3 v0.2，分区为本项目的 `ota_0`／`ota_1`）。读回分区表和 otadata，两项序号 1／2 的 CRC 均有效，当前从 `ota_1` 启动；三次只向 `0x410000` 写入应用，均通过摘要校验并以看门狗复位，otadata 前后一致，未擦除或改写其他区域。单章样本在全屏原书模式下与 host 一致：题图贴顶并左右出血，标题两行相接，正文为原书行高；均分后正文页顶部墨迹 30–31 px、底部空白 34 px，行距在 54–57 px 间变化。同一本 33,403,760 字节实书以两份不同摘要的副本冷开，切到原书模式后每 15 秒读取一次状态，以页数索引字节增长作统计进度：无尺寸表的候选为 37.5 字节／秒（213 秒窗口），加尺寸表后为 88.0 字节／秒（213 秒窗口），各 1 轮；最低空闲堆 1.65／1.71 MB，最大 PSRAM 连续块不低于 1.0／1.6 MB。该进度只是代理指标，未测整书统计完成时间，也未与改动前固件同条件对照。

未测与下一步：整书统计完成时间、改动前后同条件对照、图片较多章节的冷开耗时及长时间翻页未测；正文宋体仍取决于用户字体。卡上留有测试副本 `Books/fr1-layout-test.epub`、`Books/fanren-layout-test.epub`、`Books/fanren-layout-test-c.epub` 及一次失败上传留下的 `Books/fanren-layout-test-b.epub`，可在书库删除。
