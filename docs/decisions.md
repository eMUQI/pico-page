## 2. 当前设计的具体解释

正文 K1/K3 翻页，K2 = `ForceRefresh`；屏幕中部打开工具。
面板 K2 关闭/取消，冲突/确认取安全选项，仍采用现稿。
这里不把“全刷按钮”擅自解释成所有场景都忽略返回/取消。
不能声称三个键可单独到达所有功能，正文工具确实依赖触摸。
首版无长按/组合键，自定义 UI 后置。

保持现有页面结构、灰阶、方角、信息层级和视觉风格。
正文裁半行、配置被覆盖、错误状态撒谎、输入穿透等属于实现缺陷，不需要照图复现。
修这些问题可以做最小的局部文案/几何调整，并记入实现差异；不能据此重设计整个产品。

## 3. 本包采用的工作默认（不是用户逐项指定）

| ID | 默认 | 允许怎样调整 |
|---|---|---|
| W01 | 仓库目录 `pico-page`，构建标识 `pico_page` | 真正远端仓库尚未建立；用户指定地址后再使用 |
| W02 | 全局用户目录 `/PicoPage/`，单书 `<完整文件名>.picopage/` | 以产品名代替历史建议的 `/ReadPico/`/`.readpico/`；没有自动迁移既有数据 |
| W03 | 配置 TOML，程序记录 JSON，必要历史可用 JSONL | 需验证 ESP-IDF 可用解析/保注释写回方案；不能偷偷换成不可编辑数据库 |
| W04 | 文件夹为真实数据入口，书架/最近阅读是视图 | 可用现有列表组件补入口，不另做一套首页 |
| W05 | 双向 KOSync，原书内容匹配优先 | 以实际原生协议验证；需要额外插件时必须明确说明安装前提 |
| W06 | 独立正文排版，轻量 UI，主机复用核心 | GUI 库与字体组件待依赖审查，不把某库当作用户要求 |
| W07 | 中文、竖屏优先，沿用 684×1216 设计画布 | 实际安全区/触摸转换由板级实测，不照抄外部参数 |
| W08 | 本书设置仅存覆盖项 | 全局设置变更不覆盖其他书的显式设置 |
| W09 | 预处理路径与原生解析路径先选一种做通 | 不先为两种都写完整实现；保持原书与源位置关系 |

W02 只是新项目命名统一；本次没有修改用户 TF 卡。发现已有旧格式文件时，先识别、报告，
再做显式兼容/迁移，不把目录名称变化当成删除旧记录的理由。
