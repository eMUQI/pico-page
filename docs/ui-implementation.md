# 现稿不重画：Codex 实现注意事项

用户决定：当前设计直接用于开发；项目名 Pico Page；K2 在所有可交互页面始终全刷当前画面，自定义按键以后考虑。
原件位于 [design/original](design/README.md)。本文件覆盖原件/旧评审中的冲突行为，不改原 PNG。

## 1. 当前视觉基线

保留 684×1216 竖屏画布、黑白/灰阶、方角、现有书架与沉浸式正文、工具和设置的页面组织。
沿用 original/tokens.json 起步，数值是设计值不是硬件测量。示例值全部来自 ViewModel 后才能显示。
现有 HTML 是视觉参考，不复制其脚本作为固件业务逻辑；它不是 ESP-IDF UI 实现或模拟器。

原设计有 36 张 PNG 与 5 份 HTML，screens.md 列出 69 状态；没有 PNG 的状态按现有 HTML/文字实现。
不因为缺 33 张 PNG 就阻塞开发，也不能声称原件全覆盖。图标可先用统一可控基础图形实现，不依赖缺字字符。
产品中字符串使用 Pico Page，原始文件继续保留 Pico Pages/Read Pico 以维持溯源。
字体按声明来源由开发者自行获取并核对许可；本包没有字体文件，回退要明确。

## 2. 输入规则（以此为准）

| 上下文 | K1 | K2 | K3 |
|---|---|---|---|
| 正文阅读 S02 | 上一页 | **立即全刷**；有脚注返回条也不改成返回 | 下一页 |
| 工具 S03 | 不操作背后 | 全刷当前画面 | 不操作背后 |
| 排版 S05 | 不操作背后 | 全刷当前预览，保留草稿 | 不操作背后 |
| 目录/书库 S04/S01 | 上一屏 | 全刷当前画面 | 下一屏 |
| 冲突/确认 S07/S12 | 不操作背后 | 全刷当前画面，不执行确认或取消 | 不操作背后 |
| 传输 S09 | 按实际传输模式可用项 | 全刷当前画面，不结束传输 | 按实际传输模式可用项 |
| 睡眠 S11 | 由实际 wake_sources 决定 | 同左，不假设 K2 可唤醒 | 同左 |

本表按 2026-10-06 用户更新覆盖原稿：K2 统一全刷，返回、收起、取消和确认使用触摸控件。
正文中部触摸打开工具，左右区/轻扫翻页；不声称按键独立覆盖所有操作。
映射集中为语义动作，为未来自定义保留替换点；第一版不做重映射设置和组合键。
长按只有一处：在书库中长按一本书进入书籍详情（D22）。其他位置的长按等同点按。

全刷进行中重复 K2 忽略；不中断波形、不排无限全刷。相同画面也要执行真正清理刷新。
一个输入序列只有一个消费者，打开/关闭/唤醒操作的抬手不能传到新页面或背后正文。
不能照抄原 input.md 的“打开后第一次抬手用于关闭”，否则同一次点击会开了又关。
忙碌状态以 available_actions 指定可取消/返回项，不统一禁用一切。

## 5. 动作补丁细节

“应用排版”：优先完成当前内容；预览取消不修改保存文件，旧任务失效。
“使用阅读默认”：移除本书覆盖，不是恢复固件出厂配置。
“设为阅读默认”：使用已确认有效的参数，明确影响继承默认的书；当前书应用与全局保存分开反馈。
“取消同步”：取消后续工作，上传已发送时结果可能未明；不能统一变成离线或保证服务器未变。
“远端无记录”：可以首次上传，不能显示错书；缺乏身份不匹配证据时不自造原因。
“清除进度”：新状态提交后，旧会话/备份/outbox 不得将进度复活。
“删除书籍”：按 storage.md 的明确范围保留记录，远端不受影响。
“结束传输”：取消未完成内容或有界收尾，不能永久拒绝休眠也不能截断关键提交。

## 6. UI 数据来源

save_state 来自 StoreAck，不从“已按下保存”推断。
sync_ack 来自对应 revision 与 account_scope 的服务响应，不从进度条结束推断。
refresh_busy 来自显示事务；baseline_valid 来自成功呈现/恢复，不从内存有 buffer 推断。
page_total 可空；字体名区分 preference 与 effective；路径来自真实配置和书籍身份。
“需要处理”来自实际内容后端能力，不提前强制所有 EPUB 只能走专有格式。
角色为录屏/截图的模拟数据必须标为模拟，不能写进生产状态默认成功分支。

## 11. 等待反馈（2026-10-06，host 与诊断输入已验证，面板观感待确认）

对应 DP04。超过约 1 秒的操作先在当前页面显示一行状态并刷新一次，完成后再显示结果；
不增加弹窗、动画或进度轮询。状态行沿用各页已有的提示位置，不改布局。

- 从书库、继续阅读或详情打开书籍：提示行显示“正在打开书籍…”。
- 书库卡片：尚未生成的封面先显示书名占位，提示行显示“正在生成封面…”，生成后再刷新一次。
  已缓存的封面直接显示，不出现中间帧。
- 回翻需要重排超过 10,000 个字符（跨章回到长章节，或在长章节深处没有已知页起点）：
  正文页脚显示“正在排版…”。较短的重排不显示，避免多刷一次。
- 状态帧显示期间和随后的工作期间不接受输入；状态帧刷新失败时不执行后续工作，按原有错误页处理。
- 翻到图片页、目录跳转、排版预览没有状态行；真机复测后按实际耗时决定是否补充。

## 12. 全书页数与设置页补齐（2026-10-06，host 已验证，未烧录）

对应 D16，覆盖第 8 节“显示章内文本位置近似百分比”和原稿 S02-1 的“本章 3 / 12”。

- 正文页脚显示“第 N / M 页 · P%”。页码按当前排版从全书第一章起连续计数，百分比为 N / M。
  工具页眉只显示百分比；休眠画面的位置行使用同一格式。点按页脚仍切换为“第 N 章 / 共 M 章”。
- 页数在正文页面空闲 1 秒后分片统计，每片约 40 毫秒或读取一章；先统计当前章，再按阅读顺序统计其余章节。
  统计期间页脚显示“约 P% · 正在统计页数”，百分比按各章 XHTML 大小估算。统计完成不触发刷新，下一次重画页脚时显示页码。
- 页码是“首个可见字符所在的页”。从恢复位置、目录或链接进入的页面可能跨两页，连续翻页时页码偶尔重复或跳过一个。
- 修改字号、字体、行距、页边距、段距或缩进后重新统计。不在阅读顺序内的章节不计页，位于其中时只显示总页数。
- 任何输入都会先释放统计占用的内存，空闲后继续；
  内存不足以读取下一段时暂停统计，换章后再试，期间页脚仍显示“正在统计页数”。
- 长章节分段读取（D17）：翻到一段的末尾时读取下一段，回翻到段首时读取上一段。超过 150 KB 的章节换段前先在页脚显示“正在排版…”。
  一段结束处的最后一页可能不满；从目录或链接进入时读取目标所在的段。
  统计只做精简解析，内存上界见 [开发状态](development-status.md) 的资源审计记录。
- 分段后正常章节不会再触发内存不足。设备可用内存异常偏低、连一段也读不下时，错误页仍显示“本章内容过大，设备内存不足，无法显示。”并保留最后确认的位置；
  同步页对应显示“设备内存不足，暂时无法计算同步位置。”或“……暂时无法映射远端位置，未跳转。”

## 13. 手机配置 Wi-Fi 与同步账户（S09-2、S09-3）

截图见 `artifacts/provisioning-20261006/`，来自桌面预览；桌面预览没有热点，热点名称和密码是占位值。
截图中的两个二维码已用 macOS CoreImage 解码，内容与页面文字一致。

- 入口：“设置 › 网络与传输”的“开启手机配置”，以及“设置 › KOReader 同步”的“用手机配置”。
  “网络与传输”页标题由“USB 文件传输”改为“网络与传输”，分 USB 和 Wi-Fi 两段；设置首页该行显示已保存的 Wi-Fi 名称或“未配置”。
- 配置页（设备屏幕）：第 1 步显示加入热点的二维码、热点名称和密码；第 2 步显示打开配置页的二维码和地址；
  下方是状态区，底部是“结束配置”。二维码首次出现时整屏刷新。没有返回格，K1/K3 无动作，K2 全刷当前画面。
- 状态区依次显示：等待手机提交、正在连接某网络、正在验证同步账户、已保存、未保存及原因。
  原因来自驱动返回的编号和服务器的状态码，不按网络名称猜测频段（UI12）。
- 手机上的表单：Wi-Fi 名称（可从扫描到的名称中选）和密码，同步服务地址、账户和密码。
  Wi-Fi 名称留空表示不修改 Wi-Fi，同步密码留空表示不修改账户；页面不回显任何密码。
- 结束后回到设置首页；因超时或热点启动失败结束时，设置首页显示原因。

与原稿的差异：

- 原稿只有一个二维码（打开配置页）；实现增加了加入热点的二维码，省去手工输入热点密码。
- 原稿的失败示例按名称判断“可能是 5 GHz 网络”；实现只在驱动报告找不到网络时说明设备只支持 2.4 GHz。
- 原稿的“在设备上输入”后备、“重新填写”按钮未实现：失败后直接在手机上重新提交。
- 原稿的配置页只配 Wi-Fi；实现把 KOReader 同步账户放在同一张表单里。

## 14. 按《实现评审 · 修改稿》调整（2026-10-07，host 已验证，未烧录）

### 全局规则

- 顶栏只有一种：左侧“‹ 上一级名称”，后面直接接粗体标题，中间没有竖线。书库在文件夹内显示“‹ 上一级 | 文件夹名”。
- 提示显示在页脚 96 px 区域（y 1120 起）。只有一屏时页脚只显示提示；有多屏时，提示暂时取代中间的“1 / 3”，两侧翻屏不变。
  提示在显示它之后的下一次输入时清除，K2 不清除。适用于书库、书籍详情、设置首页和“网络与传输”。
- 加载状态不再压在面板上：从工具面板或错误页开始加载时，先换回正文再显示状态行；
  同步时的位置换算在同步面板内显示“准备中”和“取消同步”；排版预览准备图片时，状态和“取消”显示在预览区。
- 错误页的标题写具体原因，顶栏写“无法打开”或“暂时无法继续”。文档、存储和同步层返回的英文原因只写入串口日志，
  界面按类别显示中文（内存不足、文件无法读取、内容无效、结构不支持、读取时变化）。
- 多行说明不在英文单词、数字和路径中间断行；句末标点不出现在行首。
- 黑底按钮表示推荐的选择。删除原书、清除进度、替换远端位置使用虚线框，推荐项是“取消”。
- “›”只用于进入下一页的行。“立即全刷”“清理全部缓存”“开启 USB 传输”是按钮；“Wi-Fi 与同步账户”“Wi-Fi 传书”“用手机配置”是带“›”的行。

### 各页面

- 阅读顶栏：只在“尚未保存”和“位置不同 ›”两种情况显示黑底标签；“未配置”“待上传”等不再常驻。
