# 现稿不重画：Codex 实现注意事项

带日期的增量章节保留当时实现范围；后续章节及产品决定覆盖旧说明。网络设置以第 21 节和 D37 为准，历史手机配置流程不再使用。

用户决定：当前设计直接用于开发；项目名 Pico Page；K2 在所有可交互页面始终全刷当前画面，自定义按键以后考虑。原件位于 [design/original](design/README.md)。本文件覆盖原件/旧评审中的冲突行为，不改原 PNG。

## 1. 当前视觉基线

休眠反馈按 D43、R4 处理：手动或自动休眠请求被接受后，先在原页页脚显示一次「正在准备休眠，按电源键取消」，提示刷新完成后再结束网络、保存进度、交还后台资源及准备休眠画面；书籍封面、保留正文、简洁屏保和自定义图片共用此流程，不等待图片任务或 1 秒计时，不增加倒计时或连续进度刷新。从请求休眠到进入浅睡，仅再短按电源键取消准备；触摸和 K1/K2/K3 均忽略，不全刷、不保留或重放到原页。长按电源键仍请求电源菜单，待页脚恢复和 worker 交还资源后打开。取消后恢复页脚与原页面交互。真正无法准备时才使用既有简洁屏保，唤醒后在原页面页脚提示「本次使用简洁屏保」，不弹错误页，不要求确认；图片已显示时，轮播记录或图片缓存提交失败不提示，只写诊断日志。提示只局部更新页脚，保留阅读位置、正文图片任务与书库分页，详细原因进入诊断日志；资源不足或缓冲分配失败时允许省略等待提示，详见 PW07。

按 D39，产品界面不使用虚线。可点击控件使用实线框；不可用控件使用淡色实线框和淡色文字，不注册热区。危险操作使用黑色实线框及明确的动作文字，取消仍是推荐项；待保存单选项使用细实线框和「待保存」，已保存选中项使用粗实线框和「当前」。传书网页的拖放区及状态标签同样使用实线。原始设计与历史记录保留原样，涉及虚线的旧描述不再作为实现依据。

保留 684×1216 竖屏画布、黑白/灰阶、方角、现有书架与沉浸式正文、工具和设置的页面组织。沿用 `original/tokens.json` 起步，数值是设计值不是硬件测量。示例值全部来自 ViewModel 后才能显示。现有 HTML 是视觉参考，不复制其脚本作为固件业务逻辑；它不是 ESP-IDF UI 实现或模拟器。

原设计有 36 张 PNG 与 5 份 HTML，screens.md 列出 69 状态；没有 PNG 的状态按现有 HTML/文字实现。不因为缺 33 张 PNG 就阻塞开发，也不能声称原件全覆盖。图标可先用统一可控基础图形实现，不依赖缺字字符。产品中字符串使用 Pico Page，原始文件继续保留 Pico Pages/Read Pico 以维持溯源。字体按声明来源由开发者自行获取并核对许可；本包没有字体文件，回退要明确。

## 2. 输入规则（以此为准）

| 上下文 | K1 | K2 | K3 |
|---|---|---|---|
| 正文阅读 S02 | 上一页 | **立即全刷**；有脚注返回条也不改成返回 | 下一页 |
| 工具 S03 | 不操作背后 | 全刷当前画面 | 不操作背后 |
| 排版 S05 | 不操作背后 | 全刷当前预览，保留草稿 | 不操作背后 |
| 目录/书库 S04/S01 | 上一屏 | 全刷当前画面 | 下一屏 |
| 冲突/确认 S07/S12 | 不操作背后 | 全刷当前画面，不执行确认或取消 | 不操作背后 |
| 传输 S09 | 按实际传输模式可用项 | 全刷当前画面，不结束传输 | 按实际传输模式可用项 |
| 睡眠 S11 | 由实际 wake_sources 决定 | 同左，不假设 K2 可唤醒 | 同左 |

本表按 2026-10-06 用户更新覆盖原稿：K2 统一全刷，返回、收起、取消和确认使用触摸控件。本表是默认映射；自定义按键（D30）的规则见 [功能路线图](roadmap.md) R7。书库、目录、使用说明可左右轻扫翻屏，正文可左右轻扫翻页；左滑向后、右滑向前。阈值和拖动忽略规则见 [当前决定](decisions.md)「左右轻扫翻屏与翻页」。页脚翻屏按钮保留，不增加开关；工具、排版和确认等上下文忽略轻扫。正文中部触摸打开工具，左右区点按翻页；不声称按键独立覆盖所有操作。映射集中为语义动作，为未来自定义保留替换点；第一版不做重映射设置和组合键。长按书库中的书进入书籍详情（D22）；长按正文图片进入图片查看（D27）。其他屏幕位置的长按等同点按。电源键长按关机/重启菜单按 D34、路线图 R1 实现，真机时序待测；不改变 K1/K2/K3 的行为。图片查看页顶部左侧返回正文，右侧显示当前对比度档位。点按右侧按原图 0/3、增强 1/3、2/3、3/3、原图 0/3 的顺序循环；每次打开默认原图，切换时全刷当前图片。K2 全刷当前图片；短按正文图片仍按所在区域翻页或打开工具。图片查看不改变阅读位置。

正文图片按 D36 渐进显示：先呈现文字和图片占位，首次开书的正文帧成功刷新后即可提交图片准备，后续翻页仍须短暂停留，保持翻页可用；停留期间继续翻页不启动旧页图片任务，也不为该任务提前清理预取和分页资源；图片就绪且仍在原页时局部补刷。已准备好的当前页或预取位图直接显示；空闲时不预先准备下一页的图片，也不预取下一分段或下一章。翻页取消旧请求，旧结果不覆盖新页；补图不改变阅读进度。缺图、解码失败或内存不足只在图片区域显示原有错误提示，不阻止阅读其余正文。

全刷进行中重复 K2 忽略；不中断波形、不排无限全刷。相同画面也要执行真正清理刷新。一个输入序列只有一个消费者，打开/关闭/唤醒操作的抬手不能传到新页面或背后正文。不能照抄原 input.md 的「打开后第一次抬手用于关闭」，否则同一次点击会开了又关。忙碌状态以 available_actions 指定可取消/返回项，不统一禁用一切。

### 非正文刷新（0.2.0-beta.4，待真机验收）

`reader_core` 的 `Display::present()` 统一决定逐像素保持：有效基准下的 `FramePurpose::Overlay + RefreshIntent::Content` 只驱动前后变化的像素，未变化的封面、标题栏、边框、白底和间隙保持不驱动。适用于书库、书籍详情、目录、书签、设置各页、传书页、使用说明、工具栏、各类面板、确认页和错误页的普通整屏更新，也适用于正文页脚、传书状态区、更新进度、休眠等待及取消恢复页脚、锁屏失败提示、内联图片补图、键盘区和输入框的已有局部更新。

默认档使用既有 Gray16 保持表，快速档使用既有 Gray8 保持表；变化像素沿用各自源表的相位序列。面板仍完成既有扫描，不新增内存，不改变波形表、扫描时序、pclk 或刷新档位，也不承诺刷新时间按变化面积缩短。未变化区域不再顺带重刷，连续操作的累积残影由 K2 清除。灰阶、闪烁、残影及同条件面板耗时须按 DP08 在两档分别验收。

K2（`ManualRefresh`）、基准失效、刷新失败后的恢复、二维码首次出现（`overlay(true)`）仍完整清屏；所有显式 `FullClean` 均清除区域限制和 `changed_pixels_only`，保留开机首帧、返回书库、锁屏、关机或安装结果等已有全刷请求。正文翻页（`Body`）不设置该标记，继续按刷新档位和翻页效果执行；正文中的页脚和补图属于 Overlay，不推进正文位置或修订。

## 5. 动作补丁细节

「应用排版」：优先完成当前内容；预览取消不修改保存文件，旧任务失效。「使用阅读默认」：移除本书覆盖，不是恢复固件出厂配置。「设为阅读默认」：使用已确认有效的参数，明确影响继承默认的书；当前书应用与全局保存分开反馈。「取消同步」：取消后续工作，上传已发送时结果可能未明；不能统一变成离线或保证服务器未变。「远端无记录」：可以首次上传，不能显示错书；缺乏身份不匹配证据时不自造原因。「位置准备任务创建失败」：留在同步面板，提供重新检查及继续阅读；内部连续内存不足时明确提示。重试期间保留取消和 K2 全刷；失败不改变本机位置，也不自动上传。此状态与远端位置无法映射分开。「清除进度」：新状态提交后，旧会话/备份/outbox 不得将进度复活。「删除书籍」：按 storage.md 的明确范围保留记录，远端不受影响。「结束传输」：取消未完成内容或有界收尾，不能永久拒绝休眠也不能截断关键提交。

## 6. UI 数据来源

save_state 来自 StoreAck，不从「已按下保存」推断。sync_ack 来自对应 revision 与 account_scope 的服务响应，不从进度条结束推断。refresh_busy 来自显示事务；baseline_valid 来自成功呈现/恢复，不从内存有 buffer 推断。page_total 可空；字体名区分 preference 与 effective；路径来自真实配置和书籍身份。「需要处理」来自实际内容后端能力，不提前强制所有 EPUB 只能走专有格式。角色为录屏/截图的模拟数据必须标为模拟，不能写进生产状态默认成功分支。

## 7. 对照与证据

每个首次实现的页面至少检查正常、忙碌、失败和空/未知状态中相关项。截图需标字体、方向、视口、提交版本；对照原 PNG 或对应 HTML，不只检查缩略图。实际可点击区域与绘制共享布局；脚注扩展热区受行与邻近链接限制，不能一律 88×88 重叠抢点。界面截图验证几何与信息，不验证波形、残影、功耗、写入断电安全或真实 KOReader 接续。原审查详见 [archive/ui-review-v1.md](archive/ui-review-v1.md)，其优先级低于本文件。

封面读取优先级：EPUB 3 `cover-image`、EPUB 2 `meta name="cover"`、guide 封面页；无声明时仅接受第一 spine 的单图片页。复用 PNG/JPEG 解码边界，只处理当前屏最多六张封面，不计算整书身份摘要，不修改阅读会话或进度。封面页 XML 上限 256 KiB，图片上限 2 MiB。最多缓存两屏缩略图，占用不超过 181,056 字节像素内存；文件大小/修改时间变化时失效，TF 卸载时清空。

## 10. 书籍管理、同步和错误恢复（2026-10-06）

- 详情下方提供本书内存缓存清理、清除本地进度、删除原书；破坏性操作另有带书名和路径的确认页。取消不改文件，K2 只全刷。删除保留伴随记录；清除进度不修改远端。提交协议见 storage。
- 同步沿用 S06 的正文、508 px 工具栏、三栏状态和底部操作结构。第三栏标「远端记录」，避免把一次服务器读取描述成其他设备实时状态。无配置、检查中、无记录、位置相同、无法映射、登录失效及上传确认均来自实际状态；不显示设计稿中的虚构时间。
- 位置不同沿用 S07 的并列卡片和等高选择按钮：「继续此处」只关闭，「使用远端位置」仅使用精确映射的候选；下方独立覆盖上传入口仍需确认。成功显示后才保存目标及返回位置。
- 上传确认绑定确切保存记录和账户配置；取消在途上传或响应不明确时保留待核实状态。明确确认与在途请求分开保存，不把请求结束或旧回包当作已上传。
- 内容仍可读时错误页沿用最后确认位置的背景，上方正文无触摸入口，下方提示和返回/重试保存按钮。卡已移除或重绘失败时使用完整内置提示页；不声称物理屏幕一定保留旧画面。

### 错误和状态页的返回来源（0.2.0-beta.4，待真机验收）

`error()` 弹出时按当前页面及入口标记记录来源，不以 `has_book()` 代替页面来源。正文类使用 `recover_body()` 恢复最后确认的位置；书库类回书库，保留当前文件夹和分页；设置类回设置首页，丢弃未保存的草稿。按钮分别显示「恢复阅读」「返回书库」「返回设置」，热区与位置沿用现有布局。存在未保存进度时，「重试保存」仍优先于打开书籍的「重试」，成功后按同一来源返回；设置首页的保存重试成功后留在设置首页。

正文来源必须存在可恢复的已呈现或已保存位置。新书首帧显示失败、尚无任何确认位置时，统一回退书库类，按钮写「返回书库」，不承诺恢复阅读；错误提示和实际返回保持一致。

屏幕整屏或局部更新失败时，只有正文类写「返回将恢复已确认位置」，书库类写「返回将回到书库」，设置类写「返回将回到设置首页」。异步保存失败、书签失败、`show_error()` 和移除 TF 卡均按错误实际弹出时的页面记录来源；错误页再次出错保留已记录的来源。网络收尾页复用 `network_return_view` 判定类别，「继续离线阅读」也按该类别返回，迟到的网络结果不改变返回后的页面或位置。

| View | 来源类别 | 判断依据 |
|---|---|---|
| Reading（含正文图片查看）、Tools、Contents、Sync、Confirmation | 正文 | 正文及其工具、目录、同步和上传确认流程 |
| Typography | 正文或设置 | 工具入口为正文；InputSettings 的「阅读默认排版」入口为设置，以 `typography_from_settings` 保留入口 |
| Refresh、RefreshConfirm、RefreshInterval、PageEffects | 正文或设置 | `refresh_from_settings`；确认、间隔和翻页效果页均沿用刷新页入口 |
| Library、BookDetails、BookManagement | 书库 | 书库、条目详情和管理确认；详情不改变当前阅读会话 |
| Help | 书库或设置 | `help_from_settings` |
| Import、UsbTransfer、Portal | 书库或设置 | `import_from_settings`；USB/网络传书由书库或网络与传输页发起。USB 持卡时仍沿用专用错误页，不改所有权交接 |
| Settings、WifiSettings、PowerSettings、StorageSettings、InputSettings、SyncSettings、TextEntry、LockScreens、About、Update | 设置 | 设置及配置子流程；Wi-Fi 和同步账户即使由其他入口打开，仍属于设置；键盘只编辑 Wi-Fi 或同步账户字段 |
| Loading | 沿用进入前的类别 | 开书/详情、章节、图片、排版预览、同步位置换算和锁屏图片列表在进入加载状态前捕获来源 |
| Error | 沿用弹出时的类别 | 再绘制、重试保存失败或错误画面刷新失败不覆盖来源 |
| Sleeping | 沿用休眠请求开始时的类别 | `prepare_sleep()` 在等待背景工作前固定目的地；正文类无书时回书库 |
| NetworkClosing | 沿用收尾前页面的类别 | 复用 `network_return_view`，账户验证收尾属于设置，正文同步收尾属于正文 |
| PowerMenu | 沿用菜单前页面的类别 | `power_return_view`；菜单取消仍恢复原画面和草稿 |
| PowerOff | 不适用（终态） | 关机、重启和更新安装的收尾状态；输入、休眠和最终刷屏失败均不会走通用返回。分类函数保留菜单来源作为兜底，不为终态新增退出路径 |

休眠与错误共用来源判定。书库类唤醒后仍保留文件夹和分页，设置类回设置首页，正文类沿用原正文恢复路径；设置、使用说明、传输页即使尚未打开书，也不会因无书而改为回书库。锁屏准备失败、简洁屏保回退与页脚提示不改变已捕获的目的地；设置首页同样只局部显示一次回退提示，不带书库翻屏控件。无待定的 View 归类；终止状态和持卡状态的专用处理保留。

## 21. 按《网络与同步 · 审计》调整（D37，2026-10-10，host 已验证，未烧录）

修改方案是 claude.ai/design 项目中的「Read Pico 网络与同步 · 审计」（P1–P11）。沿用现有列表、按钮、灰阶和 684×1216 画布，不改原设计文件。host 画布截图见 `artifacts/network-sync-20261010/`（忽略产物），不是实体设备画面。本节与第 13、15、17 节冲突时以本节为准。

### Wi-Fi 页

- 首页：大字写连接状态（未连接 / 正在连接 / 已连接「名称」/ Wi-Fi 已关闭），小字写连接方式。「Wi-Fi」行右侧显示「开 / 关」，点一下切换，不带「›」。下面依次是「连接方式」「已保存网络」「添加网络」。「立即连接」和「断开」按状态只显示一个；没有已保存网络时「立即连接」为淡色实线框及淡色文字（不可用）。Wi-Fi 关闭时只留开关一行。
- 连接方式：单选列表，「自动」和每个已保存网络各一行，点一下立即生效，不需要确认。当前项只用左侧圆点表示，不加外框和「当前」标签（2026-10-10 用户意见）。
- 已保存网络：列出网络，被指定的那一个标「指定」。点一个网络进入详情：「更新密码」和「忘记网络」；忘记需要确认，忘记被指定的网络时提示将改回自动。
- 添加网络：进入时扫描一次，列出附近的 2.4 GHz 网络（每屏 6 个，页脚翻屏），右侧写「需要密码 / 开放网络 / 已保存」。点开放网络直接连接；其余进入密码页。「手动输入网络名称」分两步：名称、密码。已保存满 5 个时，未保存的网络和手动输入不可点，仍可更新已保存网络的密码。
- 连接中页只有「取消」；取消后回到密码页，已输入的内容保留。失败页写原因和「网络没有保存」，密码被拒时主按钮是「重新输入密码」，其余是「重试」。成功页写已保存的数量；没有同步账户时提供「设置 KOReader 同步」。

### 屏幕键盘

- 键盘区从 y=796 起，4 行，键高 92，键宽 61，行距和键距 6–8。三层：字母、数字与符号、其余符号，合起来覆盖全部可打印 ASCII。字母层的「大写」只作用于下一个字母。网址键盘把空格换成 `https://`、`.`、`/`、`:`。
- 回车键的文字随场景变化：密码页「连接」，名称页「下一步」，同步字段「完成」。条件不满足时为淡色实线框及淡色文字（不可用）：Wi-Fi 密码为 1–7 位、满 64 位但不是十六进制密钥、名称为空。
- 按键没有按下反色。输入字符或退格只刷新输入区（y 104–424）；切换层只刷新键盘区；回车键可用状态变化时两者一起刷新；K2 全刷。
- 键盘区和输入区的普通局刷共用上述非正文逐像素保持规则：大小写切换主要驱动标签的变化像素，未变化的边框、白底和间隙输出保持；数字或符号层的按键几何变化仍清除旧边框并绘制新边框。变化像素沿用当前 GL16 / 8 灰阶 GL16 的相位序列，面板仍完成完整扫描；K2、基准失效及欠载恢复绕过保持掩码。切换时的横带、灰阶与连续切换残影仍须真机验收。
- 字符键只改内存中的输入内容，在主循环的下一个空闲点一次画出。刷新期间的点按全部保留并按顺序执行，不沿用「忙时只留最后一次点按」的规则（`ReaderApp::keyboard_visible()`）。排队的「回车」也执行，其他排队控件忽略。
- 点按滑出按键则不输入。每个键的命中区域延伸到间隙中线。K1、K3 在键盘页不起作用。
- 按键按当前输入内容匹配，不按已画出的控件匹配：补足最后一位后紧接着点回车，即使那一位还没画出，也会执行。
- 退格删除一个完整字符；手改配置中的非 ASCII 账户名不会被删成半个字符。
- 密码默认明文显示，可点「隐藏」；「清空」删除全部内容。超出输入框宽度时显示末尾。
- 草稿只在本次流程内保留：取消连接、失败后重新输入时保留；离开流程、休眠或保存成功后清除，不写入存储。

### KOReader 同步账户

- 「设置 › KOReader 同步」改为可编辑的三行：服务地址、账户、密码，各自进入单字段键盘页。「验证并保存账户」在账户和密码都具备时可用；已保存且未修改时写「重新验证」，并沿用已保存的密钥。小标题按实际情况写「未保存 / 已保存 / 已验证 / 验证未通过」：文件里有账户只说明已保存，本次验证通过后才写「已验证」。
- 验证按连接方式联网；只有服务器接受时才写 `sync.toml`。结果写在页面下方：已验证并保存、账户或密码不正确、服务器没有响应、联网失败的原因。「移除同步账户」需要确认。
- 已保存账户且有打开的 EPUB 时，显示「检查《书名》的同步」。

### 同步面板

- 两栏「本机 / 远端」加一行状态。本机栏写章节和百分比；远端栏写服务器返回的百分比、设备名，位置对上后写章节。
- 按钮分上下两行。上面一行放不改动数据的操作（检查、再次检查、重试、继续阅读、设置账户）；「上传本机位置…」和「取消」固定在下面一行，所以检查后的第二次点按不会落在上传上。
- 检查前显示「网络」行（自动 / 指定 名称 / 已连接「名称」），点进去是连接方式页。
- 检查中、上传中只显示一句进度、所用的连接方式和取消按钮，不显示无操作的占位按钮。
- 两端位置不同时，两张卡片就是按钮：「留在这里」和「跳到这里」，更靠后的一张用粗框并标「更靠后」。前后关系按远端位置映射后所在的章节、章节分段和段内偏移与本机当前页比较，不使用服务器记录的百分比；远端位置落在当前页内时不标。两张卡片的百分比用同一种方法计算：页数统计完成后按所在页码，完成前按章节大小估算。远端位置无法映射时只显示服务器记录的「约 P%」，不判断前后。「留在这里」不上传，正文顶栏保留「位置不同 ›」，直到下次检查或换书。
- 上传确认分两种：远端无记录时问「上传本机位置？」，主按钮是「上传」；远端有位置时问「用本机位置替换远端？」，写出两端位置，默认按钮是「取消」，「替换」为实线框。不可用控件采用淡色实线框及淡色文字，并移除热区。
- 远端位置在本机找不到时，主按钮是「继续阅读」，上传是次要操作。位置所在的章节超出精确映射范围（例如含有表格）时，状态行写明这一原因：检查远端时为「远端位置所在的章节含有表格等暂不支持的内容，无法换算成本机位置，没有跳转。」，上传时为「这一章含有表格等暂不支持的内容，无法换算成 KOReader 的位置，没有上传。」，不使用「两端的书可能不是同一版本」或「暂时不能上传」。
- 账户被拒时主按钮是「同步账户设置」。未设置账户、Wi-Fi 关闭、TXT 都在面板内显示，不再跳到整页。
- 指定的网络连不上时，面板写明没有连接其他网络，并提供「重试」和「本次改用自动」；后者只对这一次检查有效。自动方式失败时提供「重试」和「Wi-Fi 设置」。

### 与修改方案的差异

- **同步和添加网络的进度不逐步刷新。** 方案要求三步进度各刷新一次。2026-10-09 真机上，状态画面刷新与网络请求重叠时出现过 EPD 行队列欠载，所以等待期间画面保持不变；连接驱动也只在结束时报告停在哪一步。结果页写出实际原因。
- **面板的「刷新」标签没有改成「全刷」。** 这个标签打开的是刷新方式面板，不是全刷；全刷由 K2 和工具页的「全刷」执行。
- **输入框没有使用等宽字体。** 设备上没有等宽字形，增加字体属于新增资源；沿用界面字体。
- **指定方式失败时不扫描**，所以不显示「附近有 N 个已保存的网络」；有两个以上已保存网络时就提供「本次改用自动」。
- **网络收尾仍用原来的整页「正在结束同步…」**，没有移入面板。
- **键高 92、键宽 61**，小于其他页面 88 px 的热区宽度，误触率要在真机上测；需要时可把键高提到 104。
- 远端更新时间没有显示：`RemoteResult` 目前不解析 KOSync 的 timestamp。
