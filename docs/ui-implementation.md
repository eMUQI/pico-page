# 现稿不重画：Codex 实现注意事项

用户决定：当前设计直接用于开发；项目名 Pico Page；正文 K2 默认全刷，自定义按键以后考虑。
原件位于 [design/original](design/README.md)。本文件覆盖原件/旧评审中的冲突行为，不改原 PNG。

## 1. 当前视觉基线

保留 684×1216 竖屏画布、黑白/灰阶、方角、现有书架与沉浸式正文、工具和设置的页面组织。
沿用 original/tokens.json 起步，数值是设计值不是硬件测量。示例值全部来自 ViewModel 后才能显示。
现有 HTML 是视觉参考，不复制其脚本作为固件业务逻辑；它不是 ESP-IDF UI 实现或模拟器。

原设计有 36 张 PNG 与 5 份 HTML，screens.md 列出 69 状态；没有 PNG 的状态按现有 HTML/文字实现。
不因为缺 33 张 PNG 就阻塞开发，也不能声称原件全覆盖。图标可先用统一可控基础图形实现，不依赖缺字字符。
产品中字符串使用 Pico Page，原始文件继续保留 Pico Pages/Read Pico 以维持溯源。
字体按声明来源由开发者自行获取并核对许可；本包没有字体文件，回退要明确。

## 2. 输入规则（以此为准）

| 上下文 | K1 | K2 | K3 |
|---|---|---|---|
| 正文阅读 S02 | 上一页 | **立即全刷**；有脚注返回条也不改成返回 | 下一页 |
| 工具 S03 | 不操作背后 | 关闭 | 不操作背后 |
| 排版 S05 | 不操作背后 | 取消未应用预览并收起 | 不操作背后 |
| 目录/书库 S04/S01 | 上一屏 | 返回/关闭；根处安全无操作 | 下一屏 |
| 冲突/确认 S07/S12 | 不操作背后 | 继续此处/取消等安全选项 | 不操作背后 |
| 传输 S09 | 可滚动列表上一屏 | 请求结束，有写入先确认/收尾 | 可滚动列表下一屏 |
| 睡眠 S11 | 由实际 wake_sources 决定 | 同左，不假设 K2 可唤醒 | 同左 |

本表保留现稿的上下文语义，不把用户的“全刷按钮”擅自改成全局拦截键。
正文中部触摸打开工具，左右区/轻扫翻页；不声称按键独立覆盖所有操作。
映射集中为语义动作，为未来自定义保留替换点；第一版不做重映射设置、长按和组合键。

全刷进行中重复 K2 忽略；不中断波形、不排无限全刷。相同画面也要执行真正清理刷新。
一个输入序列只有一个消费者，打开/关闭/唤醒操作的抬手不能传到新页面或背后正文。
不能照抄原 input.md 的“打开后第一次抬手用于关闭”，否则同一次点击会开了又关。
忙碌状态以 available_actions 指定可取消/返回项，不统一禁用一切。

## 3. 实现时必须处理，不等设计返工

| ID | 原页面/评审 | 必须做到 | 允许的最小处理 |
|---|---|---|---|
| UI01 | S02-1 / R01 | 正文无半行裁切、重复或漏字 | 用真实行框分页，最后一行挪下一页；不要复制 overflow 裁切 |
| UI02 | S05-2 / R04 | 当前位置优先重排，不等待全书完成 | 保留面板，文案改为准备当前内容；其余后台/按需 |
| UI03 | S05 / R05 | applied/pending 分开，本书覆盖与全局继承明确 | 取消不落盘；“使用阅读默认”删除本书覆盖；无效字体不能设默认 |
| UI04 | S06–07 / R08–09 | 不把远端记录当对方实时位置 | 状态三格可保留，第三格改“远端记录”；不凭空推断 |
| UI05 | S06 / R09 | 无记录/不匹配/近似/不支持/网络失败分开 | 用现有提示组件；unsupported 禁止附近跳转；旧 ACK 不标新版本成功 |
| UI06 | S07 / R09 | 保留本地不被下一次自动上传反悔 | 存该候选的处置，必要覆盖必须明确确认 |
| UI07 | 全局 / R10–11 | 防穿透，有界任务反馈 | 合并无意义帧，允许开始/阶段/结果；非“一次操作永远一帧” |
| UI08 | S08-4 / R12 | 刷新失败不保证物理旧画面完整 | 文案说明上次确认位置仍在；失败基准标 unknown，恢复后再提示 |
| UI09 | S01/S10 / R13–14 | 不误删原书/必要资源/进度 | 空间与清理边界来自 storage.md，不写“清理”却让书失去离线能力 |
| UI10 | S02/S11 / R14 | 移卡/低电与保存成功分别判断 | 已保存后移卡 vs 尚未保存；有重试，不要求再翻一页才保存 |
| UI11 | S04 / R15 | 无目录不等于读取失败；跳转失败历史不变 | 呈现成功后才提交返回历史，错误按来源区分 |
| UI12 | S09/S11 / R17 | 不根据名字猜 Wi-Fi 频段，不编造唤醒能力 | 取真实驱动原因与 capabilities；未测标待测 |
| UI13 | S01/S10 / R02–03 | 本地文件可见、配置可手改并重新加载 | 沿用列表/详情/设置组件补轻量入口，无需重做首页 |
| UI14 | S12 / R18 | 操作与可用条件有唯一来源 | 排序、展开、关闭等由明确 UI/业务所有者实现，状态机不互相矛盾 |

这些是实现行为和可靠性要求，不是要求复刻旧评审提出的全部视觉修改。
修正后用实际实现截图对照，记录原状态编号、改动理由与测试，不再篡改交付原图。

## 5. 动作补丁细节

“应用排版”：优先完成当前内容；预览取消不修改保存文件，旧任务失效。
“使用阅读默认”：移除本书覆盖，不是恢复固件出厂配置。
“设为阅读默认”：使用已确认有效的参数，明确影响继承默认的书；当前书应用与全局保存分开反馈。
“取消同步”：取消后续工作，上传已发送时结果可能未明；不能统一变成离线或保证服务器未变。
“远端无记录”：可以首次上传，不能显示错书；缺乏身份不匹配证据时不自造原因。
“清除进度”：新状态提交后，旧会话/备份/outbox 不得将进度复活。
“删除书籍”：按 storage.md 的明确范围保留记录，远端不受影响。
“结束传输”：取消未完成内容或有界收尾，不能永久拒绝休眠也不能截断关键提交。

## 6. UI 数据来源

save_state 来自 StoreAck，不从“已按下保存”推断。
sync_ack 来自对应 revision 与 account_scope 的服务响应，不从进度条结束推断。
refresh_busy 来自显示事务；baseline_valid 来自成功呈现/恢复，不从内存有 buffer 推断。
page_total 可空；字体名区分 preference 与 effective；路径来自真实配置和书籍身份。
“需要处理”来自实际内容后端能力，不提前强制所有 EPUB 只能走专有格式。
角色为录屏/截图的模拟数据必须标为模拟，不能写进生产状态默认成功分支。

## 7. 对照与证据

每个首次实现的页面至少检查正常、忙碌、失败和空/未知状态中相关项。
截图需标字体、方向、视口、提交版本；对照原 PNG 或对应 HTML，不只检查缩略图。
实际可点击区域与绘制共享布局；脚注扩展热区受行与邻近链接限制，不能一律 88×88 重叠抢点。
界面截图验证几何与信息，不验证波形、残影、功耗、写入断电安全或真实 KOReader 接续。
原审查详见 [archive/ui-review-v1.md](archive/ui-review-v1.md)，其优先级低于本文件。
