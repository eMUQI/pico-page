# 实现画面

本目录保留仓库首页、现行 UI 说明和设计审计引用的合成画面，界面来源为桌面渲染器。这些图片的验证范围限于界面绘制。

新增画面应使用原创合成内容，注明来源及其验证范围。个人书籍、真实词典内容、设备标识、网络凭据和原始日志不放入本目录。未被现行文档引用的过程截图与来源日志保存在被 Git 忽略的本地目录。
