Pico Page · 锁屏图集 01

五张图文锁屏，使用 GPT Image 生成，为 Pico Page 项目制作并选定发布。
来源：Pico Page 项目，https://picopage.wulu.zone/
每张图片为 684 × 1216、16 级灰度 PNG。第 2、3、4 张采用灰度抖动，减轻渐变断层；第 1、5 张无抖动。
图片预览不代表墨水屏实拍；实际显示效果尚待真机确认。
manifest.json 记录文件、标题、规格、生成来源和 SHA-256。

使用方法
1. 需要支持「自定义图片」休眠模式的 Pico Page 固件。
2. 将 ZIP 中的 LockScreens 文件夹复制到 TF 卡根目录；已有该目录时合并内容。
   单张下载时，将 PNG 文件直接放入 TF 卡的 LockScreens/，不要放在子目录中。
3. 在「设置 → 电源与休眠」选择「自定义图片」，进入「选择图片 / 轮播」。
4. 选择一张图片或轮播，返回并点击「保存设置」。轮播按文件名顺序进行。
5. 0.2.0-beta.3 起，休眠时会等待图片准备；等待期间操作可取消。轮播跳过损坏或超限图片。
   没有可用图片或准备失败时才显示简洁屏保，唤醒后只在原页面页脚提示结果。更早固件请在保存后让设备空闲片刻。
