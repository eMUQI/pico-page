Pico Page 透明锁屏 · 8 张

三方古印、两张繁体现代印、三张植物线描。印章采用已确认的放大及右下内收位置；植物主体不透明，背景和间隙透明。

固件要求
透明叠加需要设备具有「叠加当前画面」选项。当前正式版 0.3.0 及更早版本不支持。

使用方法
1. 将 ZIP 中的 LockScreens/ 合并到 TF 卡根目录，或把单张 PNG 放入卡根 LockScreens/；需要替换同名旧图时只替换对应文件。
2. 电脑安全弹出后，在设备退出 USB 文件模式并重启。
3. 在「设置 → 电源与休眠」选择「自定义图片」，固定一张或按文件名轮播，开启「叠加当前画面」，保存设置。
4. 短按电源键查看休眠效果；准备期间再次短按电源键可取消。

网页缩略图仅展示主体，下载 PNG 保留完整透明画布。印章为 684 × 1216，植物为 940/941 × 1672，由设备按屏幕适配。PNG 与设备选定版本逐字节相同，清单记录大小及 SHA-256。
